# Tài liệu sinh cũ

Các file DOCX trong thư mục này là bản trung gian/phiên bản cũ, được giữ để đối chiếu chứ không phải tài liệu học chính.

Bản tham khảo hiện tại ở root là:

- `PCCP_Level_1_Full_De_Bai_Tieng_Viet_84_Bai.docx`
- `PCCP_Level_1_Full_De_Bai_Tieng_Viet_84_Bai.pdf`

Tên file cũ được giữ nguyên để còn truy vết nguồn gốc.
