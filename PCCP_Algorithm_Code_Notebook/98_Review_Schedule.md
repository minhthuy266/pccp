## Nội dung từng lần ôn

- Ngay sau học: Recall Card + viết code xương.
- D+1: Blank Page Test, tự tạo test có key lặp hoặc biên.
- D+3: bài mới cùng dạng, không nhìn tên pattern.
- D+7: mutation drill; nói phần state/check/update đổi chỗ nào.
- D+14: mini-test trộn và Explain Back trong 3 phút.

Nếu `✗`, lịch mới bắt đầu lại từ D+1. Nếu `△`, làm một bài Tầng 2 hoặc 3 trước lần review kế tiếp.
