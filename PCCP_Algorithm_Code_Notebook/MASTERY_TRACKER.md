## Gate chương

Một chương chỉ qua khi ≥80% ID CORE đạt mức 3, ≥60% ID CORE đạt mức 4, hai Transfer/Mixed Test liên tiếp đạt rubric, không xem full code và giải thích được invariant. Ghi test hoặc bài cụ thể vào cột bằng chứng; không tự tăng mức chỉ vì đã đọc chương.
