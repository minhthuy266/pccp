# OF028 — Xuồng cứu sinh

- Nguồn đề: [Programmers lesson 42885](https://school.programmers.co.kr/learn/courses/30/lessons/42885?language=javascript)
- Pattern chính: sort + greedy two pointers
- Mức trong bank: CORE / representative

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Mỗi xuồng chở tối đa hai người và tổng cân nặng không vượt `limit`. Mọi người phải được chở. Trả số xuồng ít nhất.

Không được ghép ba người dù tổng vẫn dưới limit; giới hạn cardinality hai người là phần quan trọng của contract.

## 02. Bound

Thử mọi cách ghép cặp là exponential hoặc ít nhất quadratic. Sort `O(n log n)` rồi hai pointers tuyến tính đủ nhanh cho danh sách lớn.

## 03. Brute force

Chọn một người, thử ghép với mọi người còn lại hoặc đi một mình; backtrack mọi matching và lấy minimum boat. Mỗi quyết định tạo nhiều nhánh tương đương.

## 04. Bottleneck

Người nặng nhất còn lại bắt buộc lên một xuồng ngay trong mọi lời giải. Họ chỉ có hai khả năng:

- ghép được với người nhẹ nhất;
- hoặc không ghép được với bất kỳ ai.

Nếu nặng nhất + nhẹ nhất vượt limit, mọi người khác còn nặng hơn nhẹ nhất nên cũng không ghép được.

## 05. Pattern

Sort tăng dần, giữ `lightest`, `heaviest`. Mỗi vòng đóng một xuồng chứa người nặng nhất:

- nếu ghép được với nhẹ nhất, tiêu thụ cả hai đầu;
- nếu không, tiêu thụ chỉ đầu nặng;
- tăng boat một.

## 06. State

- `sorted` cân nặng tăng dần;
- `lightest`: người nhẹ nhất chưa xử lý;
- `heaviest`: người nặng nhất chưa xử lý;
- `boats`: số xuồng đã đóng.

Vùng chưa xử lý luôn là interval `[lightest, heaviest]`.

## 07. Transition

```text
if lightest == heaviest: one final boat
else if weight[lightest] + weight[heaviest] <= limit:
    lightest++
always:
    heaviest--
    boats++
```

Người nặng nhất luôn rời vùng trong mỗi vòng nên loop kết thúc.

## 08. Invariant

Trước mỗi vòng, mọi người ngoài `[lightest, heaviest]` đã được gán vào đúng `boats` xuồng hợp lệ; chưa ai trong interval được dùng.

Greedy exchange: nếu người nặng nhất ghép được với ai đó, ghép họ với người nhẹ nhất không làm mất giải pháp tốt hơn—partner cũ (nặng hơn hoặc bằng nhẹ nhất) có thể được thay bởi nhẹ nhất, để lại partner cũ linh hoạt hơn. Nếu không ghép được với nhẹ nhất, họ buộc đi một mình.

## 09. Complexity

- Sort: `O(n log n)`.
- Two pointers: `O(n)`; mỗi người bị tiêu thụ một lần.
- Space: `O(n)` vì code copy input trước sort; có thể `O(1)` phụ nếu được mutate input.

## 10. Pseudocode

```text
sort people ascending
left = 0, right = n-1, boats = 0
while left <= right:
    if left == right:
        boats += 1
        break
    if people[left] + people[right] <= limit:
        left += 1
    right -= 1
    boats += 1
return boats
```

## 11. Code bước 1 — dựng state

```js
function sortedWeights(people) {
  return [...people].sort((a, b) => a - b);
}
```

Numeric comparator là bắt buộc; copy tránh làm thay đổi input của caller.

## 12. Code bước 2 — viết transition

```js
function canShare(sorted, lightest, heaviest, limit) {
  return sorted[lightest] + sorted[heaviest] <= limit;
}
```

Chỉ test hai cực trị. Khi pair này fail, không cần thử người ở giữa với heaviest.

## 13. Code bước 3 — ghép vòng lặp

```js
function countBoats(sorted, limit) {
  let left = 0;
  let right = sorted.length - 1;
  let boats = 0;
  while (left <= right) {
    if (left === right) return boats + 1;
    if (canShare(sorted, left, right, limit)) left++;
    right--;
    boats++;
  }
  return boats;
}
```

Không tăng `left` khi người nặng đi một mình; người nhẹ vẫn chưa được xử lý.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF028.js](../../../solutions/official/OF028.js).

```js
function minimumLifeboats(people, limit) {
  const sorted = [...people].sort((a, b) => a - b);
  let lightest = 0;
  let heaviest = sorted.length - 1;
  let boats = 0;
  while (lightest <= heaviest) {
    if (lightest === heaviest) {
      boats++;
      break;
    }
    if (sorted[lightest] + sorted[heaviest] <= limit) lightest++;
    heaviest--;
    boats++;
  }
  return boats;
}
```

## 15. Dry-run

`[70,50,80,50]`, limit `100` → sorted `[50,50,70,80]`:

| left/right | Test | Quyết định | boats |
|---|---|---|---:|
| 50 / 80 | 130 > 100 | 80 đi một mình | 1 |
| 50 / 70 | 120 > 100 | 70 đi một mình | 2 |
| 50 / 50 | 100 <= 100 | ghép đôi | 3 |

## 16. Edge cases

1. Một người: một xuồng.
2. Mọi pair vừa đúng limit.
3. Không pair nào hợp lệ: answer bằng `n`.
4. Duplicate weights.
5. Số người lẻ: cuối cùng `left === right`.

## 17. Lỗi JavaScript thường gặp

- Quên numeric comparator.
- Cho hơn hai người lên xuồng vì chỉ kiểm tổng weight.
- Khi pair fail vẫn tăng `left`, làm mất người nhẹ.
- Đếm boat theo số pair rồi quên người đi một mình.
- Mutate input bằng sort khiến test/caller sau dùng dữ liệu đã đổi.
