# OF012 — Cay hơn

- Nguồn đề: [Programmers lesson 42626](https://school.programmers.co.kr/learn/courses/30/lessons/42626?language=javascript)
- Pattern chính: min-heap + greedy combine two minima
- Mức trong bank: CORE / template

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Lặp lại việc lấy hai món có độ cay nhỏ nhất `a <= b`, tạo món mới có độ cay `a + 2*b`, cho đến khi mọi món đạt ít nhất `K`. Trả số lần trộn ít nhất; nếu không thể thì `-1`.

Nếu minimum hiện tại đã đạt K thì toàn bộ heap đạt K và dừng ngay.

## 02. Bound

Sort lại toàn bộ array sau mỗi lần trộn tốn gần `O(n² log n)`. Cần cấu trúc lấy hai minimum và chèn một value trong `O(log n)`: min-heap.

## 03. Brute force

Mỗi vòng sort tăng dần, `shift()` hai phần tử, tính món mới, push lại. Đúng theo rule nhưng sort lặp và shift dịch array.

## 04. Bottleneck

Mỗi vòng chỉ cần ba operation:

- xem minimum;
- pop minimum hai lần;
- push một value.

Không cần biết thứ tự đầy đủ của mọi phần tử. Heap duy trì partial order đủ cho các operation này.

## 05. Pattern

Greedy đã được contract chỉ định: luôn trộn hai minimum. Min-heap thực thi rule hiệu quả:

```text
while heap.min < K:
    if heap.size < 2: impossible
    a = popMin(); b = popMin()
    push(a + 2*b)
    count++
```

## 06. State

- heap array thỏa parent `<=` children;
- `mixes`;
- mỗi vòng: `least`, `secondLeast`, `mixed`.

Heap index: parent `(i-1)//2`, left `2i+1`, right `2i+2`.

## 07. Transition

`push`: thêm cuối rồi bubble-up đến khi parent không lớn hơn child. `pop`: lấy root, đưa last lên root rồi bubble-down với child nhỏ hơn. Main loop pop hai, push một nên size giảm một mỗi mix.

## 08. Invariant

Heap invariant: mọi node không lớn hơn các child, nên root là minimum global. Sau mỗi push/pop, bubble operation khôi phục invariant.

Main invariant: heap chứa chính xác multiset món hiện tại sau `mixes` thao tác. Nếu root `>= K`, mọi món đều đạt. Nếu root `< K` nhưng size `< 2`, không còn operation hợp lệ nên impossible.

## 09. Complexity

- Cách constructor hiện tại push từng value: `O(n log n)`.
- Tối đa `n-1` lần mix; mỗi lần ba heap operation `O(log n)`.
- Tổng `O(n log n)`, space `O(n)`.

Có thể heapify `O(n)`, nhưng push-build dễ học và vẫn đủ bound.

## 10. Pseudocode

```text
heap = minHeap(scoville)
mixes = 0
while heap not empty and heap.peek < K:
    if heap.size < 2: return -1
    least = heap.pop
    second = heap.pop
    heap.push(least + 2*second)
    mixes++
return mixes
```

## 12. Code bước 2 — viết transition

```js
function bubbleUp(heap, child) {
  while (child > 0) {
    const parent = Math.floor((child - 1) / 2);
    if (heap[parent] <= heap[child]) break;
    [heap[parent], heap[child]] = [heap[child], heap[parent]];
    child = parent;
  }
}
```

Sau push, chỉ đường từ leaf mới lên root có thể vi phạm.

## 13. Code bước 3 — ghép vòng lặp

```js
function mixTwoLeast(heap) {
  const least = heap.pop();
  const secondLeast = heap.pop();
  heap.push(least + secondLeast * 2);
}
```

Phải pop lần hai sau khi heap đã tái cấu trúc; không lấy `values[1]` vì phần tử nhỏ thứ hai không cố định ở đó.

## 14. Code hoàn chỉnh

Code executable, gồm toàn bộ `MinHeap`: [solutions/official/OF012.js](../../../solutions/official/OF012.js).

```js
class MinHeap {
  constructor(values = []) {
    this.values = [];
    for (const value of values) {
      this.push(value);
    }
  }

  get size() {
    return this.values.length;
  }

  peek() {
    return this.values[0];
  }

  push(value) {
    const heap = this.values;
    heap.push(value);
    let child = heap.length - 1;

    while (child > 0) {
      const parent = Math.floor((child - 1) / 2);
      if (heap[parent] <= heap[child]) {
        break;
      }
      [heap[parent], heap[child]] = [heap[child], heap[parent]];
      child = parent;
    }
  }

  pop() {
    const heap = this.values;
    if (heap.length === 0) {
      return undefined;
    }
    if (heap.length === 1) {
      return heap.pop();
    }

    const minimum = heap[0];
    heap[0] = heap.pop();
    let parent = 0;

    while (true) {
      const left = parent * 2 + 1;
      const right = left + 1;
      let smallest = parent;

      if (left < heap.length && heap[left] < heap[smallest]) {
        smallest = left;
      }
      if (right < heap.length && heap[right] < heap[smallest]) {
        smallest = right;
      }
      if (smallest === parent) {
        break;
      }

      [heap[parent], heap[smallest]] = [heap[smallest], heap[parent]];
      parent = smallest;
    }

    return minimum;
  }
}

function minimumScovilleMixes(scoville, target) {
  const heap = new MinHeap(scoville);
  let mixes = 0;

  while (heap.size > 0 && heap.peek() < target) {
    if (heap.size < 2) {
      return -1;
    }
    const least = heap.pop();
    const secondLeast = heap.pop();
    heap.push(least + secondLeast * 2);
    mixes += 1;
  }

  return mixes;
}
```

## 16. Edge cases

1. Minimum ban đầu đã đạt: 0 mix.
2. Một phần tử dưới K: `-1`.
3. Trộn đến còn một phần tử vẫn dưới K: `-1`.
4. Duplicate minima.
5. Heap pop khi size 0/1 phải có contract rõ.

## 17. Lỗi JavaScript thường gặp

- Dùng `.sort()` sau mỗi push.
- Dùng `.shift()` lấy minimum.
- Sau pop root quên bubble-down.
- Bubble-down luôn chọn left dù right nhỏ hơn.
- Check size sau khi đã pop một phần tử, làm mất state.
- Công thức sai thành `2*a+b`.
- Dùng bitwise midpoint/index ở dữ liệu có thể lớn không cần thiết.

### Loop and condition derivation

- **Nhịp lặp:** `trong khi heap không rỗng và root còn nhỏ hơn target.`. Đây là lý do code dùng block bắt đầu bởi `while (heap.size > 0 && heap.peek() < target) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “root đã đạt target chưa; nếu chưa thì heap còn ít nhất hai phần tử không.”. Trong dry run `[1,2,3,9,10,12]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (heap.size < 2) {`.
- **Tiến triển:** heap tự đổi root qua bubble-down/up; không có array pointer.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `heap xóa hai occurrence, thêm mixedValue và mixes += 1.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `mixes += 1;`.
- **Cleanup:** không cần; mọi món chưa trộn vẫn nằm đúng một occurrence trong heap.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Cay hơn:** Condition phải hỏi đúng ý nghĩa heap top sau comparator và sau khi stale entry (nếu có) đã được dọn. Equal priority tiếp tục theo tie-break ghi trong contract, không theo thứ tự tình cờ của array heap.

#### 19. Làm bằng tay và brute force executable

Với `[1,2,3,9,10,12]`, K=7, lần đầu lấy đúng `1,2` tạo 5; multiset mới là
`[3,5,9,10,12]`. Lần hai lấy `3,5` tạo 13; minimum trở thành 9 nên dừng sau 2 lần.

```js
function minimumScovilleMixesBrute(scoville, target) {
  const values = scoville.slice();
  let mixes = 0;

  while (values.length > 0) {
    values.sort((a, b) => a - b);
    if (values[0] >= target) return mixes;
    if (values.length < 2) return -1;

    const least = values.shift();
    const secondLeast = values.shift();
    values.push(least + secondLeast * 2);
    mixes += 1;
  }
  return -1;
}
```

Brute force bám sát contract nhưng sort lại và dịch array mỗi vòng. Heap giữ đúng phần order cần dùng.
