# OF047 — Đếm phòng

- Nguồn đề: [Programmers lesson 49190](https://school.programmers.co.kr/learn/courses/30/lessons/49190?language=javascript)
- Pattern chính: planar walk + new edge to visited node
- Mức trong bank: STRETCH / graph modeling

## 01. Contract

Đi theo tám hướng trên mặt phẳng; đường vẽ tạo các phòng kín. Đếm số phòng.

## 02. Bound

Scan arrows tuyến tính, nhưng cần phát hiện giao nhau giữa hai diagonal tại midpoint.

## 03. Brute force

Dựng hình học polygon đầy đủ rồi tìm faces; phức tạp. Chỉ đếm node visit cũng bỏ diagonal crossing.

## 04. Bottleneck

Trong planar graph connected, thêm một edge mới nối tới node đã tồn tại tạo đúng một cycle/room. Scale mỗi arrow thành hai half-step biến diagonal crossing thành node nguyên.

## 05. Pattern

Visited nodes + undirected edges. Mỗi half-step: nếu next node cũ nhưng edge mới, rooms++; rồi add node/edge.

## 06. State

Current x,y; node Set; canonical undirected edge Set; rooms; eight direction deltas.

## 07. Transition

Mỗi arrow lặp hai step cùng delta. Build node keys và edge key sorted endpoints; test trước add.

## 08. Invariant

Sets mô tả đúng embedded graph của prefix half-steps. Edge cũ không tạo face mới; edge mới tới node mới mở tree branch; edge mới tới node cũ đóng đúng một independent cycle nên tăng room một.

## 09. Complexity

Time `O(arrows)` average Set operations, space `O(arrows)`.

## 10. Pseudocode

```text
visitedNodes={origin}; visitedEdges={}
for arrow:
  repeat twice:
    next=current+direction
    edge=canonical(current,next)
    if next visited and edge new: rooms++
    add next,edge; current=next
return rooms
```

## 11. Code bước 1 — dựng state

```js
const visitedNodes=new Set(["0,0"]);
const visitedEdges=new Set();
```

## 12. Code bước 2 — viết transition

```js
function undirectedEdgeKey(first,second) {
  return first<second?`${first}|${second}`:`${second}|${first}`;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
if (visitedNodes.has(nextKey)&&!visitedEdges.has(edgeKey)) rooms++;
visitedNodes.add(nextKey); visitedEdges.add(edgeKey);
```

```js
function createsRoom(visitedNodes,visitedEdges,nextKey,edgeKey) {

}
```

Module đầy đủ scale bằng hai half-step cho mỗi arrow.

## 15. Dry-run

Đi hình vuông quay về origin qua edge mới: ba step đầu tới node mới, step cuối next origin đã visited và edge chưa có ⇒ rooms tăng1. Đi lại cạnh cũ không tăng.

## 16. Edge cases

Đi tới/lùi cùng edge; square; diagonal crossing; nhiều cycles share node/edge; negative coordinates.

## 17. Lỗi JavaScript thường gặp

Không half-step; edge có hướng làm lượt về thành edge mới; tăng room mỗi lần revisit node kể cả edge cũ; key coordinate mơ hồ thiếu separator.

## 18. Bài transfer cùng pattern

- OF037: component graph không embedding.

Tín hiệu: đếm faces trong walk planar ⇒ track cả node lẫn undirected edge; crossing cần được biến thành node.
