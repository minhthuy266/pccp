# OF025 — Đồng phục thể dục

- Nguồn đề: [Programmers lesson 42862](https://school.programmers.co.kr/learn/courses/30/lessons/42862?language=javascript)
- Pattern chính: line-neighbor greedy sau conflict normalization
- Mức trong bank: TRANSFER / warmup

## 01. Contract

Student mất đồ chỉ mượn từ số thứ tự kề `-1/+1`; người có reserve chỉ cho một bộ. Người xuất hiện cả lost và reserve phải dùng bộ dự phòng cho chính mình. Tối đa hóa số người tham gia.

## 02. Bound

Có thể brute-force matching, nhưng line adjacency cho greedy scan sau khi xử lý overlap.

## 03. Brute force

Với mỗi người mất, branch mượn trái/phải/không; exponential và nhiều conflict cùng reserve.

## 04. Bottleneck

Overlap không phải lender. Sau normalization, xử lý borrower tăng dần và ưu tiên lender bên trái: reserve bên trái không còn cơ hội giúp borrower tương lai, còn reserve bên phải có thể giúp người kế.

## 05. Pattern

Set lost/reserve; xóa intersection; sort lost; với mỗi student thử `student-1` rồi `student+1`, consume lender.

## 06. State

`lostSet`, `reserveSet`, sorted borrowers; attendance `n-lostSet.size` sau matching.

## 07. Transition

Overlap: delete cả hai Set. Borrow: nếu left reserve delete lender và borrower; else thử right.

## 08. Invariant

Trước borrower x, mọi borrower nhỏ hơn đã được xử lý tối ưu và reserve nhỏ hơn x-1 không thể giúp ai tương lai. Chọn left khi có không làm giảm khả năng của suffix; right được giữ nếu left đủ.

## 09. Complexity

Set build `O(n)`, sort lost `O(l log l)`, scan `O(l)`, space `O(n)`.

## 10. Pseudocode

```text
lostSet, reserveSet
remove intersection
for student in sorted lost:
  if reserve has student-1: consume
  else if reserve has student+1: consume
return n-remainingLost
```

## 11. Code bước 1 — dựng state

```js
const lostSet=new Set(lost);
const reserveSet=new Set(reserve);
```

## 12. Code bước 2 — viết transition

```js
for (const student of [...lostSet]) if (reserveSet.has(student)) {
  lostSet.delete(student); reserveSet.delete(student);
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
for (const student of [...lostSet].sort((a,b)=>a-b)) {
  const lender=reserveSet.has(student-1)?student-1:
    reserveSet.has(student+1)?student+1:null;
  if (lender!==null) { reserveSet.delete(lender); lostSet.delete(student); }
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF025.js](../../../solutions/official/OF025.js).

```js
function maximumGymClassAttendance(n,lost,reserve) {
  const lostSet=new Set(lost),reserveSet=new Set(reserve);
  for (const s of [...lostSet]) if (reserveSet.has(s)) { lostSet.delete(s); reserveSet.delete(s); }
  for (const s of [...lostSet].sort((a,b)=>a-b)) {
    if (reserveSet.has(s-1)) reserveSet.delete(s-1);
    else if (reserveSet.has(s+1)) reserveSet.delete(s+1);
    else continue;
    lostSet.delete(s);
  }
  return n-lostSet.size;
}
```

## 15. Dry-run

Lost `[2,3]`, reserve `[3,4]`: student3 overlap tự dùng, còn lost2 và reserve4; khoảng cách2 nên không cho mượn, attendance4. Nếu cho 3 mượn trước khi normalize sẽ sai.

## 16. Edge cases

Overlap; lender có hai hàng xóm mất; boundary student1/n; không ai mượn được; tất cả được cứu.

## 17. Lỗi JavaScript thường gặp

Không remove overlap; process lost unsorted; cho một reserve hai lần; ưu tiên right tùy tiện; splice array đang iterate.
