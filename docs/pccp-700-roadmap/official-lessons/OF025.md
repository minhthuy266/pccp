# OF025 — Đồng phục thể dục

- Nguồn đề: [Programmers lesson 42862](https://school.programmers.co.kr/learn/courses/30/lessons/42862?language=javascript)
- Pattern chính: line-neighbor greedy sau conflict normalization
- Mức trong bank: TRANSFER / warmup

## 01. Contract

Student mất đồ chỉ mượn từ số thứ tự kề `-1/+1`; người có reserve chỉ cho một bộ. Người xuất hiện cả lost và reserve phải dùng bộ dự phòng cho chính mình. Tối đa hóa số người tham gia.

## 02. Bound

Có thể brute-force matching, nhưng line adjacency cho greedy scan sau khi xử lý overlap.

## 03. Brute force

Với mỗi người mất, branch mượn trái/phải/không; exponential và nhiều conflict cùng reserve.

## 04. Bottleneck

Overlap không phải lender. Sau normalization, xử lý borrower tăng dần và ưu tiên lender bên trái: reserve bên trái không còn cơ hội giúp borrower tương lai, còn reserve bên phải có thể giúp người kế.

## 05. Pattern

Set lost/reserve; xóa intersection; sort lost; với mỗi student thử `student-1` rồi `student+1`, consume lender.

## 06. State

`lostSet`, `reserveSet`, sorted borrowers; attendance `n-lostSet.size` sau matching.

## 07. Transition

Overlap: delete cả hai Set. Borrow: nếu left reserve delete lender và borrower; else thử right.

## 08. Invariant

Trước borrower x, mọi borrower nhỏ hơn đã được xử lý tối ưu và reserve nhỏ hơn x-1 không thể giúp ai tương lai. Chọn left khi có không làm giảm khả năng của suffix; right được giữ nếu left đủ.

## 09. Complexity

Set build `O(n)`, sort lost `O(l log l)`, scan `O(l)`, space `O(n)`.

## 10. Pseudocode

```text
lostSet, reserveSet
remove intersection
for student in sorted lost:
  if reserve has student-1: consume
  else if reserve has student+1: consume
return n-remainingLost
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF025.js](../../../solutions/official/OF025.js).

```js
function maximumGymClassAttendance(n,lost,reserve) {
  const lostSet = new Set(lost);
  const reserveSet = new Set(reserve);

  for (const student of [...lostSet]) {
    if (!reserveSet.has(student)) continue;
    lostSet.delete(student);
    reserveSet.delete(student);
  }

  const borrowers = [...lostSet].sort((first, second) => first - second);
  for (const student of borrowers) {
    const leftNeighbor = student - 1;
    const rightNeighbor = student + 1;
    if (reserveSet.has(leftNeighbor)) {
      reserveSet.delete(leftNeighbor);
      lostSet.delete(student);
      continue;
    }
    if (reserveSet.has(rightNeighbor)) {
      reserveSet.delete(rightNeighbor);
      lostSet.delete(student);
    }
  }

  return n - lostSet.size;
}
```

### Loop and condition derivation

- **Nhịp lặp:** `quét từng student trong borrowers theo thứ tự tăng.`. Đây là lý do code dùng block bắt đầu bởi `for (const student of [...lostSet]) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “borrower còn trong lostSet; lender trái còn reserve; nếu không thì lender phải.”. Trong dry run `[2,3]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (!reserveSet.has(student)) continue;`.
- **Tiến triển:** for...of tự sang borrower kế; mỗi lender bị consume tối đa một lần.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `khi mượn, delete lender khỏi reserveSet và delete student khỏi lostSet.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (const student of [...lostSet]) {`.
- **Cleanup:** overlap đã xóa trước loop; không còn state phải flush.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

#### 19. Problem → Code hoàn chỉnh

**Làm tay:** trước hết gạch người xuất hiện ở cả lost/reserve vì họ tự dùng đồ của mình. Sau đó
xét người mất tăng dần; thử hàng xóm trái trước vì resource trái sắp hết cơ hội, còn resource
phải có thể cứu người kế tiếp.

```js
function maximumAttendanceBruteForce(n, lost, reserve) {
  const overlap = new Set(lost.filter((student) => reserve.includes(student)));
  const borrowers = lost.filter((student) => !overlap.has(student));
  const lenders = reserve.filter((student) => !overlap.has(student));
  let bestBorrowed = 0;
  function match(index, usedLenders, borrowedCount) {
    if (index === borrowers.length) {
      bestBorrowed = Math.max(bestBorrowed, borrowedCount);
      return;
    }
    match(index + 1, usedLenders, borrowedCount);
    for (let lenderIndex = 0; lenderIndex < lenders.length; lenderIndex++) {
      if (usedLenders.has(lenderIndex)) continue;
      if (Math.abs(lenders[lenderIndex] - borrowers[index]) !== 1) continue;
      usedLenders.add(lenderIndex);
      match(index + 1, usedLenders, borrowedCount + 1);
      usedLenders.delete(lenderIndex);
    }
  }
  match(0, new Set(), 0);
  return n - borrowers.length + bestBorrowed;
}
```

| --- | --- | --- | --- | --- |
| `lostSet`,`reserveSet` | Set | borrower/lender còn sống sau normalization | từ input | xuyên loop |
| `borrowers` | number[] | người mất tăng dần | sorted copy | toàn scan |
| neighbors | number | lender trái/phải của current | `student±1` | iteration |
