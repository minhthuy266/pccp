# OF029 — Nối đảo

- Nguồn đề: [Programmers lesson 42861](https://school.programmers.co.kr/learn/courses/30/lessons/42861?language=javascript)
- Pattern chính: Kruskal minimum spanning tree + DSU
- Mức trong bank: TRANSFER / graph extension

## 01. Contract

Chọn các cầu để mọi đảo liên thông với tổng cost nhỏ nhất. Không cần shortest path giữa một cặp; cần một network spanning toàn bộ node.

## 02. Bound

Sort edge và DSU chạy `O(E log E)`, phù hợp.

## 03. Brute force

Thử mọi subset edge, giữ subset liên thông và lấy tổng nhỏ nhất: `2^E`.

## 04. Bottleneck

Ta cần thêm edge rẻ nhưng không tạo cycle. DSU trả lời nhanh hai endpoint đã cùng component chưa.

## 05. Pattern

Kruskal: sort cost tăng; edge nối hai component khác nhau thì chọn/union; dừng sau `n-1` edge.

## 06. State

Sorted edges, DSU parent/rank, `selectedEdges`, `totalCost`.

## 07. Transition

`union(a,b)` false nếu cùng root; true thì merge và cộng cost.

## 08. Invariant

Selected edges là forest minimum cho các cut đã xử lý. Cut property: edge nhẹ nhất nối hai component hiện tại an toàn thuộc một MST. n-1 edge không cycle trên n node tạo spanning tree.

## 09. Complexity

Sort `O(E log E)`; DSU gần `O(E α(N))`; space `O(N+E)` do copy sort.

## 10. Pseudocode

```text
sort edges by cost
for edge:
  if union endpoints:
    total+=cost; selected++
    if selected==n-1 break
return total
```

## 14. Code hoàn chỉnh

Code executable gồm DSU: [solutions/official/OF029.js](../../../solutions/official/OF029.js).

```js
class DisjointSet {
  constructor(size) {
    this.parent = Array.from({ length: size }, (_, index) => index);
    this.rank = Array(size).fill(0);
  }

  find(node) {
    if (this.parent[node] !== node) {
      this.parent[node] = this.find(this.parent[node]);
    }
    return this.parent[node];
  }

  union(first, second) {
    let firstRoot = this.find(first);
    let secondRoot = this.find(second);
    if (firstRoot === secondRoot) {
      return false;
    }

    if (this.rank[firstRoot] < this.rank[secondRoot]) {
      [firstRoot, secondRoot] = [secondRoot, firstRoot];
    }
    this.parent[secondRoot] = firstRoot;
    if (this.rank[firstRoot] === this.rank[secondRoot]) {
      this.rank[firstRoot] += 1;
    }
    return true;
  }
}

function minimumIslandConnectionCost(n, costs) {
  const sorted = [...costs].sort((a, b) => a[2] - b[2]);
  const disjointSet = new DisjointSet(n);
  let selectedEdges = 0;
  let totalCost = 0;

  for (const [from, to, cost] of sorted) {
    if (!disjointSet.union(from, to)) {
      continue;
    }
    totalCost += cost;
    selectedEdges += 1;
    if (selectedEdges === n - 1) {
      break;
    }
  }

  return totalCost;
}
```

- **Nhịp lặp:** `quét sorted edges từ nhẹ đến nặng.`. Đây là lý do code dùng block bắt đầu bởi `for (const [from, to, cost] of sorted) {`, thay vì chọn loop theo thói quen.

- **Tiến triển:** for...of sang edge kế; find dùng path compression.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `union roots, totalCost += cost, acceptedEdges += 1.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (const [from, to, cost] of sorted) {`.
- **Cleanup:** input costs không mutate vì sort bản sao.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

### Complexity proof from movements

#### 19. Làm bằng tay và brute force executable

Với 4 đảo, một spanning tree phải có đúng 3 edge. Duyệt edge theo cost: chọn edge nối hai
component khác nhau; edge nối hai node đã cùng component chỉ tạo cycle và bị bỏ.

```js
function minimumIslandConnectionCostBrute(n, costs) {
  let best = Infinity;

  for (let mask = 0; mask < 2 ** costs.length; mask += 1) {
    if (mask.toString(2).replaceAll("0", "").length !== n - 1) continue;
    const adjacency = Array.from({ length: n }, () => []);
    let total = 0;
    for (let index = 0; index < costs.length; index += 1) {
      if ((mask & (1 << index)) === 0) continue;
      const [from, to, cost] = costs[index];
      adjacency[from].push(to);
      adjacency[to].push(from);
      total += cost;
    }
    const stack = [0];
    const visited = new Set([0]);
    while (stack.length > 0) {
      for (const next of adjacency[stack.pop()]) {
        if (visited.has(next)) continue;
        visited.add(next);
        stack.push(next);
      }
    }
    if (visited.size === n) best = Math.min(best, total);
  }
  return best;
}
```
