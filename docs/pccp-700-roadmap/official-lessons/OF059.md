# OF059 — Giao hàng

- Nguồn đề: [Programmers lesson 12978](https://school.programmers.co.kr/learn/courses/30/lessons/12978?language=javascript)
- Pattern chính: Dijkstra + min-heap
- Mức trong bank: TRANSFER / weighted shortest path

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Graph vô hướng có trọng số thời gian dương, có thể có nhiều road giữa cùng hai làng. Từ làng 1, đếm làng có shortest travel time không vượt K.

## 02. Bound

Gọi `E = roads.length`, tính cả các road song song. BFS không đúng vì edge cost khác nhau. Implementation dùng adjacency list và min-heap lazy deletion, nên có thể giữ `O(E)` entry kể cả stale entry và chạy `O(N + E log(E+1))`.

## 03. Brute force

DFS mọi simple path rồi lấy minimum cho từng node; exponential. Hoặc Bellman-Ford lặp relax toàn edge `O(NE)`, đúng nhưng thừa vì weight không âm.

## 04. Bottleneck

Cần luôn mở rộng node có tentative distance nhỏ nhất. FIFO queue không đảm bảo điều đó; priority queue làm được.

## 05. Pattern

Dijkstra lazy deletion: pop `[distance,node]`; nếu entry không bằng distance mới nhất thì stale, skip; relax mọi edge và push candidate tốt hơn.

## 06. State

- weighted adjacency `[neighbor,cost]`;
- `distance`;
- min-heap `[distance,node]`;
- current/candidate.

## 07. Transition

`candidate=currentDistance+edgeCost`. Nếu nhỏ hơn stored, update và push. Không cần decrease-key; entry cũ được skip khi pop.

## 08. Invariant

Khi pop entry bằng distance hiện tại, đó là shortest finalized vì mọi weight không âm và heap không còn tentative path nhỏ hơn. Distance luôn là upper bound tốt nhất đã biết.

## 09. Complexity

Mỗi road vô hướng tạo hai adjacency entry. Mỗi adjacency entry được xét tối đa một lần từ một node finalized và mỗi lần relax thành công push một heap entry; vì vậy có `O(E)` push/pop, kể cả stale entry do parallel road hoặc better path tìm thấy sau. Time `O(N + E log(E+1))`, space `O(N+E)`. Ở đây `E` tính từng road record, không gộp parallel road.

## 10. Pseudocode

```text
dist[1]=0; heap=(0,1)
while heap:
  pop d,node
  if d != dist[node]: continue
  for neighbor,cost:
    candidate=d+cost
    if candidate<dist[neighbor]: update; push
count dist<=K
```

## 11. Code bước 1 — dựng state

```js
function weightedGraph(n,roads) {
  const adj=Array.from({length:n+1},()=>[]);
  for (const [a,b,cost] of roads) { adj[a].push([b,cost]); adj[b].push([a,cost]); }
  return adj;
}
```

## 14. Code hoàn chỉnh

Code executable gồm heap: [solutions/official/OF059.js](../../../solutions/official/OF059.js).

```js
class DistanceMinHeap {
  constructor() {
    this.values = [];
  }
  get size() {
    return this.values.length;
  }
  push(entry) {
    const heap = this.values;
    heap.push(entry);
    let child = heap.length - 1;
    while (child > 0) {
      const parent = Math.floor((child - 1) / 2);
      if (heap[parent][0] <= heap[child][0]) break;
      [heap[parent], heap[child]] = [heap[child], heap[parent]];
      child = parent;
    }
  }
  pop() {
    const heap = this.values;
    if (heap.length === 1) return heap.pop();
    const minimum = heap[0];
    heap[0] = heap.pop();
    let parent = 0;
    while (true) {
      const left = parent * 2 + 1;
      const right = left + 1;
      let smallest = parent;
      if (left < heap.length && heap[left][0] < heap[smallest][0]) smallest = left;
      if (right < heap.length && heap[right][0] < heap[smallest][0]) smallest = right;
      if (smallest === parent) break;
      [heap[parent], heap[smallest]] = [heap[smallest], heap[parent]];
      parent = smallest;
    }
    return minimum;
  }
}

function deliverableVillageCount(n,roads,limit) {
  const adjacency = Array.from({ length: n + 1 }, () => []);
  for (const [from, to, cost] of roads) {
    adjacency[from].push([to, cost]);
    adjacency[to].push([from, cost]);
  }

  const distance = Array(n + 1).fill(Infinity);
  distance[1] = 0;
  const heap = new DistanceMinHeap();
  heap.push([0, 1]);

  while (heap.size > 0) {
    const [currentDistance, node] = heap.pop();
    if (currentDistance !== distance[node]) continue;

    for (const [neighbor, edgeCost] of adjacency[node]) {
      const candidate = currentDistance + edgeCost;
      if (candidate >= distance[neighbor]) continue;
      distance[neighbor] = candidate;
      heap.push([candidate, neighbor]);
    }
  }

  return distance.slice(1).filter((value) => value <= limit).length;
}
```

## 15. Dry-run

Road 1–2 cost10, 1–2 cost1, 2–3 cost1: relax 2 lần tạo heap entries 10 và 1. Pop 1, reach 3 at 2. Khi entry 10 pop, `10 !== dist[2]`, skip.

## 16. Edge cases

1. Parallel roads.
2. Làng 1 luôn distance 0.
3. Unreachable node Infinity.
4. Distance đúng K được tính.
5. Nhiều parallel road giảm dần có thể tạo nhiều stale heap entry; vẫn phải giữ lazy-deletion check.

## 17. Lỗi JavaScript thường gặp

- Dùng BFS/FIFO cho weighted edges.
- Mark visited ngay enqueue như BFS; Dijkstra có thể tìm path tốt hơn sau.
- Quên stale-entry check.
- Chỉ thêm road một chiều.
- Heap so node id thay distance.
