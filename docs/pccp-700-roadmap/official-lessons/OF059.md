# OF059 — Giao hàng

- Nguồn đề: [Programmers lesson 12978](https://school.programmers.co.kr/learn/courses/30/lessons/12978?language=javascript)
- Pattern chính: Dijkstra + min-heap
- Mức trong bank: TRANSFER / weighted shortest path

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Graph vô hướng có trọng số thời gian dương, có thể có nhiều road giữa cùng hai làng. Từ làng 1, đếm làng có shortest travel time không vượt K.

## 02. Bound

BFS không đúng vì edge cost khác nhau. Dijkstra với adjacency list và min-heap chạy `O((N+E)log N)`.

## 03. Brute force

DFS mọi simple path rồi lấy minimum cho từng node; exponential. Hoặc Bellman-Ford lặp relax toàn edge `O(NE)`, đúng nhưng thừa vì weight không âm.

## 04. Bottleneck

Cần luôn mở rộng node có tentative distance nhỏ nhất. FIFO queue không đảm bảo điều đó; priority queue làm được.

## 05. Pattern

Dijkstra lazy deletion: pop `[distance,node]`; nếu entry không bằng distance mới nhất thì stale, skip; relax mọi edge và push candidate tốt hơn.

## 06. State

- weighted adjacency `[neighbor,cost]`;
- `distance`;
- min-heap `[distance,node]`;
- current/candidate.

## 07. Transition

`candidate=currentDistance+edgeCost`. Nếu nhỏ hơn stored, update và push. Không cần decrease-key; entry cũ được skip khi pop.

## 08. Invariant

Khi pop entry bằng distance hiện tại, đó là shortest finalized vì mọi weight không âm và heap không còn tentative path nhỏ hơn. Distance luôn là upper bound tốt nhất đã biết.

## 09. Complexity

Time `O((N+E)log E)`, space `O(N+E)`.

## 10. Pseudocode

```text
dist[1]=0; heap=(0,1)
while heap:
  pop d,node
  if d != dist[node]: continue
  for neighbor,cost:
    candidate=d+cost
    if candidate<dist[neighbor]: update; push
count dist<=K
```

## 11. Code bước 1 — dựng state

```js
function weightedGraph(n,roads) {
  const adj=Array.from({length:n+1},()=>[]);
  for (const [a,b,cost] of roads) { adj[a].push([b,cost]); adj[b].push([a,cost]); }
  return adj;
}
```

## 12. Code bước 2 — viết transition

```js
function candidateDistance(currentDistance,edgeCost) {
  return currentDistance+edgeCost;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function isStale(poppedDistance,node,distance) {
  return poppedDistance!==distance[node];
}
```

## 14. Code hoàn chỉnh

Code executable gồm heap: [solutions/official/OF059.js](../../../solutions/official/OF059.js).

```js
function deliverableVillageCount(n,roads,limit) {
  const adj=weightedGraph(n,roads), dist=Array(n+1).fill(Infinity);
  const heap=new DistanceMinHeap(); dist[1]=0; heap.push([0,1]);
  while (heap.size) {
    const [d,node]=heap.pop();
    if (d!==dist[node]) continue;
    for (const [next,cost] of adj[node]) {
      const candidate=d+cost;
      if (candidate>=dist[next]) continue;
      dist[next]=candidate; heap.push([candidate,next]);
    }
  }
  return dist.slice(1).filter(value=>value<=limit).length;
}
```

## 15. Dry-run

Road 1–2 cost10, 1–2 cost1, 2–3 cost1: relax 2 lần tạo heap entries 10 và 1. Pop 1, reach 3 at 2. Khi entry 10 pop, `10 !== dist[2]`, skip.

## 16. Edge cases

1. Parallel roads.
2. Làng 1 luôn distance 0.
3. Unreachable node Infinity.
4. Distance đúng K được tính.

## 17. Lỗi JavaScript thường gặp

- Dùng BFS/FIFO cho weighted edges.
- Mark visited ngay enqueue như BFS; Dijkstra có thể tìm path tốt hơn sau.
- Quên stale-entry check.
- Chỉ thêm road một chiều.
- Heap so node id thay distance.
