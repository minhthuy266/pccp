# OF059 — Giao hàng

- Nguồn đề: [Programmers lesson 12978](https://school.programmers.co.kr/learn/courses/30/lessons/12978?language=javascript)
- Pattern chính: Dijkstra + min-heap
- Mức trong bank: TRANSFER / weighted shortest path

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Graph vô hướng có trọng số thời gian dương, có thể có nhiều road giữa cùng hai làng. Từ làng 1, đếm làng có shortest travel time không vượt K.

## 02. Bound

Gọi `E = roads.length`, tính cả các road song song. BFS không đúng vì edge cost khác nhau. Implementation dùng adjacency list và min-heap lazy deletion, nên có thể giữ `O(E)` entry kể cả stale entry và chạy `O(N + E log(E+1))`.

## 03. Brute force

DFS mọi simple path rồi lấy minimum cho từng node; exponential. Hoặc Bellman-Ford lặp relax toàn edge `O(NE)`, đúng nhưng thừa vì weight không âm.

## 04. Bottleneck

Cần luôn mở rộng node có tentative distance nhỏ nhất. FIFO queue không đảm bảo điều đó; priority queue làm được.

## 05. Pattern

Dijkstra lazy deletion: pop `[distance,node]`; nếu entry không bằng distance mới nhất thì stale, skip; relax mọi edge và push candidate tốt hơn.

## 06. State

- weighted adjacency `[neighbor,cost]`;
- `distance`;
- min-heap `[distance,node]`;
- current/candidate.

## 07. Transition

`candidate=currentDistance+edgeCost`. Nếu nhỏ hơn stored, update và push. Không cần decrease-key; entry cũ được skip khi pop.

## 08. Invariant

Khi pop entry bằng distance hiện tại, đó là shortest finalized vì mọi weight không âm và heap không còn tentative path nhỏ hơn. Distance luôn là upper bound tốt nhất đã biết.

## 09. Complexity

Mỗi road vô hướng tạo hai adjacency entry. Mỗi adjacency entry được xét tối đa một lần từ một node finalized và mỗi lần relax thành công push một heap entry; vì vậy có `O(E)` push/pop, kể cả stale entry do parallel road hoặc better path tìm thấy sau. Time `O(N + E log(E+1))`, space `O(N+E)`. Ở đây `E` tính từng road record, không gộp parallel road.

## 10. Pseudocode

```text
dist[1]=0; heap=(0,1)
while heap:
  pop d,node
  if d != dist[node]: continue
  for neighbor,cost:
    candidate=d+cost
    if candidate<dist[neighbor]: update; push
count dist<=K
```

## 14. Code hoàn chỉnh

Code executable gồm heap: [solutions/official/OF059.js](../../../solutions/official/OF059.js).

```js
class DistanceMinHeap {
  constructor() {
    this.values = [];
  }
  get size() {
    return this.values.length;
  }
  push(entry) {
    const heap = this.values;
    heap.push(entry);
    let child = heap.length - 1;
    while (child > 0) {
      const parent = Math.floor((child - 1) / 2);
      if (heap[parent][0] <= heap[child][0]) {
        break;
      }
      [heap[parent], heap[child]] = [heap[child], heap[parent]];
      child = parent;
    }
  }
  pop() {
    const heap = this.values;
    if (heap.length === 1) {
      return heap.pop();
    }
    const minimum = heap[0];
    heap[0] = heap.pop();
    let parent = 0;
    while (true) {
      const left = parent * 2 + 1;
      const right = left + 1;
      let smallest = parent;
      if (left < heap.length && heap[left][0] < heap[smallest][0]) {
        smallest = left;
      }
      if (right < heap.length && heap[right][0] < heap[smallest][0]) {
        smallest = right;
      }
      if (smallest === parent) {
        break;
      }
      [heap[parent], heap[smallest]] = [heap[smallest], heap[parent]];
      parent = smallest;
    }
    return minimum;
  }
}

function deliverableVillageCount(n, roads, limit) {
  const adjacency = Array.from({ length: n + 1 }, () => []);
  for (const [from, to, cost] of roads) {
    adjacency[from].push([to, cost]);
    adjacency[to].push([from, cost]);
  }

  const distance = Array(n + 1).fill(Infinity);
  distance[1] = 0;
  const heap = new DistanceMinHeap();
  heap.push([0, 1]);

  while (heap.size > 0) {
    const [currentDistance, node] = heap.pop();
    if (currentDistance !== distance[node]) {
      continue;
    }

    for (const [neighbor, edgeCost] of adjacency[node]) {
      const candidate = currentDistance + edgeCost;
      if (candidate >= distance[neighbor]) {
        continue;
      }
      distance[neighbor] = candidate;
      heap.push([candidate, neighbor]);
    }
  }

  return distance.slice(1).filter((value) => value <= limit).length;
}
```

## 16. Edge cases

1. Parallel roads.
2. Làng 1 luôn distance 0.
3. Unreachable node Infinity.
4. Distance đúng K được tính.
5. Nhiều parallel road giảm dần có thể tạo nhiều stale heap entry; vẫn phải giữ lazy-deletion check.

## 17. Lỗi JavaScript thường gặp

- Dùng BFS/FIFO cho weighted edges.
- Mark visited ngay enqueue như BFS; Dijkstra có thể tìm path tốt hơn sau.
- Quên stale-entry check.
- Chỉ thêm road một chiều.
- Heap so node id thay distance.

### Loop and condition derivation

- **Nhịp lặp:** `pop heap; skip stale; relax mọi neighbor.`. Đây là lý do code dùng block bắt đầu bởi `while (heap.size > 0) {`, thay vì chọn loop theo thói quen.

- **Tiến triển:** heap pop theo minimum; adjacency loop quét edges.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `distance[to]=candidate; heap.push new immutable entry.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `const [currentDistance, node] = heap.pop();`.

### Complexity proof from movements

Mỗi road vô hướng tạo hai adjacency entry. Mỗi adjacency entry được xét tối đa một lần từ một node finalized và mỗi lần relax thành công push một heap entry; vì vậy có `O(E)` push/pop, kể cả stale entry do parallel road hoặc better path tìm thấy sau. Time `O(N + E log(E+1))`, space `O(N+E)`. Ở đây `E` tính từng road record, không gộp parallel road.

**Proof từ operation của Giao hàng:** Đếm theo representation của graph: traversal thường xử lý mỗi đỉnh hữu hạn lần và xét mỗi cạnh theo adjacency; nếu frontier là heap, mỗi push/pop hợp lệ cộng O(log V). Main loop được mô tả là `pop heap; skip stale; relax mọi neighbor.`; movement là `heap pop theo minimum; adjacency loop quét edges.`. Vì vậy phải cộng chi phí các phase nối tiếp và chỉ nhân khi một phase thật sự chạy trọn bên trong mỗi lượt ngoài. Auxiliary space chính là state `distance array và heap entries {node,distance}.`, không tính output nếu convention của bài tách output.

#### 19. Làm bằng tay và brute force executable

Road song song `1—2` cost 10 và 1 tạo hai heap entry cho node 2. Entry distance 1 được xử lý trước;
khi 10 nổi lên, nó khác `distance[2]` mới nhất nên là stale và phải skip.

```js
function deliverableVillageCountBrute(n, roads, limit) {
  const distance = Array(n + 1).fill(Infinity);
  distance[1] = 0;

  for (let pass = 1; pass < n; pass += 1) {
    let changed = false;
    for (const [from, to, cost] of roads) {
      if (distance[from] + cost < distance[to]) {
        distance[to] = distance[from] + cost;
        changed = true;
      }
      if (distance[to] + cost < distance[from]) {
        distance[from] = distance[to] + cost;
        changed = true;
      }
    }
    if (!changed) break;
  }
  return distance.slice(1).filter((value) => value <= limit).length;
}
```

Bellman-Ford đối chứng `O(NE)`. Weight dương cho phép Dijkstra `O(E log E)`.

#### 22. Invariant, lỗi lộ diện và recall

`distance[v]` luôn là cost của path tốt nhất đã khám phá. Khi pop entry còn current, không tentative
path nhỏ hơn nào còn trong heap; weight không âm nên distance đó được finalized. Lazy deletion thay
decrease-key bằng stale check mà vẫn giữ correctness.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| BFS/FIFO | direct cost 10, path hai edge cost 2 | chọn 2 |
| mark visited khi push | better path được tìm sau | vẫn relax lại |
| quên stale check | 2.000 parallel road giảm dần | skip entry cũ |
| dùng `< limit` | distance đúng K | vẫn được giao |

Recall: **weighted nonnegative shortest ⇒ Dijkstra; relax better path, push mới, skip stale khi pop.**
