## 01. Contract

Grid `1` đi được, `0` là tường. Đi bốn hướng từ góc trên trái đến góc dưới phải. Trả số ô của đường ngắn nhất, tính cả start và destination; không tới được trả `-1`.

## 02. Bound

Mỗi ô là node, cạnh giữa hai ô đi được kề nhau có cost 1. BFS thăm mỗi ô tối đa một lần: `O(rows*columns)`.

## 03. Brute force

DFS mọi path đơn rồi lấy minimum. Số path tăng exponential và phải backtrack visited.

## 04. Bottleneck

Ta chỉ cần shortest unweighted path. BFS duyệt theo layer distance, nên lần đầu discover một ô là đường ngắn nhất; không cần enumerate path khác tới ô đó.

## 05. Pattern

Queue BFS: enqueue start, mark distance ngay; dequeue, sinh bốn neighbor hợp lệ chưa thăm, gán `distance+1` rồi enqueue.

## 06. State

- queue `[row,column]` + head;
- `distance[row][column]`, zero nghĩa unseen ngoài start;
- bốn direction.

## 07. Transition

Neighbor hợp lệ khi trong bounds, cell `1`, distance chưa gán. Mark trước push; khi dequeue destination có thể return.

## 08. Invariant

Queue có distance không giảm. Khi distance của ô được gán lần đầu, đó là shortest từ start. Mark lúc enqueue bảo đảm mỗi ô vào queue tối đa một lần.

## 09. Complexity

Time `O(RC)`, space `O(RC)` cho distance và queue.

## 10. Pseudocode

```text
distance[start]=1; enqueue start
while queue:
  current=dequeue
  if destination return distance
  for four neighbors:
    if valid and unseen:
      distance[next]=distance[current]+1
      enqueue next
return -1
```

## 13. Code bước 3 — ghép vòng lặp


## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF038.js](../../../solutions/official/OF038.js).

```js
const GRID_DIRECTIONS = [[-1, 0], [1, 0], [0, -1], [0, 1]];

function shortestGameMapPath(maps) {
  const rows = maps.length;
  const columns = maps[0].length;
  const distance = Array.from({ length: rows }, () => new Int32Array(columns));
  const queue = [[0, 0]];
  let head = 0;
  distance[0][0] = 1;

  while (head < queue.length) {
    const [row, column] = queue[head];
    head += 1;
    if (row === rows - 1 && column === columns - 1) {
      return distance[row][column];
    }

    for (const [deltaRow, deltaColumn] of GRID_DIRECTIONS) {
      const nextRow = row + deltaRow;
      const nextColumn = column + deltaColumn;
      if (
        nextRow < 0 || nextRow >= rows ||
        nextColumn < 0 || nextColumn >= columns ||
        maps[nextRow][nextColumn] === 0 ||
        distance[nextRow][nextColumn] !== 0
      ) continue;

      distance[nextRow][nextColumn] = distance[row][column] + 1;
      queue.push([nextRow, nextColumn]);
    }
  }

  return -1;
}
```

### Loop and condition derivation

- **Nhịp lặp:** `while head < queue.length; inner bốn hướng.`. Đây là lý do code dùng block bắt đầu bởi `while (head < queue.length) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “destination; bounds; wall; distance neighbor đã khác 0.”. Trong dry run `[[1,1],[0,1]]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (row === rows - 1 && column === columns - 1) {`.
- **Tiến triển:** head += 1 sau read; neighbor loop quét bốn direction.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `distance[next] = distance[current] + 1 trước queue.push.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `head += 1;`.
- **Cleanup:** không cần visited riêng vì distance đồng thời là visited.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Đường ngắn nhất bản đồ game:** Guard visited, bounds hoặc stale distance phải chạy trước transition tương ứng. Với BFS, mark visited lúc enqueue để một đỉnh không xếp hàng nhiều lần; với Dijkstra, bỏ entry stale trước khi relax cạnh.

```js
  while (head < queue.length) {
    const [row, column] = queue[head];
    head += 1;
    if (row === rows - 1 && column === columns - 1) {
      return distance[row][column];
    }

    for (const [deltaRow, deltaColumn] of GRID_DIRECTIONS) {
      const nextRow = row + deltaRow;
      const nextColumn = column + deltaColumn;
      if (
        nextRow < 0 || nextRow >= rows ||
        nextColumn < 0 || nextColumn >= columns ||
        maps[nextRow][nextColumn] === 0 ||
        distance[nextRow][nextColumn] !== 0
      ) continue;

      distance[nextRow][nextColumn] = distance[row][column] + 1;
      queue.push([nextRow, nextColumn]);
    }
  }
}
```

```js
  const queue = [[0, 0]];
```

#### 19. Làm bằng tay và brute force executable

Trên grid `[[1,1],[0,1]]`, các layer BFS theo số ô là `{(0,0):1}`, `{(0,1):2}`,
`{(1,1):3}`. Destination lần đầu được discover ở distance 3 nên không path nào ngắn hơn.

```js
function shortestGameMapPathBrute(maps) {
  const rows = maps.length;
  const columns = maps[0].length;
  let best = Infinity;
  const visited = Array.from({ length: rows }, () => Array(columns).fill(false));

  function dfs(row, column, cells) {
    if (cells >= best) return;
    if (row === rows - 1 && column === columns - 1) {
      best = cells;
      return;
    }
    for (const [deltaRow, deltaColumn] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
      const nextRow = row + deltaRow;
      const nextColumn = column + deltaColumn;
      if (nextRow < 0 || nextRow >= rows || nextColumn < 0 || nextColumn >= columns) continue;
      if (maps[nextRow][nextColumn] === 0 || visited[nextRow][nextColumn]) continue;
      visited[nextRow][nextColumn] = true;
      dfs(nextRow, nextColumn, cells + 1);
      visited[nextRow][nextColumn] = false;
    }
  }

  visited[0][0] = true;
  dfs(0, 0, 1);
  return best === Infinity ? -1 : best;
}
```

DFS enumerate path đơn nên exponential; BFS loại mọi path tới cùng ô sau lần discover đầu tiên.
