# OF039 — Chuyển đổi từ

- Nguồn đề: [Programmers lesson 43163](https://school.programmers.co.kr/learn/courses/30/lessons/43163?language=javascript)
- Pattern chính: BFS trên implicit graph của string
- Mức trong bank: CORE / transfer check

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Từ `begin`, mỗi bước đổi đúng một ký tự và từ mới phải thuộc `words`. Tìm số bước ít nhất để đạt `target`; không thể trả `0`. Mọi từ có cùng độ dài.

## 02. Bound

Mỗi word là node; hai word nối cạnh nếu khác đúng một vị trí. Không cần dựng trước toàn bộ graph: khi dequeue một word, scan words để sinh neighbor. `O(N²L)` phù hợp.

## 03. Brute force

DFS mọi chuỗi biến đổi không lặp rồi lấy path ngắn nhất. Số path tăng mạnh và DFS không đảm bảo path đầu là shortest.

## 04. Bottleneck

Mọi transition cost một bước; lần đầu BFS discover word là minimum distance. Nhiều path hội tụ cùng word nên visited loại công việc tương lai trùng nhau.

## 05. Pattern

Implicit BFS: queue `{word,steps}`, với mỗi word chưa visited kiểm Hamming distance đúng 1; mark khi enqueue.

## 06. State

- queue word + steps, head;
- `visited[index]` theo words;
- helper `differsByOneCharacter`.

## 07. Transition

Neighbor hợp lệ nếu chưa visited và khác current đúng một ký tự. Gán visited, enqueue steps+1. Nếu target không có trong words, return 0 sớm.

## 08. Invariant

Queue có steps không giảm. Khi word được mark lần đầu, steps của nó là shortest từ begin. Helper chỉ tạo cạnh đúng contract, không cho zero hoặc hơn một difference.

## 09. Complexity

Mỗi node dequeue tối đa một lần, mỗi lần scan N word và so L ký tự: `O(N²L)` time, `O(N)` space.

## 10. Pseudocode

```text
if target absent return 0
enqueue begin distance 0
while queue:
  pop word
  if target return steps
  for each unseen candidate:
    if differs exactly one: mark; enqueue steps+1
return 0
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF039.js](../../../solutions/official/OF039.js).

```js
function differsByOneCharacter(first, second) {
  let differences = 0;
  for (let index = 0; index < first.length; index++) {
    if (first[index] !== second[index] && ++differences > 1) return false;
  }
  return differences === 1;
}

function minimumWordTransformations(begin, target, words) {
  if (!words.includes(target)) return 0;

  const visited = Array(words.length).fill(false);
  const queue = [{ word: begin, steps: 0 }];
  let head = 0;

  while (head < queue.length) {
    const { word, steps } = queue[head++];
    if (word === target) return steps;

    for (let index = 0; index < words.length; index++) {
      if (visited[index] || !differsByOneCharacter(word, words[index])) continue;
      visited[index] = true;
      queue.push({ word: words[index], steps: steps + 1 });
    }
  }

  return 0;
}
```

## 15. Dry-run

`hit→hot→dot→dog→cog` có 4 edge. BFS có thể đồng thời khám phá nhánh `hot→lot`, nhưng target lần đầu dequeue ở layer 4 vẫn shortest.

## 16. Edge cases

1. Target không trong list.
2. Candidate giống hệt current: không phải một change.
3. Nhiều shortest paths.
4. Có word unreachable.

## 17. Lỗi JavaScript thường gặp

- Chấp nhận difference `<=1`.
- DFS và return path đầu.
- Mark lúc dequeue.
- Dùng Set value khi words có thể cần identity; bài này unique nhưng index đơn giản.
- Return `-1` thay vì 0.

## 18. Bài transfer cùng pattern

- OF038: neighbor grid trực tiếp.

- OF045: graph đã cho adjacency list.

Tín hiệu: node là object/string và cạnh được xác định bằng rule ⇒ implicit graph; shortest unweighted vẫn là BFS.

## 19. Làm bằng tay và brute force executable

Với `hit → cog`, layer đầu chỉ có `hot`; layer hai có `dot, lot`; layer ba có `dog, log`; layer
bốn tới `cog`. Ta không cần dựng adjacency trước: rule “khác đúng một ký tự” sinh edge khi cần.

```js
function minimumWordTransformationsBrute(begin, target, words) {
  let best = Infinity;
  const used = Array(words.length).fill(false);

  function differsByOne(first, second) {
    let differences = 0;
    for (let index = 0; index < first.length; index += 1) {
      if (first[index] !== second[index]) differences += 1;
    }
    return differences === 1;
  }

  function dfs(current, steps) {
    if (steps >= best) return;
    if (current === target) {
      best = steps;
      return;
    }
    for (let index = 0; index < words.length; index += 1) {
      if (used[index] || !differsByOne(current, words[index])) continue;
      used[index] = true;
      dfs(words[index], steps + 1);
      used[index] = false;
    }
  }

  dfs(begin, 0);
  return best === Infinity ? 0 : best;
}
```

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `visited[index]` | occurrence trong `words` đã discover | toàn false |
| queue item | word hiện tại và shortest steps | `{word: begin, steps: 0}` |
| `head` | vị trí dequeue | `0` |
| `differences` | Hamming distance đang đếm | `0` cho mỗi cặp |

## 21. Blueprint từ đề đến code

1. Xem mỗi word là node; hai node nối nếu Hamming distance đúng 1.
2. Không materialize graph vì neighbor có thể kiểm trực tiếp từ `words`.
3. Vì mỗi phép đổi cost 1 và cần minimum, dùng BFS.
4. Loại sớm nếu target không có trong danh sách hợp lệ.
5. Mark occurrence khi enqueue và gắn `steps + 1` vào state.

## 22. Invariant, lỗi lộ diện và recall

Mỗi queue item có shortest steps tới word của nó. Helper chỉ nhận đúng một ký tự khác, nên mọi
edge sinh ra đều hợp lệ; BFS layer order bảo đảm lần discover đầu là tốt nhất. Dùng visited theo
index khiến identity rõ ràng ngay cả khi dữ liệu mở rộng có duplicate.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| chấp nhận khác 0 ký tự | begin xuất hiện trong words | không tạo self-step |
| chấp nhận khác 2 ký tự | `hit → dot` | không phải neighbor |
| target không có trong list | `cog` absent | 0 |
| DFS trả path đầu | có nhánh dài được xét trước | shortest BFS |

Recall: **implicit graph không cần adjacency; viết rule neighbor chính xác rồi BFS nếu edge cost 1.**
