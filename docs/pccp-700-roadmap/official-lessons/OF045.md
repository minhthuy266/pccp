# OF045 — Node xa nhất

- Nguồn đề: [Programmers lesson 49189](https://school.programmers.co.kr/learn/courses/30/lessons/49189?language=javascript)
- Pattern chính: adjacency-list BFS distance
- Mức trong bank: CORE / graph distance

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Graph vô hướng không trọng số, bắt đầu node 1. Khoảng cách là số edge trên shortest path. Trả số node có khoảng cách lớn nhất từ node 1.

## 02. Bound

Adjacency list + BFS chạy `O(N+E)`. Không dùng all-pairs shortest path.

## 03. Brute force

Với mỗi node đích chạy một BFS riêng hoặc enumerate path; lặp lại traversal graph N lần.

## 04. Bottleneck

Một BFS từ source đã cho shortest distance tới mọi node cùng lúc. Sau đó chỉ cần argmax count.

## 05. Pattern

Build undirected adjacency; BFS từ 1 với `distance=-1`; scan distance để giữ maximum và count.

## 06. State

- adjacency list;
- distance `n+1`;
- queue/head;
- `maximumDistance`, `count`.

## 07. Transition

Neighbor unseen nhận `distance[node]+1`, mark/enqueue. Khi scan: distance lớn hơn reset count=1; bằng maximum thì increment.

## 08. Invariant

BFS lần đầu gán distance là shortest vì edge cost 1. Trong scan node 1..i, maximum/count mô tả chính xác prefix đã xét.

## 09. Complexity

Time `O(N+E)`, space `O(N+E)`.

## 10. Pseudocode

```text
build undirected adjacency
distance=-1; distance[1]=0; BFS
max=0,count=0
for node:
  if dist>max: max=dist,count=1
  else if dist==max: count++
return count
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF045.js](../../../solutions/official/OF045.js).

```js
function farthestNodeCount(n, edges) {
  const adjacency = Array.from({ length: n + 1 }, () => []);
  for (const [from, to] of edges) {
    adjacency[from].push(to);
    adjacency[to].push(from);
  }

  const distance = new Int32Array(n + 1);
  distance.fill(-1);
  const queue = [1];
  let head = 0;
  distance[1] = 0;

  while (head < queue.length) {
    const node = queue[head];
    head += 1;
    for (const neighbor of adjacency[node]) {
      if (distance[neighbor] !== -1) {
        continue;
      }
      distance[neighbor] = distance[node] + 1;
      queue.push(neighbor);
    }
  }

  let maximumDistance = 0;
  let count = 0;
  for (let node = 1; node <= n; node++) {
    if (distance[node] > maximumDistance) {
      maximumDistance = distance[node];
      count = 1;
    } else if (distance[node] === maximumDistance) {
      count += 1;
    }
  }
  return count;
}
```

## 15. Dry-run

Star từ node 1 tới 2,3,4: ba node cùng distance 1, maximum 1 và count 3.

## 16. Edge cases

1. n=1: node 1 xa nhất với distance 0, count 1.
2. Chain: chỉ node cuối xa nhất.
3. Nhiều node tie ở layer cuối.
4. Duplicate edge không làm sai visited.

## 17. Lỗi JavaScript thường gặp

- Chỉ thêm adjacency một chiều.
- Dùng DFS depth làm shortest distance trong graph có cycle.
- Count maximum trước khi BFS xong.
- Dùng `Math.max(...distance)` với input quá lớn.

## 18. Bài transfer cùng pattern

## 19. Làm bằng tay và brute force executable

Trong star `1—{2,3,4}`, BFS layer 0 có node 1 và layer 1 có ba node. Maximum distance 1 xuất
hiện ba lần, nên answer 3.

```js
function farthestNodeCountBrute(n, edges) {
  const adjacency = Array.from({ length: n + 1 }, () => []);
  for (const [from, to] of edges) {
    adjacency[from].push(to);
    adjacency[to].push(from);
  }

  function distanceTo(target) {
    const queue = [[1, 0]];
    const visited = new Set([1]);
    for (let head = 0; head < queue.length; head += 1) {
      const [node, distance] = queue[head];
      if (node === target) return distance;
      for (const neighbor of adjacency[node]) {
        if (visited.has(neighbor)) continue;
        visited.add(neighbor);
        queue.push([neighbor, distance + 1]);
      }
    }
    return -1;
  }

  const distances = Array.from({ length: n }, (_, index) => distanceTo(index + 1));
  const maximum = Math.max(...distances);
  return distances.filter((distance) => distance === maximum).length;
}
```

Brute chạy BFS cho từng target. Một BFS từ source đã tính mọi distance cùng lúc.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `adjacency` | graph vô hướng | thêm cả hai chiều |
| `distance[node]` | shortest số edge từ 1 | `-1`, riêng node 1 bằng 0 |
| `queue`, `head` | BFS layer order | `[1]`, `0` |
| `maximumDistance`, `count` | argmax và multiplicity | `0`, `0` |

## 21. Blueprint từ đề đến code

1. Graph unweighted và một source nên chọn BFS.
2. Dựng adjacency hai chiều.
3. Distance `-1` đồng thời là unseen; mark khi enqueue.
4. Sau BFS, scan node 1..n: lớn hơn thì reset count, bằng thì tăng count.
5. Không spread toàn distance vào `Math.max` khi n lớn.

## 22. Invariant, lỗi lộ diện và recall

BFS gán distance lần đầu là shortest. Trong scan prefix node 1..i, cặp
`(maximumDistance,count)` luôn mô tả đúng maximum và số lần xuất hiện trong prefix.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| adjacency một chiều | edge input đảo orientation | graph vẫn vô hướng |
| DFS depth | graph có cycle/shortcut | shortest BFS |
| quên count node 1 | n=1 | 1 |
| chỉ giữ một farthest node | star | 3 |

Recall: **one-source unweighted distance ⇒ một BFS; rồi scan argmax + count.**

## A17. Blueprint đủ trường và Recall ba tầng

```text
OUTPUT: số node có shortest distance lớn nhất từ node 1.
PREPARE: dựng adjacency hai chiều.
GLOBAL STATE: distance, queue và head.
INIT: distance=-1; distance[1]=0; queue=[1]; head=0.
MAIN LOOP: BFS dequeue node; inner quét neighbors; sau BFS scan node 1..n.
CURRENT ITEM: node và neighbor; phase cuối là distance[node].
PER-ITERATION STATE: maximumDistance và count ở phase scan.
CHECK: neighbor unseen; distance lớn hơn hay bằng current maximum.
BRANCH: unseen mark/enqueue; scan lớn hơn reset count, bằng thì increment.
UPDATE: distance[neighbor]=distance[node]+1; update max/count.
POINTER MOVEMENT: head tăng riêng; node scan tăng 1.
STOP / RETURN: BFS queue cạn, scan hết n thì return count.
CLEANUP: không spread distance vào Math.max; index 0 bị bỏ.
```

- Recall 1: Một BFS lấy mọi distance; scan sau để vừa tìm maximum vừa đếm tie.
- Recall 2: STATE distance/queue/max/count → LOOP BFS+scan → CHECK unseen/compare → UPDATE → RETURN count.
- Recall 3: Điền neighbor distance `distance[node] + ___`; lớn hơn max thì `count = ___`.
