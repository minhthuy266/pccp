# OF055 — Thoát mê cung

- Nguồn đề: [Programmers lesson 159993](https://school.programmers.co.kr/learn/courses/30/lessons/159993?language=javascript)
- Pattern chính: hai phase BFS bắt buộc
- Mức trong bank: CORE / multi-phase BFS

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Từ `S` phải tới cần gạt `L` trước, sau đó mới tới exit `E`; `X` là tường. Trả tổng shortest distance hai chặng. Nếu một chặng không tới được, trả `-1`. Có thể đi qua E trước khi mở lever nhưng chưa được kết thúc.

## 02. Bound

Mỗi chặng là shortest path grid unweighted. Chạy BFS hai lần `O(RC)` vẫn tuyến tính.

## 03. Brute force

DFS mọi route mang state `leverOpened`; đúng nhưng enumerate path. Một BFS state ba chiều cũng đúng nhưng phức tạp hơn cần thiết vì checkpoint L duy nhất tách bài thành hai chặng độc lập.

## 04. Bottleneck

Requirement có thứ tự cố định `S→L→E`. Mọi đường hợp lệ đều gồm một path S-L và một path L-E; tối ưu tổng bằng tổng shortest của từng phần vì điểm nối bắt buộc là L.

## 05. Pattern

Viết helper `bfs(start,targetChar)`, gọi hai lần. Mỗi lần phải có distance/visited mới; visited phase một không được chặn đường phase hai.

## 06. State

Helper giữ queue, head, distance và target. Main giữ start, kết quả `toLever` gồm distance + vị trí L, rồi `toExit`.

## 07. Transition

BFS giống OF038 nhưng wall là `'X'` và start distance 0 theo số bước cạnh. Gặp target trả `{distance,position}`; queue hết trả null.

## 08. Invariant

Trong mỗi helper, lần đầu discover ô là shortest từ start phase. Main chỉ chạy phase hai nếu phase một tồn tại; tổng hai shortest là shortest trong mọi route thỏa checkpoint bắt buộc.

## 09. Complexity

Hai BFS: `O(RC)` time và `O(RC)` peak space.

## 10. Pseudocode

```text
start=find S
a=bfs(start,'L'); if absent return -1
b=bfs(a.position,'E'); if absent return -1
return a.distance+b.distance
```

## 14. Code hoàn chỉnh

Code executable gồm helper BFS: [solutions/official/OF055.js](../../../solutions/official/OF055.js).

```js
const MAZE_DIRECTIONS = [[-1, 0], [1, 0], [0, -1], [0, 1]];

function mazeDistance(maps, start, targetCharacter) {
  const rows = maps.length;
  const columns = maps[0].length;
  const distance = Array.from({ length: rows }, () => new Int32Array(columns).fill(-1));
  const queue = [start];
  let head = 0;
  distance[start[0]][start[1]] = 0;

  while (head < queue.length) {
    const [row, column] = queue[head];
    head += 1;
    if (maps[row][column] === targetCharacter) {
      return { distance: distance[row][column], position: [row, column] };
    }

    for (const [deltaRow, deltaColumn] of MAZE_DIRECTIONS) {
      const nextRow = row + deltaRow;
      const nextColumn = column + deltaColumn;
      if (
        nextRow < 0 || nextRow >= rows ||
        nextColumn < 0 || nextColumn >= columns ||
        maps[nextRow][nextColumn] === "X" ||
        distance[nextRow][nextColumn] !== -1
      ) {
        continue;
      }
      distance[nextRow][nextColumn] = distance[row][column] + 1;
      queue.push([nextRow, nextColumn]);
    }
  }

  return null;
}

function mazeEscapeTime(maps) {
  let start = null;
  for (let row = 0; row < maps.length; row++) {
    const column = maps[row].indexOf("S");
    if (column !== -1) start = [row, column];
  }

  const toLever = mazeDistance(maps, start, "L");
  if (toLever === null) {
    return -1;
  }
  const toExit = mazeDistance(maps, toLever.position, "E");
  if (toExit === null) {
    return -1;
  }
  return toLever.distance + toExit.distance;
}
```

## 15. Dry-run

Map một hàng `SLE`: BFS S→L distance 1; BFS mới L→E distance 1; tổng 2. Nếu dùng visited cũ, L hoặc E có thể bị đánh dấu sai cho phase hai.

## 16. Edge cases

1. L tới được nhưng E không.
2. E tới được trực tiếp từ S nhưng L không.
3. Phase hai phải đi lại qua ô phase một.
4. S,L,E cùng một corridor.

## 17. Lỗi JavaScript thường gặp

- BFS thẳng S→E, bỏ checkpoint.
- Reuse visited giữa hai phase.
- Cộng số ô của hai chặng làm đếm L hai lần; helper dùng số bước.
- Không return -1 khi một phase null.

## 18. Bài transfer cùng pattern

- OF038: BFS một phase.
- OF039: neighbor tạo bằng đổi ký tự.
- OF056: numeric BFS.

Tín hiệu: đường đi có checkpoint bắt buộc theo thứ tự ⇒ tách shortest path tại checkpoint nếu future không phụ thuộc lịch sử khác.

### Loop and condition derivation

- **Nhịp lặp:** `BFS S→L; nếu thành công tạo BFS mới L→E.`. Đây là lý do code dùng block bắt đầu bởi `for (let row = 0; row < maps.length; row++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “current target; neighbor bounds, wall X và unseen.”. Trong dry run `SLE`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (column !== -1) start = [row, column];`.
- **Tiến triển:** head tăng riêng trong từng phase; directions bốn hướng.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `distance[next]=distance[current]+1 trước push.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let row = 0; row < maps.length; row++) {`.
- **Cleanup:** distance reset giữa phases; không tái dùng visited của S→L.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Thoát mê cung:** Guard visited, bounds hoặc stale distance phải chạy trước transition tương ứng. Với BFS, mark visited lúc enqueue để một đỉnh không xếp hàng nhiều lần; với Dijkstra, bỏ entry stale trước khi relax cạnh.

#### 19. Làm bằng tay và brute force executable

Map một hàng `SLE` tách thành hai bài độc lập: `S→L = 1`, `L→E = 1`, tổng 2. Nếu exit nằm
trước lever trên đường đi, phase một vẫn được đi qua E nhưng chưa kết thúc.

```js
function mazeEscapeTimeBrute(maps) {
  const rows = maps.length;
  const columns = maps[0].length;
  let start;
  for (let row = 0; row < rows; row += 1) {
    const column = maps[row].indexOf("S");
    if (column !== -1) start = [row, column, false, 0];
  }

  const queue = [start];
  const visited = new Set([`${start[0]}:${start[1]}:false`]);
  for (let head = 0; head < queue.length; head += 1) {
    const [row, column, opened, steps] = queue[head];
    const nextOpened = opened || maps[row][column] === "L";
    if (nextOpened && maps[row][column] === "E") return steps;
    for (const [dr, dc] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
      const nextRow = row + dr;
      const nextColumn = column + dc;
      if (nextRow < 0 || nextRow >= rows || nextColumn < 0 || nextColumn >= columns) continue;
      if (maps[nextRow][nextColumn] === "X") continue;
      const key = `${nextRow}:${nextColumn}:${nextOpened}`;
      if (visited.has(key)) continue;
      visited.add(key);
      queue.push([nextRow, nextColumn, nextOpened, steps + 1]);
    }
  }
  return -1;
}
```

State BFS ba chiều đúng nhưng nặng hơn. Vì checkpoint duy nhất và bắt buộc, hai BFS dễ chứng minh hơn.
