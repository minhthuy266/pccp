# SR001 — Cộng ma trận

- Nguồn đề: [Programmers lesson 12950](https://school.programmers.co.kr/learn/courses/30/lessons/12950?language=javascript)
- Coverage: Implementation / Array / Matrix

## 01. Contract

Hai matrix cùng shape; trả matrix mới có mỗi cell bằng tổng hai cell tương ứng.

## 02. Bound

Phải đọc mọi cell: `O(rows*columns)` là tối ưu.

## 03. Brute force

Nested loop chính là lời giải chuẩn; không có bottleneck asymptotic.

## 04. Bottleneck

Rủi ro là shape/index và alias/mutation, không phải tốc độ.

## 05. Pattern

Map row theo rowIndex, map value theo columnIndex.

## 06. State

`rowIndex`, `columnIndex`, output cell.

## 07. Transition

`result[r][c]=first[r][c]+second[r][c]`.

## 08. Invariant

Sau mỗi cell, output prefix chứa đúng tổng tương ứng và input chưa mutate.

## 09. Complexity

Time/required output space `O(RC)`.

## 10. Pseudocode

```text
for row:
  for column:
    output[row][column]=a[row][column]+b[row][column]
```

## 11. Code bước 1 — dựng state

```js
const result=[];
```

## 12. Code bước 2 — viết transition

```js
function sumCell(first,second,row,column) {
  return first[row][column]+second[row][column];
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
const row=first[rowIndex].map((value,columnIndex)=>value+second[rowIndex][columnIndex]);
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/SR001.js](../../../solutions/official/SR001.js).

```js
function addMatrices(first,second) {
  return first.map((row,r)=>row.map((value,c)=>value+second[r][c]));
}
```

## 15. Dry-run

Hai matrix `1×3` chứng minh rows không bằng columns và index không được đảo.

## 16. Edge cases

1×1; 1×N; N×1; số âm/zero.

## 17. Lỗi JavaScript thường gặp

Dùng first.length cho columns; `.fill([])` alias; mutate input; đổi row/column.
