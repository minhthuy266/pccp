# SR001 — Cộng ma trận

- Nguồn đề: [Programmers lesson 12950](https://school.programmers.co.kr/learn/courses/30/lessons/12950?language=javascript)
- Coverage: Implementation / Array / Matrix

## 01. Contract

Hai matrix cùng shape; trả matrix mới có mỗi cell bằng tổng hai cell tương ứng.

## 02. Bound

Phải đọc mọi cell: `O(rows*columns)` là tối ưu.

## 03. Brute force

Nested loop chính là lời giải chuẩn; không có bottleneck asymptotic.

## 04. Bottleneck

Rủi ro là shape/index và alias/mutation, không phải tốc độ.

## 05. Pattern

Map row theo rowIndex, map value theo columnIndex.

## 06. State

`rowIndex`, `columnIndex`, output cell.

## 07. Transition

`result[r][c]=first[r][c]+second[r][c]`.

## 08. Invariant

Sau mỗi cell, output prefix chứa đúng tổng tương ứng và input chưa mutate.

## 09. Complexity

Time/required output space `O(RC)`.

## 10. Pseudocode

```text
for row:
  for column:
    output[row][column]=a[row][column]+b[row][column]
```

## 13. Code bước 3 — ghép vòng lặp

## 14. Code hoàn chỉnh

Code executable: [solutions/official/SR001.js](../../../solutions/official/SR001.js).

```js
function addMatrices(first, second) {
  const result = [];

  for (let row = 0; row < first.length; row++) {
    const resultRow = [];

    for (let column = 0; column < first[row].length; column++) {
      const cellSum = first[row][column] + second[row][column];
      resultRow.push(cellSum);
    }

    result.push(resultRow);
  }

  return result;
}
```

## 16. Edge cases

## 17. Lỗi JavaScript thường gặp

Dùng first.length cho columns; `.fill([])` alias; mutate input; đổi row/column.

## 19. Làm bằng tay trước khi code

Đặt hai bảng `[[1,2,3],[4,5,6]]` và `[[10,20,30],[40,50,60]]` chồng lên nhau. Đi theo
từng tọa độ: `(0,0)` cho `11`, `(0,1)` cho `22`, `(0,2)` cho `33`; sang hàng 1 được
`44,55,66`. Output có đúng `2` hàng và `3` cột. Tọa độ không đổi, chỉ value tại cùng
`[row][column]` được cộng.

## 20. Brute force là lời giải cuối

```js
function addMatricesBrute(first, second) {
  const rows = first.length;
  const columns = rows === 0 ? 0 : first[0].length;
  const result = [];

  for (let row = 0; row < rows; row++) {
    const resultRow = [];
    for (let column = 0; column < columns; column++) {
      resultRow.push(first[row][column] + second[row][column]);
    }
    result.push(resultRow);
  }

  return result;
}
```

Mọi output cell phụ thuộc vào một cặp input cell riêng, nên bất kỳ thuật toán đúng nào cũng
phải tạo `rows × columns` giá trị: lower bound là `Ω(rows*columns)`. Nested loop đạt đúng
`O(rows*columns)`, vì vậy brute force này cũng là lời giải tối ưu; không cần tìm pattern cao hơn.

## 21. Bottleneck và quyết định representation

Bài không có bottleneck thời gian. Rủi ro thật nằm ở representation:

- dùng `first.length` làm cả rows lẫn columns sẽ sai trên matrix `2×3`;
- ghi thẳng vào `first` vi phạm contract trả matrix mới;
- `Array(rows).fill(Array(columns).fill(0))` tạo các hàng chung reference;
- callback lồng nhau ngắn nhưng che scope row/column khi đang học.

Vì vậy code canonical dựng một `resultRow` mới trong mỗi iteration vòng ngoài rồi push vào
`result`. Mỗi output row có reference độc lập và input không bị sửa.

## 22. Bảng state và init

| State | Kiểu | Lưu chính xác | Init | Vì sao |
| --- | --- | --- | --- | --- |
| `result` | `number[][]` | mọi hàng output đã hoàn tất | `[]` | chưa xử lý hàng nào |
| `row` | `number` | index hàng đang xử lý | `0` | hàng đầu tiên |
| `resultRow` | `number[]` | tổng các cột đã xử lý của hàng hiện tại | `[]` mỗi vòng ngoài | không dùng chung reference giữa hàng |
| `column` | `number` | index cột hiện tại trong `first[row]` | `0` | cột đầu tiên |
| `cellSum` | `number` | tổng hai cell cùng tọa độ hiện tại | phép cộng tại lượt | state riêng iteration |

## 23. Code Blueprint

```text
OUTPUT: matrix mới cùng shape, mỗi cell là tổng hai input cell tương ứng.
PREPARE: contract bảo đảm hai matrix cùng shape; không mutate input.
GLOBAL STATE: result = [].
INIT: chưa có output row nào.
MAIN LOOP: row từ 0 đến first.length-1; inner column theo first[row].length.
CURRENT ITEM: first[row][column] và second[row][column].
PER-ITERATION STATE: cellSum; resultRow thuộc scope của một row.
CHECK: không cần branch vì shape đã hợp lệ theo contract.
BRANCH: không có.
UPDATE: resultRow.push(cellSum).
POINTER MOVEMENT: column tăng; hết row thì row tăng.
STOP / RETURN: sau mỗi inner loop push resultRow; hết outer loop return result.
CLEANUP: không có state tồn đọng.
```

Map sang code: Contract → output matrix mới; State → `result/resultRow`; Loop → row ngoài,
column trong; Transition → cộng cùng tọa độ rồi push; Invariant → output prefix đúng; Return
→ `result` sau mọi hàng.

## 24. Invariant lồng nhau

- Đầu vòng trong tại `(row,column)`, `resultRow` chứa đúng tổng của các cell
  `(row,0..column-1)` và chưa có cell nào của cột sau.
- Cuối vòng trong, push `cellSum` mở rộng invariant thêm đúng một tọa độ.
- Đầu vòng ngoài tại `row`, `result` chứa đúng mọi hàng `0..row-1`, mỗi hàng có reference riêng.
- Khi push `resultRow`, hàng hiện tại hoàn tất. Hết vòng ngoài, toàn bộ matrix đúng và không
  cell input nào từng nằm bên trái phép gán.

## 25. Dry-run state

Với hai matrix `1×3`, hàng duy nhất bắt đầu `resultRow=[]`:

| Current | State trước | Update | State sau |
| --- | --- | --- | --- |
| `(0,0): 1+4` | `[]` | push `5` | `[5]` |
| `(0,1): 2+5` | `[5]` | push `7` | `[5,7]` |
| `(0,2): 3+6` | `[5,7]` | push `9` | `[5,7,9]` |
| hết hàng | `result=[]` | push row | `[[5,7,9]]` |

Case `1×3` cố ý làm lộ code lấy số cột bằng số hàng.

## 26. Ma trận lỗi và revealing test

| Lỗi | Test nhỏ | Kết quả đúng | Vì sao lộ lỗi |
| --- | --- | --- | --- |
| dùng rows làm columns | hai matrix `1×3` | `[[5,7,9]]` | loop sai chỉ xử lý một cột |
| đảo row/column | hai matrix `2×1` | `[[4],[6]]` | truy cập tọa độ không tồn tại |
| mutate input | lưu clone trước lời gọi | clone không đổi | phép gán vào `first` bị phát hiện |
| output row chung reference | cộng hai matrix `2×2`, sửa `result[0][0]` | row 1 không đổi | `.fill([])` làm cả hai hàng đổi |
| bỏ số âm/zero | `[[-2,0]] + [[1,-3]]` | `[[-1,-3]]` | không được filter theo truthiness |
