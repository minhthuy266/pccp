# OF021 — Thảm

- Nguồn đề: [Programmers lesson 42842](https://school.programmers.co.kr/learn/courses/30/lessons/42842?language=javascript)
- Pattern chính: bounded factor search
- Mức trong bank: TRANSFER / representative

## 01. Contract

Thảm chữ nhật có border nâu dày một ô và interior vàng. Biết số ô brown/yellow, trả `[width,height]` với width≥height.

## 02. Bound

Chỉ cần thử factor `height` tới sqrt(total), nên `O(sqrt(total))`.

## 03. Brute force

Thử mọi width,height tới total rồi kiểm hai count: `O(total²)`.

## 04. Bottleneck

Area total cố định nên width×height=total. Chỉ factor pair mới có thể là đáp án; interior `(width-2)(height-2)=yellow` xác nhận border.

## 05. Pattern

Enumerate height từ 3 tới sqrt(total); nếu chia hết, width=total/height và kiểm interior.

## 06. State

`total`, `height`, `width`; không cần dựng matrix thảm.

## 07. Transition

Mỗi height tăng một; non-factor skip; factor kiểm equation và return pair đầu hợp lệ.

## 08. Invariant

Mọi factor pair có width≥height được xét đúng một lần. Equation interior cùng total đảm bảo số border cũng đúng vì brown=total-yellow.

## 09. Complexity

Time `O(sqrt(brown+yellow))`, space `O(1)`.

## 10. Pseudocode

```text
total=brown+yellow
for height=3 while height²<=total:
  if total%height continue
  width=total/height
  if (width-2)(height-2)==yellow return [width,height]
```

## 11. Code bước 1 — dựng state

```js
const total=brown+yellow;
```

## 12. Code bước 2 — viết transition

```js
function yellowInterior(width,height) {
  return (width-2)*(height-2);
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function matchingDimensions(total, yellow, height) {
  if (total % height !== 0) return null;
  const width = total / height;
  return yellowInterior(width, height) === yellow ? [width, height] : null;
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF021.js](../../../solutions/official/OF021.js).

```js
function carpetDimensions(brown, yellow) {
  const total = brown + yellow;

  for (let height = 3; height * height <= total; height++) {
    if (total % height !== 0) {
      continue;
    }
    const width = total / height;
    if ((width - 2) * (height - 2) === yellow) {
      return [width, height];
    }
  }

  return [];
}
```

## 15. Dry-run

Brown10/yellow2, total12: height3 factor, width4; interior `(4-2)(3-2)=2`, return `[4,3]`.

## 16. Edge cases

Square carpet; yellow=1; width much larger height; first numeric factor không nhất thiết thỏa interior.

## 17. Lỗi JavaScript thường gặp

Return `[height,width]`; thử height từ1 tạo negative/zero interior; chỉ kiểm total factor; dùng brown equation sai `2w+2h` mà quên corners adjustment.

## 18. Bài transfer cùng pattern

- OF018: geometry normalize extrema.
- OF020: bounded exhaustive search theo constraint nhỏ.

Tín hiệu: dimensions nguyên + area cố định ⇒ enumerate divisor pairs, không scan toàn 2D space.

## 19. Làm bằng tay và brute force executable

Brown 10, yellow 2 cho total 12. Factor pair có height ít nhất 3 là `(width,height)=(4,3)`;
interior `(4-2)(3-2)=2`, nên border còn lại đúng 10.

```js
function carpetDimensionsBrute(brown, yellow) {
  const total = brown + yellow;
  for (let width = total; width >= 3; width -= 1) {
    for (let height = 3; height <= width; height += 1) {
      if (width * height !== total) continue;
      if ((width - 2) * (height - 2) === yellow) return [width, height];
    }
  }
  return [];
}
```

Brute scan hai dimension. Factor search chỉ thử height tới căn bậc hai và suy ra width.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `total` | diện tích toàn thảm | `brown + yellow` |
| `height` | divisor nhỏ hơn hoặc bằng width | từ 3 tới `sqrt(total)` |
| `width` | divisor ghép cặp | `total / height` |
| interior | số ô không thuộc border dày 1 | `(width-2)(height-2)` |

## 21. Blueprint từ đề đến code

1. Dùng area để có equation `width * height = total`.
2. Vì width≥height, chỉ enumerate height tới căn bậc hai.
3. Bỏ non-divisor; divisor xác định duy nhất width.
4. Kiểm interior yellow thay vì chỉ kiểm area.
5. Return `[width,height]` đúng contract ngay khi tìm thấy.

## 22. Invariant, lỗi lộ diện và recall

Mọi factor pair width≥height xuất hiện đúng một lần khi height là divisor nhỏ. Total equation và
yellow interior equation cùng đúng thì brown tự động bằng `total-yellow`, nên candidate là thảm hợp lệ.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | --- |
| chỉ kiểm factor total | total có nhiều factor pair | còn phải kiểm interior |
| thử height từ 1 | interior âm/zero | bắt đầu 3 |
| trả đảo dimension | brown10/yellow2 | `[4,3]` |
| border formula quên corner | square 3×3 | brown 8 |

Recall: **area rectangle ⇒ divisor pair; border dày 1 ⇒ interior `(w-2)(h-2)`; giữ width≥height.**

## A17. Blueprint đủ trường và Recall ba tầng

```text
OUTPUT: cặp [width, height] với width >= height của tấm thảm.
PREPARE: tính total = brown + yellow và chỉ thử height tới sqrt(total).
GLOBAL STATE: total; không cần lưu mọi factor pair.
INIT: height = 1 là ước dương nhỏ nhất có thể.
MAIN LOOP: tăng height trong khi height * height <= total.
CURRENT ITEM: candidateHeight và candidateWidth = total / candidateHeight.
PER-ITERATION STATE: isDivisor và interiorTiles của cặp hiện tại.
CHECK: total chia hết cho height và (width - 2) * (height - 2) === yellow.
BRANCH: không phải divisor thì continue; đúng cả interior thì return pair.
UPDATE: không có accumulator; mỗi divisor xác định duy nhất width.
POINTER MOVEMENT: height tăng đúng 1 sau mỗi candidate.
STOP / RETURN: return ngay factor pair hợp lệ; fallback [] chỉ bảo vệ total function.
CLEANUP: không cần vì candidate chỉ sống trong một iteration.
```

- Recall 1: Dùng tổng diện tích để tìm factor pair, rồi dùng diện tích lõi để xác nhận viền nâu dày một.
- Recall 2: STATE total → LOOP height<=sqrt → CHECK divisor/interior → UPDATE none → RETURN [width,height].
- Recall 3: Điền `total % height === ___` và `(width - 2) * (height - 2) === ___`.
