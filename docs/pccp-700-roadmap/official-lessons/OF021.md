# OF021 — Thảm

- Nguồn đề: [Programmers lesson 42842](https://school.programmers.co.kr/learn/courses/30/lessons/42842?language=javascript)
- Pattern chính: bounded factor search
- Mức trong bank: TRANSFER / representative

## 01. Contract

Thảm chữ nhật có border nâu dày một ô và interior vàng. Biết số ô brown/yellow, trả `[width,height]` với width≥height.

## 02. Bound

Chỉ cần thử factor `height` tới sqrt(total), nên `O(sqrt(total))`.

## 03. Brute force

Thử mọi width,height tới total rồi kiểm hai count: `O(total²)`.

## 04. Bottleneck

Area total cố định nên width×height=total. Chỉ factor pair mới có thể là đáp án; interior `(width-2)(height-2)=yellow` xác nhận border.

## 05. Pattern

Enumerate height từ 3 tới sqrt(total); nếu chia hết, width=total/height và kiểm interior.

## 06. State

`total`, `height`, `width`; không cần dựng matrix thảm.

## 07. Transition

Mỗi height tăng một; non-factor skip; factor kiểm equation và return pair đầu hợp lệ.

## 08. Invariant

Mọi factor pair có width≥height được xét đúng một lần. Equation interior cùng total đảm bảo số border cũng đúng vì brown=total-yellow.

## 09. Complexity

Time `O(sqrt(brown+yellow))`, space `O(1)`.

## 10. Pseudocode

```text
total=brown+yellow
for height=3 while height²<=total:
  if total%height continue
  width=total/height
  if (width-2)(height-2)==yellow return [width,height]
```

## 11. Code bước 1 — dựng state

```js
const total=brown+yellow;
```

## 12. Code bước 2 — viết transition

```js
function yellowInterior(width,height) {
  return (width-2)*(height-2);
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function matchingDimensions(total, yellow, height) {
  if (total % height !== 0) return null;
  const width = total / height;
  return yellowInterior(width, height) === yellow ? [width, height] : null;
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF021.js](../../../solutions/official/OF021.js).

```js
function carpetDimensions(brown, yellow) {
  const total = brown + yellow;

  for (let height = 3; height * height <= total; height++) {
    if (total % height !== 0) {
      continue;
    }
    const width = total / height;
    if ((width - 2) * (height - 2) === yellow) {
      return [width, height];
    }
  }

  return [];
}
```

## 15. Dry-run

Brown10/yellow2, total12: height3 factor, width4; interior `(4-2)(3-2)=2`, return `[4,3]`.

## 16. Edge cases

Square carpet; yellow=1; width much larger height; first numeric factor không nhất thiết thỏa interior.

## 17. Lỗi JavaScript thường gặp

Return `[height,width]`; thử height từ1 tạo negative/zero interior; chỉ kiểm total factor; dùng brown equation sai `2w+2h` mà quên corners adjustment.

- OF018: geometry normalize extrema.

- OF043: answer space lớn và monotone mới cần binary search.

### Loop and condition derivation

- **Nhịp lặp:** `tăng height trong khi height * height <= total.`. Đây là lý do code dùng block bắt đầu bởi `for (let height = 3; height * height <= total; height++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “total chia hết cho height và (width - 2) * (height - 2) === yellow.”. Trong dry run `(4-2)(3-2)=2`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (total % height !== 0) {`.
- **Tiến triển:** height tăng đúng 1 sau mỗi candidate.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `không có accumulator; mỗi divisor xác định duy nhất width.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let height = 3; height * height <= total; height++) {`.
- **Cleanup:** không cần vì candidate chỉ sống trong một iteration.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Thảm:** Condition của scan/simulation phải theo đúng tie-break và thứ tự rule của đề. So sánh strict hay non-strict chỉ đổi khi boundary/tie của bài chứng minh, không vì thói quen viết comparator.

### Complexity proof from movements

#### 19. Làm bằng tay và brute force executable

Brown 10, yellow 2 cho total 12. Factor pair có height ít nhất 3 là `(width,height)=(4,3)`;
interior `(4-2)(3-2)=2`, nên border còn lại đúng 10.

```js
function carpetDimensionsBrute(brown, yellow) {
  const total = brown + yellow;
  for (let width = total; width >= 3; width -= 1) {
    for (let height = 3; height <= width; height += 1) {
      if (width * height !== total) continue;
      if ((width - 2) * (height - 2) === yellow) return [width, height];
    }
  }
  return [];
}
```

Brute scan hai dimension. Factor search chỉ thử height tới căn bậc hai và suy ra width.
