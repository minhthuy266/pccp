# SR003 — Xoay dấu ngoặc

- Nguồn đề: [Programmers lesson 76502](https://school.programmers.co.kr/learn/courses/30/lessons/76502?language=javascript)
- Coverage: Deque / Stack / String

## 01. Contract

Với mỗi lần xoay trái chuỗi `s` từ `0` đến `s.length - 1` ký tự, kiểm tra toàn bộ chuỗi sau xoay có phải dãy ngoặc đúng hay không. Ba cặp hợp lệ là `()`, `[]`, `{}`; cặp đóng phải khớp đúng loại ngoặc mở gần nhất chưa đóng. Trả số rotation hợp lệ.

Không được chỉ đếm số lượng ngoặc: `([)]` có số lượng cân bằng nhưng sai nesting.

## 02. Bound

Độ dài chuỗi tối đa 1.000. Có `n` rotation, mỗi rotation cần kiểm tra tối đa `n` ký tự nên `O(n²)` là đủ. Không cần thuật toán vòng tròn phức tạp hơn.

## 03. Brute force

Sinh từng rotation rồi kiểm tra. Brute force sai là thử ghép/match mọi cặp ngoặc; branching không cần thiết. Khi đọc từ trái sang phải, ngoặc đóng chỉ có thể match top của stack.

## 04. Bottleneck

Cần giải hai tầng độc lập:

1. Tầng ngoài chọn điểm bắt đầu của rotation.
2. Tầng trong kiểm tra nesting bằng stack.

Lỗi thường gặp là làm đúng một tầng nhưng sai tầng còn lại, ví dụ chỉ kiểm tra một rotation hoặc dùng một biến balance cho cả ba loại ngoặc.

## 05. Pattern

Pattern là **enumerate circular start + matching stack**. Nối `s + s`; rotation bắt đầu tại `offset` chính là đoạn dài `n` từ `offset`. Nhờ vậy không phải mutate queue bằng `shift()`/`push()` ở mỗi vòng.

## 06. State

- `offset`: vị trí bắt đầu rotation trong chuỗi đôi.
- `rotation`: cửa sổ dài `n` đang kiểm tra.
- `stack`: các ngoặc mở chưa được đóng.
- `closingToOpening`: map từ ngoặc đóng sang ngoặc mở bắt buộc.
- `count`: số rotation hợp lệ.

## 07. Transition

Với từng ký tự:

- Ngoặc mở: push vào stack.
- Ngoặc đóng: pop top; nếu top khác loại cần thiết thì rotation sai ngay.
- Hết chuỗi: chỉ hợp lệ nếu stack rỗng, vì stack còn phần tử nghĩa là còn ngoặc mở chưa đóng.

## 08. Invariant

Sau khi xử lý prefix kết thúc ở vị trí `i`, stack chứa đúng các ngoặc mở của prefix chưa được ghép, theo thứ tự từ cũ đến mới. Vì một ngoặc đóng phải đóng cấu trúc gần nhất đang mở, nó bắt buộc khớp top. Invariant này chứng minh stack validator đúng.

Vòng ngoài duyệt mỗi `offset` đúng một lần nên mọi rotation và chỉ các rotation đều được đếm.

## 09. Complexity

Có `n` rotation, mỗi lần slice/scan `n` ký tự: `O(n²)` time. Stack tối đa `n` và chuỗi đôi dài `2n`: `O(n)` auxiliary space.

## 10. Pseudocode

```text
double = s + s
answer = 0
for offset = 0 .. n-1:
  candidate = double[offset .. offset+n)
  stack = empty
  for bracket in candidate:
    if opening: push
    else if pop does not match: invalid
  if no mismatch and stack empty: answer++
return answer
```

## 11. Code bước 1 — viết validator một rotation

```js
const pair = new Map([[")", "("], ["]", "["], ["}", "{"]]);

function isValid(sequence) {
  const stack = [];
  for (const bracket of sequence) {
    if (!pair.has(bracket)) stack.push(bracket);
    else if (stack.pop() !== pair.get(bracket)) return false;
  }
  return stack.length === 0;
}
```

`pop()` trên stack rỗng trả `undefined`, tự động khác ngoặc mở cần thiết nên ngoặc đóng xuất hiện quá sớm cũng bị loại.

## 12. Code bước 2 — biểu diễn rotation

```js
const doubled = sequence + sequence;
const rotation = doubled.slice(offset, offset + sequence.length);
```

Ví dụ `abcabc`, `offset=1`, lấy độ dài 3 được `bca`: đúng bằng xoay trái `abc` một lần.

## 13. Code bước 3 — duyệt đủ điểm bắt đầu

```js
let count = 0;
for (let offset = 0; offset < sequence.length; offset++) {
  const rotation = doubled.slice(offset, offset + sequence.length);
  if (isValidBracketSequence(rotation)) count++;
}
```

Chỉ duyệt `offset < n`; offset `n` quay lại chuỗi ban đầu và sẽ đếm trùng offset `0`.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/SR003.js](../../../solutions/official/SR003.js).

```js
const closingToOpening = new Map([
  [")", "("],
  ["]", "["],
  ["}", "{"],
]);

function isValidBracketSequence(sequence) {
  const stack = [];

  for (const bracket of sequence) {
    if (!closingToOpening.has(bracket)) {
      stack.push(bracket);
      continue;
    }

    if (stack.pop() !== closingToOpening.get(bracket)) return false;
  }

  return stack.length === 0;
}

function countValidBracketRotations(sequence) {
  let count = 0;
  const doubled = sequence + sequence;

  for (let offset = 0; offset < sequence.length; offset++) {
    const rotation = doubled.slice(offset, offset + sequence.length);
    if (isValidBracketSequence(rotation)) count++;
  }

  return count;
}
```

## 15. Dry-run

Với `s = "}]()[{"`:

- offset 0: bắt đầu bằng `}` ⇒ pop stack rỗng ⇒ sai.
- offset 1: `]()[{}` ⇒ sai ngay.
- offset 2: cặp ngoặc tròn đứng trước cặp ngoặc nhọn lồng trong ngoặc vuông ⇒ các lần pop đều khớp, nên hợp lệ.
- offset 3: rotation bắt đầu bằng ngoặc tròn đóng ⇒ sai ngay.
- offset 4: rotation có cặp ngoặc nhọn nằm trong cặp ngoặc vuông, sau đó là cặp ngoặc tròn ⇒ hợp lệ.
- offset 5: sau khi cặp ngoặc nhọn đã đóng, rotation gặp ngoặc vuông đóng khi stack rỗng ⇒ sai.

Kết quả là `2`.

## 16. Edge cases

- Chỉ có ngoặc đóng.
- Số ký tự lẻ: không rotation nào hợp lệ.
- Đúng số lượng nhưng sai loại/nesting như `([)]`.
- Chuỗi ban đầu hợp lệ và một vài rotation khác cũng hợp lệ.
- Stack không mismatch giữa đường nhưng còn ngoặc mở khi kết thúc.

## 17. Lỗi JavaScript thường gặp

- Dùng `shift()` lặp để rotate, gây chi phí dời array không cần thiết.
- Viết `if (stack.pop() === pair)` thay vì lấy `pair.get(bracket)`.
- Chỉ kiểm tra `stack.length === 0`, nhưng không dừng khi mismatch.
- Dùng một biến balance nên không phân biệt `(` với `[`.
- Duyệt `offset <= n`, làm rotation ban đầu bị đếm hai lần.

## 18. Bài transfer cùng pattern

- OF008: cancellation/stack, nhưng điều kiện pop khác.
- OF027 và OF061: stack giữ invariant khác, không phải bracket matching.
- Mọi bài circular enumeration: nhân đôi array/string rồi lấy cửa sổ dài `n`.

Tín hiệu nhận dạng: **mọi phép xoay + cấu trúc phải đóng theo thứ tự ngược lúc mở** ⇒ enumerate điểm cắt bên ngoài, stack bên trong.

## 19. Cầu nối từ hai vòng lặp đến code

### Làm bằng tay và brute force rõ state

Viết chuỗi thành vòng tròn. Chọn từng điểm bắt đầu, đọc đúng `n` ký tự. Trong mỗi rotation,
ngoặc mở được viết vào một danh sách chờ; ngoặc đóng phải gạch đúng opening cuối danh sách.
Nếu đóng sai loại/đóng khi rỗng thì dừng rotation; hết ký tự mà danh sách còn opening cũng sai.

```js
function countValidBracketRotationsBruteForce(sequence) {
  let validRotationCount = 0;
  const characters = sequence.split("");

  for (let rotationCount = 0; rotationCount < sequence.length; rotationCount++) {
    const rotation = characters.join("");
    if (isValidBracketSequence(rotation)) {
      validRotationCount++;
    }

    const leavingFront = characters.shift();
    characters.push(leavingFront);
  }

  return validRotationCount;
}
```

Brute force đúng nhưng mỗi `shift()` dịch array và `join()` dựng string mới. `sequence+sequence`
cho phép lấy rotation bằng một cửa sổ, giữ tầng ngoài tách khỏi validator stack tầng trong.

### State và scope của hai tầng

| State | Kiểu | Lưu chính xác gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `doubled` | string | hai bản sequence liên tiếp | `sequence+sequence` | toàn hàm ngoài |
| `offset` | number | điểm bắt đầu rotation | for từ 0 | loop ngoài |
| `validRotationCount` | number | số rotation hợp lệ | `0` | output state |
| `stack` | string[] | opening chưa được đóng của rotation hiện tại | `[]` | reset mỗi validator |
| `bracket` | string | ký tự current | từ loop trong | iteration |

`stack` phải reset cho mỗi rotation; đặt ngoài validator sẽ làm state rotation trước rò sang
rotation sau. Map pair sống toàn cục vì nó là dữ liệu chuẩn bị bất biến, không phải state chạy.

### Transition, invariant và Blueprint

Validator dùng `for` vì đọc từng bracket. Rotation ngoài cũng dùng `for` vì biết chính xác có
`n` offset. Không dùng counter vì ba loại opening cần giữ thứ tự/type.

```text
OUTPUT: validRotationCount; PREPARE: closingToOpening,doubled
GLOBAL STATE: count; INIT: count=0; MAIN LOOP: for offset 0..n-1
CURRENT ITEM: rotation=doubled.slice(offset,offset+n)
PER-ITERATION STATE: stack=[] bên trong validator, bracket
CHECK: bracket là opening? nếu closing, top có đúng required opening?
BRANCH: opening → push+continue; mismatch → return false
UPDATE: matching closing → pop; valid validator → count++
POINTER MOVEMENT: inner for qua bracket, outer for qua offset
STOP / RETURN: mismatch fail sớm; cuối validator stack rỗng; hết offset return count
CLEANUP: stack còn opening làm validator false; stack tự reset ở call kế
```

Sau mỗi bracket, stack chứa đúng opening chưa ghép của prefix rotation. Outer loop xét mỗi
offset `[0,n)` đúng một lần nên không thiếu/đếm trùng rotation.

| Case | Stack trước | Current | Update | Kết luận |
| --- | --- | --- | --- | --- |
| state rỗng | `[]` | `}` | pop được `undefined` | false ngay |
| sai nesting | `[(,[]` | `)` | top `[` khác `(` | false |
| opening dư | `[(]` | hết rotation | cleanup stack không rỗng | false |
| hợp lệ | `[(]` | `)` | pop `(` | tiếp tục/rỗng |

Có `n` rotation và mỗi validator đọc tối đa `n` ký tự: `O(n²)` time; doubled và stack `O(n)`.
Theo bound 1.000, không cần tối ưu phức tạp hơn.

- Logic: dùng một balance; `([)]` sẽ bị nhận nhầm nếu chỉ đếm.
- Off-by-one: `offset <= n` đếm rotation đầu hai lần.
- Check/update: pop trước khi xác định current là closing làm mất opening.
- Init/scope: không reset stack giữa rotation.
- Hidden: length lẻ không rotation nào hợp lệ; closing đầu phải fail sớm.
- Performance: `shift()+join()` mỗi rotation tạo thêm chi phí dịch/copy.

```text
Recall 1: n offsets; mỗi offset stack mới; opening push; closing phải match top; cuối stack rỗng.
Recall 2: STATE doubled/count + per-rotation stack; LOOP offset/bracket; CHECK pair; UPDATE; RETURN.
Recall 3: const rotation=doubled.slice(____, ____); if (isValid(rotation)) ____;
          if (stack.pop() !== closingToOpening.get(____)) return ____;
OUT: count rotations; LIMIT: O(n²) đủ; HAND: chọn start rồi match nesting
BRUTE: shift/push rotation; SLOW: dịch/join; PATTERN: circular enumeration + matching stack
STATE + INIT: doubled,count=0,stack reset; LOOP + INVARIANT: stack là unmatched openings
UPDATE + STOP: push/pop, mismatch false, empty true, count++
```
