# OF037 — Mạng lưới

- Nguồn đề: [Programmers lesson 43162](https://school.programmers.co.kr/learn/courses/30/lessons/43162?language=javascript)
- Pattern chính: connected components bằng outer DFS
- Mức trong bank: CORE / representative

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

`computers[i][j]` cho biết kết nối trực tiếp giữa hai máy trong graph vô hướng. Hai máy cùng network nếu nối trực tiếp hoặc gián tiếp. Trả số connected components.

## 02. Bound

Input là adjacency matrix `n×n`, riêng đọc neighbor của mọi node đã có chi phí `O(n²)`. DFS/BFS trên matrix phù hợp.

## 03. Brute force

Với mỗi cặp node, tìm path để quyết định cùng nhóm rồi merge thủ công. Lặp reachability nhiều lần.

## 04. Bottleneck

Một traversal từ node chưa thăm đánh dấu toàn bộ component của nó. Sau đó không cần bắt đầu lại từ bất kỳ node nào trong component đó.

## 05. Pattern

Outer component loop:

```text
for every node:
  if unseen:
    components++
    DFS/BFS mark whole component
```

## 06. State

- `visited[n]`;
- `networks`;
- stack node trong traversal hiện tại.

## 07. Transition

Khi gặp matrix entry 1 tới neighbor unseen, mark ngay và push. Self-edge bị bỏ vì node hiện tại đã visited.

## 08. Invariant

Sau mỗi traversal, toàn bộ và chỉ component chứa start đã visited. Trước mỗi outer index, `networks` bằng số component đã khám phá trong prefix start; một unseen start chứng minh có component mới.

## 09. Complexity

Time `O(n²)` do mỗi node visited quét một row matrix; space `O(n)`.

## 10. Pseudocode

```text
visited=false; count=0
for start 0..n-1:
  if visited continue
  count++; mark start; stack=[start]
  while stack:
    node=pop
    for neighbor:
      if connected and unseen: mark; push
return count
```

## 11. Code bước 1 — dựng state

```js
function traversalState(n,start) {
  const visited=Array(n).fill(false);
  visited[start]=true;
  return {visited,stack:[start]};
}
```

## 12. Code bước 2 — viết transition

```js
function connected(matrix,node,neighbor) {
  return matrix[node][neighbor]===1;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function unseenConnected(matrix,visited,node,neighbor) {
  return matrix[node][neighbor]===1 && !visited[neighbor];
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF037.js](../../../solutions/official/OF037.js).

```js
function networkCount(n, computers) {
  const visited = Array(n).fill(false);
  let networks = 0;

  for (let start = 0; start < n; start++) {
    if (visited[start]) continue;
    networks++;
    visited[start] = true;
    const stack = [start];

    while (stack.length > 0) {
      const node = stack.pop();
      for (let neighbor = 0; neighbor < n; neighbor++) {
        if (computers[node][neighbor] === 0 || visited[neighbor]) continue;
        visited[neighbor] = true;
        stack.push(neighbor);
      }
    }
  }

  return networks;
}
```

## 16. Edge cases

1. Một node.
2. Mọi node isolated: answer n.
3. Graph complete: answer 1.
4. Kết nối gián tiếp qua nhiều node.

## 17. Lỗi JavaScript thường gặp

- Chỉ đếm direct neighbor của node 0.
- Reset visited cho mỗi outer start.
- Mark lúc pop gây duplicate.
- Nhầm matrix row/column với list neighbor.

### Loop and condition derivation

- **Nhịp lặp:** `for start 0..n-1; unseen start mở một DFS/BFS.`. Đây là lý do code dùng block bắt đầu bởi `for (let start = 0; start < n; start++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “start đã visited; computers[node][neighbor] === 1 và neighbor unseen.”. Trong dry run `computers=[[1,1,0],[1,1,0],[0,0,1]]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (visited[start]) continue;`.
- **Tiến triển:** outer start tăng; inner lấy pending node và quét row matrix.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `tăng networkCount đúng lúc tìm root unseen; mark trước push.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let start = 0; start < n; start++) {`.
- **Cleanup:** không reset visited giữa components; queue chỉ reset cho root mới.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Mạng lưới:** Condition của scan/simulation phải theo đúng tie-break và thứ tự rule của đề. So sánh strict hay non-strict chỉ đổi khi boundary/tie của bài chứng minh, không vì thói quen viết comparator.

### Complexity proof from movements

Time `O(n²)` do mỗi node visited quét một row matrix; space `O(n)`.

**Proof từ operation của Mạng lưới:** Tách chi phí chuẩn bị (nếu có sort) khỏi traversal. Trong traversal, mỗi item/candidate được xét đúng số lần mô tả bởi loop; không nhân các loop nối tiếp thành tích. Main loop được mô tả là `for start 0..n-1; unseen start mở một DFS/BFS.`; movement là `outer start tăng; inner lấy pending node và quét row matrix.`. Vì vậy phải cộng chi phí các phase nối tiếp và chỉ nhân khi một phase thật sự chạy trọn bên trong mỗi lượt ngoài. Auxiliary space chính là state `visited và networkCount.`, không tính output nếu convention của bài tách output.

#### 19. Làm bằng tay và brute force executable

Với matrix `[[1,1,0],[1,1,0],[0,0,1]]`, outer loop tại 0 đánh dấu `{0,1}` và tăng count một
lần; start 1 bị skip; start 2 mở component thứ hai.

```js
function networkCountBrute(n, computers) {
  const reachable = computers.map((row) => row.slice());
  for (let middle = 0; middle < n; middle += 1) {
    for (let from = 0; from < n; from += 1) {
      for (let to = 0; to < n; to += 1) {
        if (reachable[from][middle] && reachable[middle][to]) {
          reachable[from][to] = 1;
        }
      }
    }
  }

  const representatives = new Set();
  for (let node = 0; node < n; node += 1) {
    const firstReachable = reachable[node].findIndex(Boolean);
    representatives.add(firstReachable);
  }
  return representatives.size;
}
```

Closure `O(n³)` là đối chứng; outer traversal đạt lower bound `O(n²)` của adjacency matrix.
