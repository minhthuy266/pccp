# OF035 — Trộm cắp

- Nguồn đề: [Programmers lesson 42897](https://school.programmers.co.kr/learn/courses/30/lessons/42897?language=javascript)
- Pattern chính: circular house-robber DP
- Mức trong bank: STRETCH / advanced

## 01. Contract

Nhà xếp vòng tròn; không được lấy hai nhà kề nhau. Tối đa hóa tổng tiền.

## 02. Bound

Subset brute force exponential. Linear house-robber DP `O(n)`; vòng tròn tách hai case.

## 03. Brute force

Với mỗi nhà chọn/bỏ rồi kiểm adjacency và cặp đầu-cuối; `2^n`.

## 04. Bottleneck

Chỉ conflict đầu-cuối phá linear DP. Mọi solution hợp lệ hoặc bỏ nhà cuối, hoặc bỏ nhà đầu; lấy max hai interval.

## 05. Pattern

Linear recurrence `dp[i]=max(dp[i-1],dp[i-2]+money[i])`; chạy `[0,n-1)` và `[1,n)`.

## 06. State

`twoBack`, `oneBack`, current; hai case interval.

## 07. Transition

Current=max(skip current, take current + twoBack); shift rolling state.

## 08. Invariant

Sau index i, oneBack là optimum prefix tới i và twoBack optimum tới i-1. Hai circular cases cover mọi solution mà không cho chọn đồng thời đầu/cuối.

## 09. Complexity

Time `O(n)`, space `O(1)`.

## 10. Pseudocode

```text
linear(start,end): rolling robber DP
if n==1 return money[0]
return max(linear(0,n-1),linear(1,n))
```

## 11. Code bước 1 — dựng state

```js

```

## 12. Code bước 2 — viết transition

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF035.js](../../../solutions/official/OF035.js).

```js
function robLinear(money, start, endExclusive) {
  let twoBack = 0;
  let oneBack = 0;
  for (let index = start; index < endExclusive; index++) {
    const current = Math.max(oneBack, twoBack + money[index]);
    twoBack = oneBack;
    oneBack = current;
  }
  return oneBack;
}

function maximumCircularRobbery(money) {
  if (money.length === 1) {
    return money[0];
  }
  return Math.max(
    robLinear(money, 0, money.length - 1),
    robLinear(money, 1, money.length),
  );
}
```

## 19. Làm bằng tay và brute force executable

Với `[10,1,1,10]`, linear DP trên toàn array có thể chọn hai số 10, nhưng trong vòng chúng kề
nhau. Tách “bỏ cuối” và “bỏ đầu” đều cho 11; maximum hợp lệ là 11.

```js
function maximumCircularRobberyBrute(money) {
  let best = 0;
  const subsets = 1 << money.length;

  for (let mask = 0; mask < subsets; mask += 1) {
    let total = 0;
    let valid = true;
    for (let index = 0; index < money.length; index += 1) {
      if ((mask & (1 << index)) === 0) continue;
      const next = (index + 1) % money.length;
      if ((mask & (1 << next)) !== 0) {
        valid = false;
        break;
      }
      total += money[index];
    }
    if (valid) best = Math.max(best, total);
  }
  return best;
}
```

Brute thử `2^n` subset. Hai linear DP cover toàn bộ solution vòng trong `O(n)`.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `twoBack` | optimum kết thúc trước index liền trước | `0` |
| `oneBack` | optimum prefix trước current | `0` |
| `current` | max giữa skip và take | `max(oneBack, twoBack+money[i])` |
| hai interval | bỏ endpoint gây conflict | `[0,n-1)`, `[1,n)` |

## 21. Blueprint từ đề đến code

1. Giải bài linear bằng recurrence take/skip với rolling state.
2. Nhận ra chỉ có một cạnh vòng đặc biệt: nhà đầu kề nhà cuối.
3. Mọi solution hợp lệ phải bỏ ít nhất một trong hai endpoint.
4. Chạy linear cho case bỏ cuối và case bỏ đầu.
5. Lấy max hai case; xử lý n=1 riêng vì hai interval sẽ rỗng/lệch.

## 22. Invariant, lỗi lộ diện và recall

Trong `robLinear`, `oneBack` là optimum của prefix đã xử lý và `twoBack` là optimum trước phần tử
liền trước. Hai circular cases phủ mọi solution hợp lệ; solution bỏ cả hai xuất hiện ở cả hai nhưng
duplicate không ảnh hưởng phép max.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| chạy linear toàn vòng | `[10,1,1,10]` | 11 |
| quên n=1 | `[5]` | 5 |
| end inclusive sai | optimum ở nhà cuối | case bỏ đầu phải chứa cuối |
| cập nhật rolling sai thứ tự | `[1,2,3,1]` | 4 |

Recall: **linear DP + conflict đầu-cuối ⇒ tách hai case loại endpoint, rồi lấy max.**

## A17. Blueprint đủ trường và Recall ba tầng

```text
OUTPUT: số tiền lớn nhất khi nhà đầu và cuối kề nhau.
PREPARE: viết helper linearRobbery(start,endExclusive).
GLOBAL STATE: hai kết quả case bỏ cuối và bỏ đầu.
INIT: helper dùng skip=0,take=0; n=1 trả money[0].
MAIN LOOP: helper quét từng house trong interval tuyến tính.
CURRENT ITEM: currentMoney.
PER-ITERATION STATE: nextTake=skip+money và nextSkip=max(skip,take).
CHECK: không chọn hai nhà adjacent được biểu diễn bởi take chỉ cộng từ skip cũ.
BRANCH: bài vòng chạy hai case; helper không cần branch.
UPDATE: gán take=nextTake và skip=nextSkip sau khi tính cả hai từ state cũ.
POINTER MOVEMENT: index tăng trong từng interval; hai case cover mọi solution hợp lệ.
STOP / RETURN: helper trả max; hàm chính trả max(caseWithoutLast,caseWithoutFirst).
CLEANUP: xử lý n=1 riêng để không tạo hai interval rỗng.
```

- Recall 1: Giải linear bằng take/skip; vòng tròn tách case bỏ cuối và bỏ đầu rồi lấy max.
- Recall 2: STATE take/skip → LOOP interval → CHECK adjacency via old skip → UPDATE next states → RETURN max two cases.
- Recall 3: Điền `nextTake = skip + ___`; `nextSkip = Math.max(___, ___)`.
