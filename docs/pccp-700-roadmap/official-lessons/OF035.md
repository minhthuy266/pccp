# OF035 — Trộm cắp

- Nguồn đề: [Programmers lesson 42897](https://school.programmers.co.kr/learn/courses/30/lessons/42897?language=javascript)
- Pattern chính: circular house-robber DP
- Mức trong bank: STRETCH / advanced

## 01. Contract

Nhà xếp vòng tròn; không được lấy hai nhà kề nhau. Tối đa hóa tổng tiền.

## 02. Bound

Subset brute force exponential. Linear house-robber DP `O(n)`; vòng tròn tách hai case.

## 03. Brute force

Với mỗi nhà chọn/bỏ rồi kiểm adjacency và cặp đầu-cuối; `2^n`.

## 04. Bottleneck

Chỉ conflict đầu-cuối phá linear DP. Mọi solution hợp lệ hoặc bỏ nhà cuối, hoặc bỏ nhà đầu; lấy max hai interval.

## 05. Pattern

Linear recurrence `dp[i]=max(dp[i-1],dp[i-2]+money[i])`; chạy `[0,n-1)` và `[1,n)`.

## 06. State

`twoBack`, `oneBack`, current; hai case interval.

## 07. Transition

Current=max(skip current, take current + twoBack); shift rolling state.

## 08. Invariant

Sau index i, oneBack là optimum prefix tới i và twoBack optimum tới i-1. Hai circular cases cover mọi solution mà không cho chọn đồng thời đầu/cuối.

## 09. Complexity

Time `O(n)`, space `O(1)`.

## 10. Pseudocode

```text
linear(start,end): rolling robber DP
if n==1 return money[0]
return max(linear(0,n-1),linear(1,n))
```

## 11. Code bước 1 — dựng state

```js
let twoBack=0,oneBack=0;
```

## 12. Code bước 2 — viết transition

```js
const current=Math.max(oneBack,twoBack+money[index]);
twoBack=oneBack; oneBack=current;
```

## 13. Code bước 3 — ghép vòng lặp

```js
function solveCircle(money) {
  return Math.max(robLinear(money,0,money.length-1),robLinear(money,1,money.length));
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF035.js](../../../solutions/official/OF035.js).

```js
function robLinear(money, start, endExclusive) {
  let twoBack = 0;
  let oneBack = 0;
  for (let index = start; index < endExclusive; index++) {
    const current = Math.max(oneBack, twoBack + money[index]);
    twoBack = oneBack;
    oneBack = current;
  }
  return oneBack;
}

function maximumCircularRobbery(money) {
  if (money.length === 1) {
    return money[0];
  }
  return Math.max(
    robLinear(money, 0, money.length - 1),
    robLinear(money, 1, money.length),
  );
}
```

### Loop and condition derivation

- **Nhịp lặp:** `helper quét từng house trong interval tuyến tính.`. Đây là lý do code dùng block bắt đầu bởi `if (money.length === 1) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “không chọn hai nhà adjacent được biểu diễn bởi take chỉ cộng từ skip cũ.”. Trong dry run `[10,1,1,10]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (money.length === 1) {`.
- **Tiến triển:** index tăng trong từng interval; hai case cover mọi solution hợp lệ.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `gán take=nextTake và skip=nextSkip sau khi tính cả hai từ state cũ.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `if (money.length === 1) {`.
- **Cleanup:** xử lý n=1 riêng để không tạo hai interval rỗng.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Trộm cắp:** Base state phải khớp định nghĩa DP; thứ tự loop phải bảo đảm dependency đã tính. Branch không hợp lệ không được ghi đè sentinel hoặc state tốt hơn đã có.

### Complexity proof from movements

Time `O(n)`, space `O(1)`.

**Proof từ operation của Trộm cắp:** Đếm số DP state được tính và số transition đọc cho mỗi state. Mỗi state chỉ được chốt theo recurrence một lần; tổng thời gian bằng số state nhân số lựa chọn/dependency thực sự xét. Main loop được mô tả là `helper quét từng house trong interval tuyến tính.`; movement là `index tăng trong từng interval; hai case cover mọi solution hợp lệ.`. Vì vậy phải cộng chi phí các phase nối tiếp và chỉ nhân khi một phase thật sự chạy trọn bên trong mỗi lượt ngoài. Auxiliary space chính là state `hai kết quả case bỏ cuối và bỏ đầu.`, không tính output nếu convention của bài tách output.

#### 19. Làm bằng tay và brute force executable

Với `[10,1,1,10]`, linear DP trên toàn array có thể chọn hai số 10, nhưng trong vòng chúng kề
nhau. Tách “bỏ cuối” và “bỏ đầu” đều cho 11; maximum hợp lệ là 11.

```js
function maximumCircularRobberyBrute(money) {
  let best = 0;
  const subsets = 1 << money.length;

  for (let mask = 0; mask < subsets; mask += 1) {
    let total = 0;
    let valid = true;
    for (let index = 0; index < money.length; index += 1) {
      if ((mask & (1 << index)) === 0) continue;
      const next = (index + 1) % money.length;
      if ((mask & (1 << next)) !== 0) {
        valid = false;
        break;
      }
      total += money[index];
    }
    if (valid) best = Math.max(best, total);
  }
  return best;
}
```

Brute thử `2^n` subset. Hai linear DP cover toàn bộ solution vòng trong `O(n)`.
