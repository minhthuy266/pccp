# OF061 — Số lớn hơn phía sau

- Nguồn đề: [Programmers lesson 154539](https://school.programmers.co.kr/learn/courses/30/lessons/154539?language=javascript)
- Pattern chính: monotonic stack index unresolved
- Mức trong bank: TRANSFER / monotonic stack

## 01. Contract

Với mỗi phần tử, tìm giá trị lớn hơn đầu tiên bên phải; không có trả `-1`. Giá bằng nhau không lớn hơn.

## 02. Bound

Nested scan `O(n²)`; monotonic stack `O(n)`.

## 03. Brute force

Cho mỗi i scan j>i tới first greater.

## 04. Bottleneck

Current có thể giải quyết nhiều index trước chưa gặp greater. Giữ các index unresolved trong stack.

## 05. Pattern

Trong khi value top `< current`, pop và answer[top]=current; push current index. Stack values non-increasing.

## 06. State

Answer default -1, stack index, current index.

## 07. Transition

While strict smaller pop; equal ở lại; push current.

## 08. Invariant

Stack chứa đúng index chưa có next greater trong prefix, values không tăng từ đáy lên đỉnh. Current là greater đầu tiên cho mọi index bị pop vì không current sớm hơn đã pop chúng.

## 09. Complexity

Mỗi index push/pop tối đa một: `O(n)` time, `O(n)` space.

## 10. Pseudocode

```text
answer=-1; stack=[]
for current:
  while stack and numbers[top]<numbers[current]: answer[pop]=numbers[current]
  push current
return answer
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF061.js](../../../solutions/official/OF061.js).

```js
function nextGreaterValues(numbers) {
  const answer = Array(numbers.length).fill(-1);
  const unresolvedIndices = [];

  for (let currentIndex = 0; currentIndex < numbers.length; currentIndex++) {
    const currentValue = numbers[currentIndex];

    while (unresolvedIndices.length > 0) {
      const previousIndex = unresolvedIndices.at(-1);
      const previousValue = numbers[previousIndex];
      if (previousValue >= currentValue) break;

      unresolvedIndices.pop();
      answer[previousIndex] = currentValue;
    }

    unresolvedIndices.push(currentIndex);
  }

  return answer;
}
```

### Loop and condition derivation

- **Nhịp lặp:** `for currentIndex`. Đây là lý do code dùng block bắt đầu bởi `for (let currentIndex = 0; currentIndex < numbers.length; currentIndex++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “stack rỗng? previousValue < currentValue?”. Trong dry run `[2,3,3,5]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (previousValue >= currentValue) break;`.
- **Tiến triển:** for tăng currentIndex; stack pop nhiều nhưng mỗi index tối đa một lần. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `answer[previousIndex]=currentValue; sau while push currentIndex` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let currentIndex = 0; currentIndex < numbers.length; currentIndex++) {`.
- **Cleanup:** không, survivor giữ -1; RETURN: answer. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Số lớn hơn phía sau:** Guard cấu trúc không rỗng phải đứng trước mọi lần đọc top/front. Equality có pop hay không, và visited được mark lúc enqueue hay dequeue, lấy đúng từ invariant của bài này.

### Complexity proof from movements

Mỗi index push/pop tối đa một: `O(n)` time, `O(n)` space.

**Proof từ operation của Số lớn hơn phía sau:** Đếm số lần một item vào và rời cấu trúc: mỗi item chỉ được push/enqueue theo transition của bài và chỉ được pop/dequeue khi đã hoàn tất vai trò. Nested while không tự động là bình phương nếu item đã rời không quay lại. Main loop được mô tả là `for currentIndex`; movement là `for tăng currentIndex; stack pop nhiều nhưng mỗi index tối đa một lần`. Vì vậy phải cộng chi phí các phase nối tiếp và chỉ nhân khi một phase thật sự chạy trọn bên trong mỗi lượt ngoài. Auxiliary space chính là state `answer,unresolvedIndices`, không tính output nếu convention của bài tách output.

#### 19. Từ quét suffix đến stack các câu hỏi đang chờ

##### Làm bằng tay và brute force

Với `[2,3,3,5]`, đứng ở mỗi index rồi nhìn sang phải đến khi gặp value lớn hơn đầu tiên:
2 gặp 3; cả hai số 3 không giải quyết nhau vì bằng nhau; cả hai cùng gặp 5. Phần tử 5 không
có đáp án nên giữ default `-1`.

```js
function nextGreaterValuesBruteForce(numbers) {
  const answer = Array(numbers.length).fill(-1);
  for (let startIndex = 0; startIndex < numbers.length; startIndex++) {
    for (let candidateIndex = startIndex + 1; candidateIndex < numbers.length; candidateIndex++) {
      const candidateValue = numbers[candidateIndex];
      if (candidateValue > numbers[startIndex]) {
        answer[startIndex] = candidateValue;
        break;
      }
    }
  }
  return answer;
}
```

Brute force đúng vì candidate được thử từ gần đến xa, nhưng dãy giảm làm mọi suffix bị quét
đến hết: `O(n²)`. Đảo góc nhìn: current có thể trả lời nhiều index cũ đang chờ.

##### State, transition và invariant

| State | Kiểu | Lưu chính xác gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `answer` | number[] | next greater value hoặc -1 | fill `-1` cho survivor | output |
| `unresolvedIndices` | number[] | index chưa gặp greater | `[]` | xuyên loop |
| `currentIndex`,`currentValue` | number | vị trí/value đang đọc | từ for | iteration |
| `previousIndex`,`previousValue` | number | top đang được current xét | từ stack | mỗi vòng while |

Một current có thể giải quyết nhiều top nên dùng `while` trong `for`. Nếu top value nhỏ hơn
current: pop index rồi gán `answer[previousIndex] = currentValue`. Nếu top lớn hơn **hoặc bằng**,
dừng while. Sau cùng push current để nó chờ một value lớn hơn ở tương lai.

Trước current, stack chứa đúng index chưa có next greater trong prefix; values không tăng từ
đáy lên đỉnh. Khi pop, current là greater đầu tiên vì mọi value ở giữa đã được đọc mà không pop
index đó. Equal phải ở lại nên condition là `<`, không phải `<=`.

```text
OUTPUT: answer; PREPARE: default -1; GLOBAL STATE: answer,unresolvedIndices
INIT: Array(n).fill(-1), []; MAIN LOOP: for currentIndex
CURRENT ITEM: currentValue; PER-ITERATION STATE: previousIndex,previousValue
CHECK: stack rỗng? previousValue < currentValue?
BRANCH: while nhỏ hơn → pop+ghi answer; >= → break
UPDATE: answer[previousIndex]=currentValue; sau while push currentIndex
POINTER MOVEMENT: for tăng currentIndex; stack pop nhiều nhưng mỗi index tối đa một lần
STOP / RETURN: hết input; CLEANUP: không, survivor giữ -1; RETURN: answer
```

| Current | Stack trước (value) | Pop/update | Stack sau | Answer |
| --- | --- | --- | --- | --- |
| 2 | `[]` | không | `[2]` | `[-1,-1,-1,-1]` |
| 3 đầu | `[2]` | pop 2 → 3 | `[3]` | `[3,-1,-1,-1]` |
| 3 sau | `[3]` | equal, không pop | `[3,3]` | không đổi |
| 5 | `[3,3]` | pop hai lần → 5 | `[5]` | `[3,5,5,-1]` |

Mỗi index push đúng một và pop tối đa một nên tổng số vòng while là `O(n)`, dù while nằm
trong for. Time `O(n)`, stack và answer `O(n)`.

- Logic: lưu value thay index rồi không biết ghi answer ở đâu.
- Off-by-one: scan brute từ chính start; phần tử tự so với nó.
- Check/update: push current trước resolve; current có thể chặn stack.
- Init: fill `0`; survivor phải là `-1`.
- Hidden: equal không greater; `[3,3] → [-1,-1]`.
- Performance/correctness: dùng `if` lộ `[2,1,3]`, vì 3 phải pop cả 1 và 2.

```text
Recall 1: stack giữ index đang hỏi; current lớn hơn top thì trả lời top; pop hết rồi push current.
Recall 2: STATE answer/stack; LOOP for+while; CHECK top<current; UPDATE pop+value; RETURN.
Recall 3: while (stack.length > 0) { const previous=stack.at(-1); if (numbers[previous] ____ current) break; ____; answer[previous]=____; }
OUT: next greater values; LIMIT: O(n); HAND: current trả lời ai; BRUTE: scan suffix
SLOW: suffix lặp; PATTERN: monotonic unresolved stack; STATE + INIT: answer=-1,stack=[]
LOOP + INVARIANT: stack chưa có greater; UPDATE + STOP: pop strict smaller, push current
```
