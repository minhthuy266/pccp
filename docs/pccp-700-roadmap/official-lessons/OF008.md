## 01. Contract

String chỉ gồm `(` và `)`. Hợp lệ khi mọi dấu đóng ghép được với một dấu mở trước nó và cuối cùng không còn dấu mở.

## 02. Bound

Một scan `O(n)`; chỉ một loại ngoặc nên stack có thể nén thành counter.

## 03. Brute force

Lặp replace `()` đến khi không đổi rồi kiểm rỗng; tạo string mới nhiều lần, có thể quadratic.

## 04. Bottleneck

Ta chỉ cần số opening chưa đóng, không cần vị trí/type vì chỉ có một loại.

## 05. Pattern

`(` tăng balance, `)` giảm. Prefix balance âm ⇒ close không có opening; cuối balance phải 0.

## 06. State

`balance` = số opening chưa ghép trong prefix.

## 07. Transition

Open `+1`, close `-1`; return false ngay khi âm; cuối `balance===0`.

## 08. Invariant

Sau prefix, balance = opens - closes của prefix và nếu chưa return thì không prefix nào âm. Đây chính là số opening chưa đóng.

## 09. Complexity

Time `O(n)`, space `O(1)`.

## 10. Pseudocode

```text
balance=0
for char:
  open? balance++ : balance--
  if balance<0 return false
return balance==0
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF008.js](../../../solutions/official/OF008.js).

```js
function isValidParentheses(string) {
  let balance = 0;
  for (const character of string) {
    if (character === "(") {
      balance += 1;
    } else {
      balance -= 1;
    }
    if (balance < 0) {
      return false;
    }
  }
  return balance === 0;
}
```

### Loop and condition derivation

- **Nhịp lặp:** `for từng character vì phải đọc mỗi vị trí đúng một lần`. Đây là lý do code dùng block bắt đầu bởi `for (const character of string) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “character là mở hay đóng; sau update balance có âm không”. Trong dry run `)()(`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (character === "(") {`.
- **Tiến triển:** for...of chuyển sang ký tự kế. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `balance = balance ± 1` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (const character of string) {`.
- **Cleanup:** check opening còn tồn đọng bằng balance cuối. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Dấu ngoặc đúng:** Guard cấu trúc không rỗng phải đứng trước mọi lần đọc top/front. Equality có pop hay không, và visited được mark lúc enqueue hay dequeue, lấy đúng từ invariant của bài này.

### Complexity proof from movements

Time `O(n)`, space `O(1)`.

**Proof từ operation của Dấu ngoặc đúng:** Đếm số lần một item vào và rời cấu trúc: mỗi item chỉ được push/enqueue theo transition của bài và chỉ được pop/dequeue khi đã hoàn tất vai trò. Nested while không tự động là bình phương nếu item đã rời không quay lại. Main loop được mô tả là `for từng character vì phải đọc mỗi vị trí đúng một lần`; movement là `for...of chuyển sang ký tự kế`. Vì vậy phải cộng chi phí các phase nối tiếp và chỉ nhân khi một phase thật sự chạy trọn bên trong mỗi lượt ngoài. Auxiliary space chính là state `balance`, không tính output nếu convention của bài tách output.

Với `(()())`, đi từ trái sang phải và ghi số dấu mở chưa được ghép: `1,2,1,2,1,0`.
Với `)(`, ngay ký tự đầu đã cần một dấu mở nằm bên trái nhưng không có, nên dừng và kết luận
sai; chỉ so tổng số mở/đóng sẽ bỏ lỡ lỗi prefix này.

```js
function isValidParenthesesBruteForce(string) {
  let reduced = string;
  while (reduced.includes("()")) {
    reduced = reduced.replaceAll("()", "");
  }
  return reduced.length === 0;
}
```

Mỗi vòng tạo string mới và có thể chỉ xóa một lớp lồng, nên input dạng nhiều lớp có thể tốn
`O(n²)` time và `O(n)` temporary space. Counter là bản nén hợp lệ của stack vì mọi opening
đều cùng một loại; với `()[]{}` không được nén như vậy vì còn phải nhớ **loại** ở đỉnh stack.

| State | Kiểu dữ liệu | Lưu chính xác cái gì | Tại sao cần | Giá trị ban đầu | Vì sao init như vậy | Scope |
| --- | --- | --- | --- | --- | --- | --- |
| `balance` | number | số `(` trong prefix chưa ghép | tương lai cần biết có opening để đóng | `0` | prefix rỗng chưa chờ gì | xuyên loop |
| `character` | string | ký tự đang đọc | quyết định transition `+1/-1` | từ `for...of` | mỗi lượt đọc lại | iteration |

```text
OUTPUT: boolean
PREPARE: không có
GLOBAL STATE: balance
INIT: balance = 0
MAIN LOOP: for từng character vì phải đọc mỗi vị trí đúng một lần
CURRENT ITEM: character
PER-ITERATION STATE: không có
CHECK: character là mở hay đóng; sau update balance có âm không
BRANCH: mở thì +1, đóng thì -1; âm thì return false
UPDATE: balance = balance ± 1
POINTER MOVEMENT: for...of chuyển sang ký tự kế
STOP / RETURN: fail sớm khi âm; cuối trả balance === 0
CLEANUP: check opening còn tồn đọng bằng balance cuối
```

`Contract → boolean`; `State → let balance`; `một lượt → for...of`; `Invariant → check âm`;
`Transition → if mở/else đóng`; `Stop → return false`; `state tồn đọng → balance === 0`.

| Current | Balance trước | Update | Balance sau | Kết quả |
| --- | ---: | --- | ---: | --- |
| `)` trong `)(` | 0 | `-1` | -1 | return false |
| `(` trong `(()` | 0 | `+1` | 1 | tiếp tục |
| hết `(()` | 1 | cleanup | 1 | false |

##### Lỗi làm lộ bằng test nhỏ

- Logic: chỉ so tổng count; `)(` làm lộ lỗi.
- Off-by-one: bỏ ký tự cuối; `(` làm lộ lỗi.
- Check/update: check âm trước khi trừ; `)` làm lộ lỗi.
- Init: `balance = 1`; chuỗi `()` bị báo sai.
- Hidden test: opening dư; `(()` phải false.
- Performance: replace lặp; chuỗi `"(".repeat(50000) + ")".repeat(50000)` làm lộ chi phí.
