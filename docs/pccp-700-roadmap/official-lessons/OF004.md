# OF004 — Trang phục

- Nguồn đề: [Programmers lesson 42578](https://school.programmers.co.kr/learn/courses/30/lessons/42578?language=javascript)
- Pattern chính: group count + product rule
- Mức trong bank: CORE / representative

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Mỗi item gồm `[itemName, category]`. Trong một outfit, mỗi category được chọn tối đa một item; có thể không chọn category đó. Outfit phải có ít nhất một item. Trả tổng số outfit khác nhau.

Tên item chỉ định danh; để đếm, thông tin quan trọng là mỗi category có bao nhiêu item.

## 02. Bound

Số item nhỏ, nhưng brute force mọi subset vẫn là `2^n`. Vì constraint lựa chọn tách độc lập theo category, có thể đếm bằng quy tắc nhân trong `O(n)`.

## 03. Brute force

Sinh mọi subset item, loại subset rỗng và subset chứa từ hai item cùng category, rồi đếm phần còn lại.

Brute force lặp lại cùng một quyết định category dưới vô số tổ hợp item cụ thể.

## 04. Bottleneck

Với category có `c` item, ta có đúng `c + 1` lựa chọn hợp lệ:

- không dùng category;
- hoặc dùng đúng một trong `c` item.

Các category độc lập nên nhân số lựa chọn. Tích này chứa một trường hợp không chọn gì ở mọi category, phải trừ `1`.

## 05. Pattern

Pattern `group → count choices → product → remove invalid empty case`:

```text
count item per category
answerIncludingEmpty = product(count + 1)
answer = answerIncludingEmpty - 1
```

## 06. State

- `countByCategory: Map<string, number>`;
- `combinationsIncludingEmpty`, khởi tạo `1` vì đây là tích.

Không cần lưu danh sách tên item trong từng category vì output chỉ phụ thuộc count.

## 07. Transition

- Với item thuộc `category`: tăng count category một.
- Với category có `count`: nhân accumulator với `count + 1`.
- Sau cùng trừ một outfit rỗng.

## 08. Invariant

Sau khi đọc prefix clothes, Map chứa đúng số item đã thấy theo từng category.

Trong vòng nhân, sau khi xử lý `k` category, accumulator bằng số cách lựa chọn hợp lệ từ đúng `k` category đó, **bao gồm** cách không chọn item nào. Quy tắc nhân đúng vì quyết định ở mỗi category độc lập.

## 09. Complexity

- Time trung bình: `O(n)`.
- Space: `O(c)` với `c` category.
- Không enumerate outfit.

## 10. Pseudocode

```text
counts = empty map
for [name, category] in clothes:
    counts[category] += 1
ways = 1
for count in counts.values:
    ways *= count + 1
return ways - 1
```

## 11. Code bước 1 — dựng state

```js
function countCategories(clothes) {
  const countByCategory = new Map();
  for (const [, category] of clothes) {
    countByCategory.set(category, (countByCategory.get(category) ?? 0) + 1);
  }
  return countByCategory;
}
```

Destructure bỏ `itemName` bằng dấu phẩy đầu vì tên không ảnh hưởng phép đếm.

## 12. Code bước 2 — viết transition

```js
function countIncludingEmpty(countByCategory) {
  let ways = 1;
  for (const itemCount of countByCategory.values()) {
    ways *= itemCount + 1;
  }
  return ways;
}
```

Accumulator phải bắt đầu bằng `1`; bắt đầu `0` sẽ làm mọi phép nhân sau vẫn bằng `0`.

## 13. Code bước 3 — ghép vòng lặp

```js
function clothingCombinationsStep3(clothes) {
  const counts = countCategories(clothes);
  const includingEmpty = countIncludingEmpty(counts);
  return includingEmpty - 1;
}
```

Chỉ trừ một lần sau khi nhân xong, vì chỉ có đúng một global empty outfit.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF004.js](../../../solutions/official/OF004.js).

```js
function clothingCombinations(clothes) {
  const countByCategory = new Map();
  for (const [, category] of clothes) {
    countByCategory.set(category, (countByCategory.get(category) ?? 0) + 1);
  }

  let combinationsIncludingEmpty = 1;
  for (const itemCount of countByCategory.values()) {
    combinationsIncludingEmpty *= itemCount + 1;
  }
  return combinationsIncludingEmpty - 1;
}
```

|---|---:|---:|
| headgear | 2 | 3 |
| eyewear | 1 | 2 |

Tích `3 * 2 = 6` chứa outfit không mặc gì. Kết quả `6 - 1 = 5`.

## 16. Edge cases

1. Chỉ một item: `(1 + 1) - 1 = 1`.
2. Mọi item cùng category: chỉ chọn được một trong chúng, answer bằng số item.
3. Mỗi item thuộc category khác: mỗi category chọn/không chọn, answer `2^n - 1`.
4. Category name khác nhau dù item name tương tự; group theo category, không group theo item name.

## 17. Lỗi JavaScript thường gặp

- Cộng count các category thay vì nhân choices.
- Nhân `count` thay vì `count + 1`, làm mất lựa chọn không dùng category.
- Quên `-1`, vô tình tính outfit rỗng.
- Khởi tạo tích bằng `0`.
- Group theo `itemName` thay vì `category`.
- Dùng `for...in` trên Map; phải dùng `for...of countByCategory.values()`.

## 18. Bài transfer cùng pattern

- OF001: cùng là Map count nhưng dùng multiset subtraction, không dùng product rule.
- OF005: group theo genre nhưng phải giữ thêm tổng score và top item có tie-break.
- OF052: count theo loại trong cửa sổ, state phải tăng và giảm động.

Tín hiệu: chọn tối đa một item từ mỗi nhóm độc lập và có thể bỏ nhóm ⇒ mỗi nhóm có `count + 1` choices, nhân rồi loại all-none.

### Loop and condition derivation

- **Nhịp lặp:** `vòng đếm clothes, rồi vòng nhân các category.`. Đây là lý do code dùng block bắt đầu bởi `for (const itemCount of countByCategory.values()) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “không cần kiểm item name; mọi item thuộc đúng một category.”. Trong dry run `3 * 2 = 6`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `const countByCategory = new Map();`.
- **Tiến triển:** for...of sang item/category tiếp theo.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `set oldCount+1; sau đó multiply itemCount+1.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (const itemCount of countByCategory.values()) {`.
- **Cleanup:** trừ đúng một global empty outfit, không trừ theo category.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Trang phục:** Với Map/Set, phải phân biệt key chưa tồn tại với count bằng 0 và membership với multiplicity. Default, increment, decrement hoặc delete chỉ xuất hiện nếu contract của bài cần đúng transition đó.

#### 20. Brute force đầy đủ và dry-run

```js
function clothingCombinationsBrute(clothes) {
  let validOutfitCount = 0;

  function choose(index, usedCategories, selectedCount) {
    if (index === clothes.length) {
      if (selectedCount > 0) validOutfitCount++;
      return;
    }

    choose(index + 1, usedCategories, selectedCount);

    const category = clothes[index][1];
    if (!usedCategories.has(category)) {
      usedCategories.add(category);
      choose(index + 1, usedCategories, selectedCount + 1);
      usedCategories.delete(category);
    }
  }

  choose(0, new Set(), 0);
  return validOutfitCount;
}
```

Với hai mũ và một kính, cây chọn/bỏ có tám lá thô; hai lá chọn cả hai mũ bị chặn và lá
rỗng không được đếm, còn năm outfit. Brute đúng vì duyệt mọi subset hợp lệ, nhưng cây có
`O(2^n)` node. Product rule gộp mọi nhánh có cùng quyết định category.
