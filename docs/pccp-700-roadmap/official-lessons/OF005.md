Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Chọn tối đa hai bài mỗi genre. Genre có tổng plays lớn hơn xuất trước; trong genre, bài plays lớn hơn trước; hòa plays lấy original index nhỏ hơn. Trả index theo order đó.

## 02. Bound

Group một lần `O(n)`, sort genres và songs `O(n log n)` đủ. Quan trọng là giữ metadata phục vụ ba tầng order.

## 03. Brute force

Mỗi lần chọn bài kế tiếp, scan toàn input tính lại genre totals và candidate; lặp logic grouping.

## 04. Bottleneck

Output order gồm group-level key và item-level key. Cần tách state: `totalByGenre` và list `{index,plays}` theo genre.

## 05. Pattern

Group → aggregate → sort groups → sort items within group → take top 2.

## 06. State

- Map genre→total;
- Map genre→songs;
- ordered genres;
- answer indices.

## 07. Transition

Mỗi input tăng total và push song. Genre comparator total desc. Song comparator plays desc, index asc.

## 08. Invariant

Sau prefix input, totals bằng tổng plays chính xác và lists chứa đủ song kèm original index. Sau xử lý k genre sorted, answer chứa đúng top tối đa hai của k genre đầu theo mọi tie-break.

## 09. Complexity

Time `O(n log n)`, space `O(n)`.

## 10. Pseudocode

```text
group totals and songs
sort genre keys by total descending
for genre:
  sort songs by plays desc then index asc
  append first two indices
return answer
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF005.js](../../../solutions/official/OF005.js).

```js
function bestAlbumSongIndices(genres, plays) {
  const totalByGenre = new Map();
  const songsByGenre = new Map();

  for (let index = 0; index < genres.length; index++) {
    const genre = genres[index];
    const currentPlays = plays[index];
    const previousTotal = totalByGenre.get(genre) ?? 0;
    totalByGenre.set(genre, previousTotal + currentPlays);

    if (!songsByGenre.has(genre)) {
      songsByGenre.set(genre, []);
    }
    const genreSongs = songsByGenre.get(genre);
    genreSongs.push({ index, plays: currentPlays });
  }

  const orderedGenres = [...totalByGenre.keys()].sort(
    (first, second) => totalByGenre.get(second) - totalByGenre.get(first),
  );
  const answer = [];

  for (const genre of orderedGenres) {
    const genreSongs = songsByGenre.get(genre);
    genreSongs.sort((first, second) => {
      if (first.plays !== second.plays) {
        return second.plays - first.plays;
      }
      return first.index - second.index;
    });

    const selectedCount = Math.min(2, genreSongs.length);
    for (let rank = 0; rank < selectedCount; rank++) {
      answer.push(genreSongs[rank].index);
    }
  }

  return answer;
}
```

#### 19. Làm bằng tay trước khi code

Với genre `a` có các bài `(index, plays) = (0,10),(1,10)` và genre `b` có `(2,15)`,

#### 20. Brute force đầy đủ và dry-run

```js
function bestAlbumSongIndicesBrute(genres, plays) {
  const distinctGenres = [...new Set(genres)];

  function totalPlays(targetGenre) {
    let total = 0;
    for (let index = 0; index < genres.length; index++) {
      if (genres[index] === targetGenre) total += plays[index];
    }
    return total;
  }

  distinctGenres.sort((firstGenre, secondGenre) => {
    return totalPlays(secondGenre) - totalPlays(firstGenre);
  });

  const answer = [];
  for (const genre of distinctGenres) {
    const candidateIndices = [];
    for (let index = 0; index < genres.length; index++) {
      if (genres[index] === genre) candidateIndices.push(index);
    }
    candidateIndices.sort((firstIndex, secondIndex) => {
      if (plays[firstIndex] !== plays[secondIndex]) {
        return plays[secondIndex] - plays[firstIndex];
      }
      return firstIndex - secondIndex;
    });
    answer.push(...candidateIndices.slice(0, 2));
  }

  return answer;
}
```

Với ví dụ `a/a/b` ở trên, comparator genre gọi `totalPlays` nhiều lần; rồi mỗi genre lại
quét toàn input để gom bài. Code đúng vì trực tiếp áp cả ba tie-break, nhưng lặp lại aggregate
và grouping. Hai Map tính và lưu chúng đúng một lần trước khi sort.

#### 23. Invariant theo hai phase
