# OF040 — Nhặt vật phẩm

- Nguồn đề: [Programmers lesson 87694](https://school.programmers.co.kr/learn/courses/30/lessons/87694?language=javascript)
- Pattern chính: coordinate scaling + border BFS
- Mức trong bank: STRETCH / special modeling

## 01. Contract

Các rectangle tạo vùng; chỉ đi trên đường biên union từ nhân vật tới vật phẩm. Trả shortest distance.

## 02. Bound

Tọa độ nhỏ cho phép raster grid. Scale ×2 tránh hai cạnh/corner chạm nhau bị coi là đường tắt.

## 03. Brute force

Đi trên grid gốc đánh dấu border trực tiếp; sai topology ở corner và đoạn cạnh sát nhau.

## 04. Bottleneck

Mô hình tọa độ nguyên không biểu diễn midpoint/crossing. Nhân đôi tạo ô trung gian, sau đó fill rectangles và erase strict interiors để giữ đúng border union.

## 05. Pattern

Scale all coordinates; fill toàn rectangle=1; erase interior=0; BFS bốn hướng trên cell1; chia distance2.

## 06. State

Scaled board, distance, queue/head, scaled start/target.

## 07. Transition

Neighbor trong bounds, board=1, unseen; mark/enqueue.

## 08. Invariant

Sau fill-erase, cell1 đúng đường biên có thể đi của union. Scale bảo đảm các điểm giao hình học xuất hiện thành node/cạnh riêng; BFS lần đầu tới target là shortest scaled path.

## 09. Complexity

Với coordinate bound cố định, build/BFS `O(C²)`; space `O(C²)`.

## 10. Pseudocode

```text
scale x2
fill every rectangle including border
erase every strict interior
BFS border from character to item
return scaledDistance/2
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF040.js](../../../solutions/official/OF040.js).

```js
const BORDER_DIRECTIONS = [[-1, 0], [1, 0], [0, -1], [0, 1]];

function itemPickupDistance(rectangles, characterX, characterY, itemX, itemY) {
  const SIZE = 102;
  const board = Array.from({ length: SIZE }, () => new Uint8Array(SIZE));

  for (const [x1, y1, x2, y2] of rectangles) {
    for (let row = y1 * 2; row <= y2 * 2; row++) {
      for (let column = x1 * 2; column <= x2 * 2; column++) {
        board[row][column] = 1;
      }
    }
  }
  for (const [x1, y1, x2, y2] of rectangles) {
    for (let row = y1 * 2 + 1; row < y2 * 2; row++) {
      for (let column = x1 * 2 + 1; column < x2 * 2; column++) {
        board[row][column] = 0;
      }
    }
  }

  const start = [characterY * 2, characterX * 2];
  const targetRow = itemY * 2;
  const targetColumn = itemX * 2;
  const distance = Array.from({ length: SIZE }, () => new Int16Array(SIZE).fill(-1));
  const queue = [start];
  let head = 0;
  distance[start[0]][start[1]] = 0;

  while (head < queue.length) {
    const [row, column] = queue[head];
    head += 1;
    if (row === targetRow && column === targetColumn) {
      return distance[row][column] / 2;
    }
    for (const [deltaRow, deltaColumn] of BORDER_DIRECTIONS) {
      const nextRow = row + deltaRow;
      const nextColumn = column + deltaColumn;
      if (
        nextRow < 0 || nextRow >= SIZE || nextColumn < 0 || nextColumn >= SIZE ||
        board[nextRow][nextColumn] !== 1 || distance[nextRow][nextColumn] !== -1
      ) {
        continue;
      }
      distance[nextRow][nextColumn] = distance[row][column] + 1;
      queue.push([nextRow, nextColumn]);
    }
  }
  return -1;
}
```

## 15. Dry-run

Rectangle đơn từ `(1,1)` tới `(2,2)` thành square scaled cạnh2; hai corner đối diện cách4 half-steps, trả2.

## 16. Edge cases

Rectangles overlap; share border/corner; start-target cùng rectangle; inner area phải không đi được.

## 17. Lỗi JavaScript thường gặp

Không scale; erase interior trước khi fill rectangle khác rồi bị fill lại; đảo x/y; quên chia2; đi diagonal.

## 18. Bài transfer cùng pattern

- OF038: grid BFS không modeling.
- OF042: extract/canonicalize components.
- OF047: scale half-step để bắt crossing.

Tín hiệu: geometry trên tọa độ nguyên có corner/crossing mơ hồ ⇒ scale trước khi raster traversal.

## 19. Làm bằng tay và brute force executable

Với rectangle `(1,1)–(2,2)`, sau scale nó thành `(2,2)–(4,4)`. Hai corner đối diện cách 4
half-step trên border, nên đáp án thật là `4 / 2 = 2`. Nếu không scale, những rectangle chỉ chạm
corner có thể tạo một cạnh giả.

```js
function itemPickupDistanceUnscaledBrute(rectangle, start, target) {
  const [x1, y1, x2, y2] = rectangle;
  const border = new Set();
  for (let x = x1; x <= x2; x += 1) {
    border.add(`${y1}:${x}`);
    border.add(`${y2}:${x}`);
  }
  for (let y = y1; y <= y2; y += 1) {
    border.add(`${y}:${x1}`);
    border.add(`${y}:${x2}`);
  }

  const queue = [[start[1], start[0], 0]];
  const visited = new Set([`${start[1]}:${start[0]}`]);
  for (let head = 0; head < queue.length; head += 1) {
    const [row, column, steps] = queue[head];
    if (column === target[0] && row === target[1]) return steps;
    for (const [dr, dc] of [[-1, 0], [1, 0], [0, -1], [0, 1]]) {
      const key = `${row + dr}:${column + dc}`;
      if (!border.has(key) || visited.has(key)) continue;
      visited.add(key);
      queue.push([row + dr, column + dc, steps + 1]);
    }
  }
  return -1;
}
```

Brute trên chỉ đúng cho một rectangle đơn; counterexample nhiều rectangle cho thấy modeling, không
phải BFS, mới là phần khó của bài.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `board` | raster của border union đã scale | fill rectangle rồi erase strict interior |
| `start` | `[row,column]` đã scale | `[characterY*2, characterX*2]` |
| `distance` | half-step shortest; `-1` là unseen | start bằng 0 |
| `queue`, `head` | BFS trên cell border | `[start]`, `0` |

## 21. Blueprint từ đề đến code

1. Nhận ra đường đi nằm trên biên hình học, không phải toàn cell trong rectangle.
2. Scale mọi tọa độ ×2 để giữ topology tại corner và cạnh sát nhau.
3. Fill toàn bộ rectangle trước; chỉ sau đó erase strict interior của mọi rectangle.
4. Đổi `(x,y)` sang `[row=y,column=x]` nhất quán.
5. BFS bốn hướng trên cell giá trị 1, rồi chia distance scaled cho 2.

## 22. Invariant, lỗi lộ diện và recall

Sau hai pass fill-erase, cell 1 biểu diễn đúng border đi được của union. Không được erase rồi fill
từng rectangle xen kẽ vì rectangle sau có thể tô lại interior cần xóa. Trên graph border đã đúng,
invariant shortest của BFS giống OF038.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| không scale ×2 | rectangles chạm corner | không đi tắt |
| erase trước khi fill xong | rectangles overlap | chỉ giữ union border |
| đảo x/y | rectangle không đối xứng | path đúng hình |
| quên chia 2 | square cạnh 1 | 2 thay vì 4 half-step |

Recall: **bài geometry thường khó ở graph model: scale ×2 → fill union → erase interior → BFS border.**
