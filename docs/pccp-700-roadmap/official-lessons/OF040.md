# OF040 — Nhặt vật phẩm

- Nguồn đề: [Programmers lesson 87694](https://school.programmers.co.kr/learn/courses/30/lessons/87694?language=javascript)
- Pattern chính: coordinate scaling + border BFS
- Mức trong bank: STRETCH / special modeling

## 01. Contract

Các rectangle tạo vùng; chỉ đi trên đường biên union từ nhân vật tới vật phẩm. Trả shortest distance.

## 02. Bound

Tọa độ nhỏ cho phép raster grid. Scale ×2 tránh hai cạnh/corner chạm nhau bị coi là đường tắt.

## 03. Brute force

Đi trên grid gốc đánh dấu border trực tiếp; sai topology ở corner và đoạn cạnh sát nhau.

## 04. Bottleneck

Mô hình tọa độ nguyên không biểu diễn midpoint/crossing. Nhân đôi tạo ô trung gian, sau đó fill rectangles và erase strict interiors để giữ đúng border union.

## 05. Pattern

Scale all coordinates; fill toàn rectangle=1; erase interior=0; BFS bốn hướng trên cell1; chia distance2.

## 06. State

Scaled board, distance, queue/head, scaled start/target.

## 07. Transition

Neighbor trong bounds, board=1, unseen; mark/enqueue.

## 08. Invariant

Sau fill-erase, cell1 đúng đường biên có thể đi của union. Scale bảo đảm các điểm giao hình học xuất hiện thành node/cạnh riêng; BFS lần đầu tới target là shortest scaled path.

## 09. Complexity

Với coordinate bound cố định, build/BFS `O(C²)`; space `O(C²)`.

## 10. Pseudocode

```text
scale x2
fill every rectangle including border
erase every strict interior
BFS border from character to item
return scaledDistance/2
```

## 11. Code bước 1 — dựng state

```js
const start=[characterY*2,characterX*2];
const target=[itemY*2,itemX*2];
```

## 12. Code bước 2 — viết transition

```js
for (let row=y1*2+1;row<y2*2;row++)
  for (let column=x1*2+1;column<x2*2;column++) board[row][column]=0;
```

## 13. Code bước 3 — ghép vòng lặp

```js
if (board[nextRow][nextColumn]===1 && distance[nextRow][nextColumn]===-1) {
  distance[nextRow][nextColumn]=distance[row][column]+1;
  queue.push([nextRow,nextColumn]);
}
```

## 15. Dry-run

Rectangle đơn từ `(1,1)` tới `(2,2)` thành square scaled cạnh2; hai corner đối diện cách4 half-steps, trả2.

## 16. Edge cases

Rectangles overlap; share border/corner; start-target cùng rectangle; inner area phải không đi được.

## 17. Lỗi JavaScript thường gặp

Không scale; erase interior trước khi fill rectangle khác rồi bị fill lại; đảo x/y; quên chia2; đi diagonal.
