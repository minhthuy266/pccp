# OF002 — Ponketmon

- Nguồn đề: [Programmers lesson 1845](https://school.programmers.co.kr/learn/courses/30/lessons/1845?language=javascript)
- Pattern chính: Set cardinality + upper bounds
- Mức trong bank: TRANSFER / warmup

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

`nums` chứa mã loại của các cá thể. Phải chọn đúng `nums.length / 2` cá thể và tối đa hóa số **loại khác nhau** trong lựa chọn. Trả số loại tối đa, không cần trả các cá thể đã chọn.

## 02. Bound

Có thể có nhiều cá thể nhưng output chỉ phụ thuộc hai con số: số slot được chọn và số loại distinct toàn bộ. Không cần sinh các tổ hợp `n choose n/2`.

Tạo Set một lần cho lời giải `O(n)` trung bình.

## 03. Brute force

Sinh mọi tập con có đúng `n/2` phần tử, đếm distinct của từng tập và lấy maximum.

Số tổ hợp tăng rất nhanh, gần `2^n`; đây là dấu hiệu phải tìm upper bound thay vì enumerate.

## 04. Bottleneck

Brute force xét danh tính cụ thể của từng cá thể, trong khi mục tiêu chỉ đếm loại. Có hai trần hiển nhiên:

- không thể có nhiều loại hơn số slot `n/2`;
- không thể có nhiều loại hơn số loại tồn tại `u`.

Cả hai trần đều đạt được, nên đáp án là `min(n/2, u)`.

## 05. Pattern

Pattern `minimum of independent upper bounds`:

```text
capacity bound = n / 2
availability bound = number of distinct kinds
answer = min(capacity, availability)
```

Set chỉ dùng để đo `availability`, không cần mô phỏng chọn.

## 06. State

- `selectableCount = nums.length / 2`;
- `distinctKindCount = new Set(nums).size`.

Không cần frequency vì mỗi loại có ít nhất một cá thể là đủ để đóng góp `1` vào diversity.

## 07. Transition

Khi quét một mã loại, Set thêm mã đó. Nếu đã có, size không đổi; nếu mới, size tăng một. Cuối cùng lấy minimum với số slot.

## 08. Invariant

Sau khi đọc prefix `nums[0..i]`, Set chứa đúng mọi loại xuất hiện trong prefix đó. Vì Set tự loại duplicate, `size` là số loại distinct chính xác.

Chứng minh đạt được:

- nếu `u <= n/2`, chọn một cá thể từ mỗi loại rồi điền slot còn lại tùy ý;
- nếu `u > n/2`, chọn một cá thể từ `n/2` loại khác nhau.

Vậy `min(n/2, u)` vừa là upper bound vừa xây dựng được.

## 09. Complexity

- Time trung bình: `O(n)`.
- Space: `O(u)`.
- Không sinh combination và không cần sort.

## 10. Pseudocode

```text
slots = length(nums) / 2
kinds = size of Set(nums)
return min(slots, kinds)
```

## 11. Code bước 1 — dựng state

```js
function selectionCapacity(nums) {
  return nums.length / 2;
}
```

Contract bảo đảm số lượng phù hợp để chọn một nửa; không cần `floor` để che input sai.

## 12. Code bước 2 — viết transition

```js
function countDistinctKinds(nums) {
  const kinds = new Set();
  for (const kind of nums) kinds.add(kind);
  return kinds.size;
}
```

`add` idempotent: thêm cùng value nhiều lần không tăng size.

## 13. Code bước 3 — ghép vòng lặp

```js
function maxPokemonKindsStep3(nums) {
  const slots = selectionCapacity(nums);
  const availableKinds = countDistinctKinds(nums);
  return Math.min(slots, availableKinds);
}
```

Đây là bước model/proof, không phải simulation chọn từng cá thể.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF002.js](../../../solutions/official/OF002.js).

```js
function maxPokemonKinds(nums) {
  const selectableCount = nums.length / 2;
  const distinctKindCount = new Set(nums).size;
  return Math.min(selectableCount, distinctKindCount);
}
```

## 15. Dry-run

| Đại lượng | Giá trị |
|---|---:|
| `n` | 6 |
| slot được chọn | 3 |
| Set loại | `{3,2,4}` |

Nếu chỉ có `{1}` nhưng có hai cá thể, số slot là `1`, answer vẫn `1`.

## 16. Edge cases

1. Tất cả cùng loại: answer `1`.
2. Mọi cá thể khác loại: answer đúng bằng `n/2`, không phải `n`.
3. Số loại đúng bằng số slot.
4. Nhiều duplicate không ảnh hưởng Set size.

## 17. Lỗi JavaScript thường gặp

- Trả `new Set(nums).size` mà quên chặn bởi `n/2`.
- Đếm frequency đầy đủ dù chỉ cần presence; không sai nhưng che mất ý chính.
- Dùng object rồi lấy `.length`; object không có size như Set.
- Sinh combinations vì đọc chữ “chọn”, bỏ qua việc output chỉ cần cardinality.

## 18. Bài transfer cùng pattern

- OF001: duplicate cần multiplicity nên Set không còn đủ, phải dùng Map count.
- OF018: cũng rút dữ liệu về các đại lượng cực trị thay vì enumerate mọi orientation.
- OF004: số lựa chọn từng category tạo thành product, không phải minimum hai bound.

Tín hiệu: tối đa hóa số loại với số slot cố định ⇒ tìm `min(capacity, distinct availability)` trước khi nghĩ backtracking.

#### 20. Brute force đầy đủ và dry-run

```js
function maxPokemonKindsBrute(nums) {
  const targetSize = nums.length / 2;
  let bestDistinctCount = 0;

  function choose(index, selectedKinds, selectedCount) {
    if (selectedCount === targetSize) {
      bestDistinctCount = Math.max(bestDistinctCount, selectedKinds.size);
      return;
    }
    if (index === nums.length) return;
    if (selectedCount + nums.length - index < targetSize) return;

    const nextKinds = new Set(selectedKinds);
    nextKinds.add(nums[index]);
    choose(index + 1, nextKinds, selectedCount + 1);
    choose(index + 1, selectedKinds, selectedCount);
  }

  choose(0, new Set(), 0);
  return bestDistinctCount;
}
```

Với `[1,1,2,3]`, brute force xét sáu cặp; các số loại lần lượt không vượt `2`, và cặp
`[1,2]` đạt `2`. Mỗi tập con hợp lệ được xét nên code đúng, nhưng cây chọn/bỏ có tới
`2^n` node. Lời giải tối ưu không cần biết tập con cụ thể vì `min(slots, kinds)` luôn đạt được.
