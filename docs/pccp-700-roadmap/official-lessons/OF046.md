# OF046 — Thứ hạng

- Nguồn đề: [Programmers lesson 49191](https://school.programmers.co.kr/learn/courses/30/lessons/49191?language=javascript)
- Pattern chính: transitive closure / reachability
- Mức trong bank: TRANSFER / graph integration

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Mỗi result `[winner,loser]` cho quan hệ thắng. Quan hệ bắc cầu: nếu A thắng B và B thắng C thì biết A đứng trên C. Đếm player có thứ hạng xác định duy nhất.

Một player xác định hạng khi với mọi player khác, biết họ thắng người kia hoặc thua người kia.

## 02. Bound

n nhỏ cho Floyd-Warshall boolean `O(n³)`. Không cần shortest distance, chỉ reachability.

## 03. Brute force

Thử mọi permutation ranking phù hợp results rồi xem player có cùng vị trí trong mọi permutation; factorial.

## 04. Bottleneck

Ta chỉ cần biết quan hệ có đường đi directed hay không. Tính transitive closure gom toàn bộ suy luận bắc cầu.

## 05. Pattern

Boolean Floyd-Warshall:

```text
if beats[from][middle] and beats[middle][to]
  beats[from][to]=true
```

Sau closure, player comparable với mọi other thì rank xác định.

## 06. State

- matrix `beats[from][to]`;
- loop order middle, from, to;
- `comparable` count từng player.

## 07. Transition

Cho phép node `middle` làm trung gian mới; mọi path dùng intermediates đã xét được ghi vào matrix. Skip row khi from không reach middle.

## 08. Invariant

Sau vòng middle k, matrix đúng cho mọi path có intermediate trong `0..k`. Khi xong, matrix là reachability toàn graph. Player có đúng n-1 quan hệ một chiều với others nên số người chắc chắn trên/dưới xác định vị trí duy nhất.

## 09. Complexity

Time `O(n³)`, space `O(n²)`.

## 10. Pseudocode

```text
beats[winner][loser]=true
for middle,from,to:
  beats[from][to] |= beats[from][middle] && beats[middle][to]
for player:
  comparable=count other where beats[p][o] or beats[o][p]
  if comparable==n-1 answer++
```

## 11. Code bước 1 — dựng state

```js
function reachability(n,results) {
  const beats=Array.from({length:n},()=>new Uint8Array(n));
  for (const [winner,loser] of results) beats[winner-1][loser-1]=1;
  return beats;
}
```

## 12. Code bước 2 — viết transition

```js
function canInfer(beats,from,middle,to) {
  return beats[from][middle] && beats[middle][to];
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function areComparable(beats,a,b) {
  return Boolean(beats[a][b] || beats[b][a]);
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF046.js](../../../solutions/official/OF046.js).

```js
function determinableRankCount(n, results) {
  const beats = Array.from({ length: n }, () => new Uint8Array(n));
  for (const [winner, loser] of results) beats[winner - 1][loser - 1] = 1;

  for (let middle = 0; middle < n; middle++) {
    for (let from = 0; from < n; from++) {
      if (beats[from][middle] === 0) continue;
      for (let to = 0; to < n; to++) {
        if (beats[middle][to]) beats[from][to] = 1;
      }
    }
  }

  let answer = 0;
  for (let player = 0; player < n; player++) {
    let comparable = 0;
    for (let other = 0; other < n; other++) {
      if (player !== other && (beats[player][other] || beats[other][player])) comparable++;
    }
    if (comparable === n - 1) answer++;
  }
  return answer;
}
```

## 15. Dry-run

Results 1>2, 2>3: closure thêm 1>3. Player1 comparable với 2,3; player2 biết thua1/thắng3; player3 thua1,2. Cả ba có rank xác định.

## 16. Edge cases

1. Không đủ relation: zero rank xác định.
2. Chain đầy đủ qua transitivity.
3. Direct result không đủ nếu bỏ closure.
4. Không đếm self trong n-1.

## 17. Lỗi JavaScript thường gặp

- Treat edge vô hướng.
- Chỉ đếm direct wins/losses.
- Loop order không đặt middle ngoài cùng, phá proof in-place.
- Dùng `&&` value mà quên set matrix.
- Yêu cầu wins+losses bằng n thay n-1.
