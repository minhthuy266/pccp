# OF049 — Dạo công viên

- Nguồn đề: [Programmers lesson 172928](https://school.programmers.co.kr/learn/courses/30/lessons/172928?language=javascript)
- Pattern chính: grid simulation + validate-then-commit
- Mức trong bank: CORE / implementation

Tài liệu này diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

`park` là grid ký tự: `S` là vị trí đầu, `O` đi được, `X` là vật cản. Mỗi route có hướng và số bước. Một route chỉ được thực hiện nếu **toàn bộ** đường đi của route vẫn trong grid và không chạm `X`; nếu có một bước lỗi, bỏ cả route và giữ nguyên vị trí cũ.

Trả `[row, column]` cuối cùng, đều là index 0-based.

## 02. Bound

Grid và danh sách route nhỏ; khoảng cách trong từng route cũng nhỏ. Mô phỏng từng bước là đúng ngân sách và bám sát contract.

Gọi `R`, `C` là kích thước grid và `S` là tổng số bước được yêu cầu. Mục tiêu `O(R*C + S)` là dư sức.

## 03. Brute force

Cho từng route, thử di chuyển từng bước. Có thể clone cả grid/state trước mỗi route rồi khôi phục nếu lỗi.

Cách đó đúng nhưng clone là thừa: chỉ cần dùng tọa độ candidate và chưa commit vào state thật.

## 04. Bottleneck

Lỗi logic chính là partial commit: cập nhật vị trí thật sau mỗi bước rồi phát hiện bước thứ ba đụng tường. Contract yêu cầu rollback cả command, nhưng code đã làm mất vị trí ban đầu.

Bottleneck tư duy được loại bằng transaction nhỏ:

```text
state thật → candidate → validate hết → commit một lần
```

## 05. Pattern

Pattern `validate-then-commit` cho simulation:

1. parse command;
2. copy vị trí hiện tại sang candidate;
3. chạy từng bước trên candidate;
4. gặp invalid thì hủy;
5. chỉ khi toàn bộ hợp lệ mới gán candidate cho state thật.

## 06. State

- State bền qua mọi route: `row`, `column`.
- State tạm của một route: `candidateRow`, `candidateColumn`, `valid`.
- Lookup bất biến: `DIRECTION[letter] = [deltaRow, deltaColumn]`.

## 07. Transition

Với mỗi bước:

```text
candidateRow += deltaRow
candidateColumn += deltaColumn
check bounds
check obstacle
```

Sau vòng bước:

```text
valid  → row = candidateRow; column = candidateColumn
invalid → không thay đổi row, column
```

## 08. Invariant

Trước mỗi route, `(row, column)` là vị trí đúng sau toàn bộ prefix route đã xử lý.

Trong lúc validate route hiện tại, state thật chưa đổi. Candidate là vị trí sau đúng số bước đã kiểm tra; mọi ô candidate đã đi qua đều nằm trong grid và không phải `X`. Vì vậy invalid có thể hủy mà không rollback.

## 09. Complexity

- Tìm `S`: `O(R*C)`.
- Mô phỏng: `O(S)`, với `S` là tổng khoảng cách route cho đến khi hợp lệ hoặc gặp lỗi.
- Space phụ: `O(1)` ngoài input và bảng bốn hướng.

## 10. Pseudocode

```text
find start row, column
for route in routes:
    parse direction and distance
    candidate = current position
    valid = true
    repeat distance times:
        move candidate one cell
        if outside or obstacle:
            valid = false
            break
    if valid:
        current position = candidate
return current position
```

## 11. Code bước 1 — dựng state

```js
const DIRECTION = {
  N: [-1, 0],
  S: [1, 0],
  W: [0, -1],
  E: [0, 1],
};

function findStart(park) {
  for (let row = 0; row < park.length; row++) {
    const column = park[row].indexOf("S");
    if (column !== -1) return [row, column];
  }
  return [-1, -1];
}
```

Row tăng khi đi Nam, column tăng khi đi Đông. Viết bảng delta một lần tránh bốn nhánh cập nhật khác nhau.

## 12. Code bước 2 — viết transition

```js
function validateRoute(park, row, column, direction, distance) {
  const [deltaRow, deltaColumn] = DIRECTION[direction];
  let candidateRow = row;
  let candidateColumn = column;

  for (let step = 0; step < distance; step++) {
    candidateRow += deltaRow;
    candidateColumn += deltaColumn;

    const outside =
      candidateRow < 0 || candidateRow >= park.length ||
      candidateColumn < 0 || candidateColumn >= park[0].length;

    if (outside || park[candidateRow][candidateColumn] === "X") return null;
  }

  return [candidateRow, candidateColumn];
}
```

Điều kiện `outside || ...` dùng short-circuit: nếu outside thì JavaScript không truy cập cell invalid.

## 13. Code bước 3 — ghép vòng lặp

```js
function parkWalkStep3(park, routes) {
  let [row, column] = findStart(park);

  for (const route of routes) {
    const [direction, rawDistance] = route.split(" ");
    const next = validateRoute(park, row, column, direction, Number(rawDistance));
    if (next !== null) [row, column] = next;
  }

  return [row, column];
}
```

`next === null` biểu diễn command bị hủy; `[0,0]` vẫn là vị trí hợp lệ nên không được kiểm bằng `if (next)` nếu representation có thể là số 0.

## 14. Code hoàn chỉnh

Code executable nằm tại [solutions/official/OF049.js](../../../solutions/official/OF049.js).

```js
const DIRECTION = {
  N: [-1, 0],
  S: [1, 0],
  W: [0, -1],
  E: [0, 1],
};

function parkWalk(park, routes) {
  const rows = park.length;
  const columns = park[0].length;
  let row = 0;
  let column = 0;

  for (let currentRow = 0; currentRow < rows; currentRow++) {
    const startColumn = park[currentRow].indexOf("S");
    if (startColumn !== -1) {
      row = currentRow;
      column = startColumn;
      break;
    }
  }

  for (const route of routes) {
    const [direction, rawDistance] = route.split(" ");
    const distance = Number(rawDistance);
    const [deltaRow, deltaColumn] = DIRECTION[direction];
    let candidateRow = row;
    let candidateColumn = column;
    let valid = true;

    for (let step = 0; step < distance; step++) {
      candidateRow += deltaRow;
      candidateColumn += deltaColumn;

      const outside =
        candidateRow < 0 ||
        candidateRow >= rows ||
        candidateColumn < 0 ||
        candidateColumn >= columns;

      if (outside || park[candidateRow][candidateColumn] === "X") {
        valid = false;
        break;
      }
    }

    if (valid) {
      row = candidateRow;
      column = candidateColumn;
    }
  }

  return [row, column];
}
```

## 16. Edge cases

1. Lỗi ngay bước đầu: state không đổi.
2. Đi được vài bước rồi gặp `X`: phải hủy cả route.
3. Đi ra ngoài ở bước cuối: cũng hủy cả route.
4. Start nằm trên biên hoặc góc.
5. Grid không vuông: luôn dùng `rows` cho row và `columns` cho column.

## 17. Lỗi JavaScript thường gặp

- Dùng `park.length` cho cả row lẫn column.
- Truy cập `park[nr][nc]` trước khi check bounds.
- Quên `Number(rawDistance)`, dựa vào coercion ngầm.
- Commit từng bước, không rollback khi route invalid.
- Đổi nhầm `N` thành tăng row hoặc `E` thành tăng row.
- Dùng `for...in` trên routes rồi nhận index chuỗi thay vì route.

### Loop and condition derivation

- **Nhịp lặp:** `từng route theo input order; inner từng step.`. Đây là lý do code dùng block bắt đầu bởi `for (let currentRow = 0; currentRow < rows; currentRow++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “bounds trước, rồi obstacle.”. Trong dry run `(0,0)`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (startColumn !== -1) {`.
- **Tiến triển:** step++, rồi route kế.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `candidate mỗi step; state thật chỉ sau inner loop.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let currentRow = 0; currentRow < rows; currentRow++) {`.
- **Cleanup:** candidate bị bỏ tự nhiên nếu invalid.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Dạo công viên:** Condition của scan/simulation phải theo đúng tie-break và thứ tự rule của đề. So sánh strict hay non-strict chỉ đổi khi boundary/tie của bài chứng minh, không vì thói quen viết comparator.

#### 19. Làm bằng tay và brute force đầy đủ

Đang ở `(0,0)`, route `E 3` đi qua `(0,1)`, `(0,2)` rồi gặp `X` tại `(0,3)`. Dù hai
bước đầu hợp lệ, route bị hủy và state vẫn `(0,0)`. Bản brute clone state trước route:

```js
function validateRouteBrute(park, startRow, startColumn, deltaRow, deltaColumn, distance) {
  let trialRow = startRow;
  let trialColumn = startColumn;

  for (let step = 0; step < distance; step++) {
    trialRow += deltaRow;
    trialColumn += deltaColumn;
    const outside =
      trialRow < 0 || trialRow >= park.length ||
      trialColumn < 0 || trialColumn >= park[0].length;
    if (outside) return [startRow, startColumn];
    if (park[trialRow][trialColumn] === "X") return [startRow, startColumn];
  }

  return [trialRow, trialColumn];
}
```

#### 21. Code Blueprint

```text
OUTPUT: [row,column] cuối sau mọi route hợp lệ.
PREPARE: rows/columns; tìm S; bảng direction.
GLOBAL STATE: row,column đã commit.
INIT: tọa độ S.
MAIN LOOP: từng route theo input order; inner từng step.
CURRENT ITEM: direction,distance; candidate cell.
PER-ITERATION STATE: candidateRow/candidateColumn/valid.
CHECK: bounds trước, rồi obstacle.
BRANCH: invalid → valid=false và break; valid toàn route → commit.
UPDATE: candidate mỗi step; state thật chỉ sau inner loop.
POINTER MOVEMENT: step++, rồi route kế.
STOP / RETURN: hết routes return [row,column].
CLEANUP: candidate bị bỏ tự nhiên nếu invalid.
```

Invariant transaction: trong inner loop state thật chưa đổi; candidate đã đi đúng số bước
và mọi cell trước đều hợp lệ. Vì vậy `break` không cần rollback, còn commit nguyên tử bảo toàn
state đúng sau prefix route.
