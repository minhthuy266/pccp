# OF014 — Hai hàng đợi ưu tiên

- Nguồn đề: [Programmers lesson 42628](https://school.programmers.co.kr/learn/courses/30/lessons/42628?language=javascript)
- Pattern chính: min/max heap + lazy deletion
- Mức trong bank: TRANSFER / variant

## 01. Contract

Xử lý lệnh insert, delete maximum, delete minimum. Delete trên cấu trúc rỗng bị bỏ qua. Cuối trả `[max,min]`, hoặc `[0,0]` nếu rỗng. Duplicate value là các occurrence riêng.

## 02. Bound

Sort array sau mỗi command hoặc splice cực trị là tốn kém. Hai heap cho hai cực trị `O(log n)` nhưng phải đồng bộ deletion.

## 03. Brute force

Giữ array, insert push, delete sort rồi shift/pop. Đúng nhưng sort lặp `O(q² log q)` worst case.

## 04. Bottleneck

Xóa từ min heap không thể xóa occurrence tương ứng trong max heap nhanh. Gán unique id cho mỗi insert và đánh dấu alive; heap kia bỏ entry chết khi nó nổi lên root.

## 05. Pattern

Dual heap lazy deletion:

```text
insert same {value,id} into both heaps; alive[id]=true
delete one root after cleaning; alive[id]=false
clean(heap): pop while root id dead
```

## 06. State

MinHeap, MaxHeap, `alive[id]`, `liveCount`, `nextId`.

## 07. Transition

Insert tăng liveCount. Delete nếu liveCount>0: clean heap tương ứng, pop, mark dead, giảm count. Cuối clean cả hai trước peek.

## 08. Invariant

Mỗi live occurrence có một entry trong cả hai heap; `alive` là nguồn sự thật. Sau clean, root là cực trị trong tập live. Unique id giữ duplicate độc lập.

## 09. Complexity

Mỗi entry push hai lần và pop tối đa một lần khỏi mỗi heap: amortized `O(q log q)`, space `O(q)`.

## 10. Pseudocode

```text
for operation:
  insert: create id, push both, alive true
  delete if nonempty:
    choose heap; clean dead roots; pop; mark dead
if empty return [0,0]
clean both; return [maxRoot,minRoot]
```

## 14. Code hoàn chỉnh

Code executable gồm heap đầy đủ: [solutions/official/OF014.js](../../../solutions/official/OF014.js).

```js
class NumericHeap {
  constructor(compare) {
    this.values = [];
    this.compare = compare;
  }
  get size() {
    return this.values.length;
  }
  peek() {
    return this.values[0];
  }
  push(value) {
    const heap = this.values;
    heap.push(value);
    let child = heap.length - 1;
    while (child > 0) {
      const parent = Math.floor((child - 1) / 2);
      if (this.compare(heap[parent], heap[child]) <= 0) break;
      [heap[parent], heap[child]] = [heap[child], heap[parent]];
      child = parent;
    }
  }
  pop() {
    const heap = this.values;
    if (heap.length === 0) return undefined;
    if (heap.length === 1) return heap.pop();
    const root = heap[0];
    heap[0] = heap.pop();
    let parent = 0;
    while (true) {
      const left = parent * 2 + 1;
      const right = left + 1;
      let best = parent;
      if (left < heap.length && this.compare(heap[left], heap[best]) < 0) best = left;
      if (right < heap.length && this.compare(heap[right], heap[best]) < 0) best = right;
      if (best === parent) break;
      [heap[parent], heap[best]] = [heap[best], heap[parent]];
      parent = best;
    }
    return root;
  }
}

function doublePriorityQueue(operations) {
  const minHeap = new NumericHeap((a, b) => a.value - b.value);
  const maxHeap = new NumericHeap((a, b) => b.value - a.value);
  const alive = [];
  let liveCount = 0;
  let nextId = 0;

  function clean(heap) {
    while (heap.size > 0 && !alive[heap.peek().id]) heap.pop();
  }

  for (const operation of operations) {
    const [command, rawValue] = operation.split(" ");
    const value = Number(rawValue);

    if (command === "I") {
      const entry = { value, id: nextId++ };
      alive[entry.id] = true;
      minHeap.push(entry);
      maxHeap.push(entry);
      liveCount++;
      continue;
    }

    if (liveCount === 0) continue;
    const heap = value === 1 ? maxHeap : minHeap;
    clean(heap);
    const removed = heap.pop();
    alive[removed.id] = false;
    liveCount--;
  }

  if (liveCount === 0) return [0, 0];
  clean(minHeap);
  clean(maxHeap);
  return [maxHeap.peek().value, minHeap.peek().value];
}
```

## 15. Dry-run

Insert 5 hai lần tạo id0,id1. Delete max mark chỉ một id dead, liveCount 1. Clean heap còn lại có thể pop dead id nhưng vẫn giữ occurrence 5 sống; kết quả `[5,5]`.

## 16. Edge cases

Delete empty; duplicate values; delete min rồi max; tất cả entries dead nhưng còn nằm vật lý trong heap.

## 17. Lỗi JavaScript thường gặp

Dùng value làm alive key làm mất duplicate; không clean trước delete/peek; giảm liveCount khi delete empty; comparator max sai dấu; heap pop empty.
