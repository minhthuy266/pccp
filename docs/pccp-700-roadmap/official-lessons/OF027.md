# OF027 — Tạo số lớn

- Nguồn đề: [Programmers lesson 42883](https://school.programmers.co.kr/learn/courses/30/lessons/42883?language=javascript)
- Pattern chính: greedy monotonic stack
- Mức trong bank: CORE / representative

## 01. Contract

Xóa đúng `k` chữ số khỏi string number, giữ thứ tự tương đối của các chữ số còn lại, để tạo số lớn nhất. Trả string.

## 02. Bound

Thử mọi subsequence dài n-k là combinatorial. Monotonic stack xử lý mỗi digit tối đa hai lần `O(n)`.

## 03. Brute force

Sinh mọi tập index bị xóa hoặc mọi subsequence rồi lấy maximum; exponential.

## 04. Bottleneck

Giá trị số ưu tiên chữ số bên trái. Khi digit mới lớn hơn top, xóa top nhỏ hơn cải thiện vị trí sớm nhất và luôn có lợi nếu còn budget.

## 05. Pattern

Stack giảm không nghiêm ngặt: trong khi top<current và còn quyền xóa, pop; push current. Nếu cuối còn budget, xóa tail vì sequence đã non-increasing.

## 06. State

Stack digits của prefix; `remainingRemovals`.

## 07. Transition

Current pop mọi smaller top trong budget, rồi push. Cuối truncate stack length bởi budget còn lại.

## 08. Invariant

Sau prefix, stack là subsequence lớn nhất lexicographically có thể tạo từ prefix với đúng số deletion đã dùng. Greedy cải thiện chữ số sớm nhất; top không nhỏ hơn current thì giữ top tốt hơn việc xóa nó cho current.

## 09. Complexity

Time `O(n)` amortized, space `O(n)`.

## 10. Pseudocode

```text
stack=[]; remaining=k
for digit:
  while remaining>0 and top<digit: pop; remaining--
  push digit
if remaining>0: remove remaining from tail
return join
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF027.js](../../../solutions/official/OF027.js).

```js
function largestNumberAfterRemovingDigits(number, removeCount) {
  const selectedDigits = [];
  let remainingRemovals = removeCount;

  for (const digit of number) {
    while (remainingRemovals > 0 && selectedDigits.length > 0) {
      const previousDigit = selectedDigits.at(-1);
      if (previousDigit >= digit) break;

      selectedDigits.pop();
      remainingRemovals--;
    }

    selectedDigits.push(digit);
  }

  if (remainingRemovals > 0) {
    selectedDigits.length -= remainingRemovals;
  }

  return selectedDigits.join("");
}
```

### Loop and condition derivation

- **Nhịp lặp:** `for digit`. Đây là lý do code dùng block bắt đầu bởi `for (const digit of number) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “còn budget? stack có top? top < digit?”. Trong dry run `number="1924", removeCount=2`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (previousDigit >= digit) break;`.
- **Tiến triển:** for tự sang digit kế tiếp; inner while chỉ pop stack.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `pop, giảm remaining; sau inner while thì push current.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `selectedDigits.pop();`.
- **Cleanup:** budget còn thì truncate tail. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Tạo số lớn:** Guard cấu trúc không rỗng phải đứng trước mọi lần đọc top/front. Equality có pop hay không, và visited được mark lúc enqueue hay dequeue, lấy đúng từ invariant của bài này.

| Cleanup/return | budget còn thì truncate tail | hết input | string lớn nhất | Không còn transition bắt buộc nào chưa chạy |

Trong **Tạo số lớn**, chỉ dòng thực hiện `pop, giảm remaining; sau inner while thì push current.` được đổi output; state còn pending theo `selectedDigits,remainingRemovals` phải sống tới branch hoặc cleanup sở hữu nó.

### Complexity proof from movements

Time `O(n)` amortized, space `O(n)`.

**Proof từ operation của Tạo số lớn:** Đếm số lần một item vào và rời cấu trúc: mỗi item chỉ được push/enqueue theo transition của bài và chỉ được pop/dequeue khi đã hoàn tất vai trò. Nested while không tự động là bình phương nếu item đã rời không quay lại. Main loop được mô tả là `for digit`; movement là `for tự sang digit kế tiếp; inner while chỉ pop stack.`. Vì vậy phải cộng chi phí các phase nối tiếp và chỉ nhân khi một phase thật sự chạy trọn bên trong mỗi lượt ngoài. Auxiliary space chính là state `selectedDigits,remainingRemovals`, không tính output nếu convention của bài tách output.

#### 19. Từ thử mọi subsequence đến greedy dễ dựng

##### Làm bằng tay và brute force

Với `1924`, cần xóa 2 chữ số. So từ trái: khi thấy 9 sau 1, xóa 1 vì chữ số bên trái quyết
định giá trị lớn hơn mọi chữ số phía sau. Sau đó thấy 4 sau 2, dùng lượt xóa cuối cho 2; còn `94`.

```js
function largestNumberBruteForce(number, removeCount) {
  const keptLength = number.length - removeCount;
  let best = "";

  function choose(index, selected) {
    if (selected.length === keptLength) {
      if (best === "" || selected > best) best = selected;
      return;
    }
    if (index === number.length) return;
    const remainingInput = number.length - index;
    const stillNeeded = keptLength - selected.length;
    if (remainingInput < stillNeeded) return;

    choose(index + 1, selected + number[index]);
    choose(index + 1, selected);
  }

  choose(0, "");
  return best;
}
```

Brute force sinh mọi subsequence dài `n-k`, đúng nhưng có số nhánh tổ hợp. Greedy chỉ cần giữ
subsequence tốt nhất của prefix: current lớn hơn top thì xóa top trong khi còn budget.

##### State, transition và cleanup

| State | Kiểu | Lưu chính xác gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `selectedDigits` | string[] | subsequence tốt nhất của prefix | `[]` | xuyên loop |
| `remainingRemovals` | number | số chữ số còn phải xóa | `removeCount` | xuyên loop |
| `digit` | string | chữ số current | từ for | iteration |
| `previousDigit` | string | top đang so | từ stack | mỗi vòng while |

Một current có thể pop nhiều top nên dùng `while`. Dừng khi hết budget, stack rỗng, hoặc top
`>= current`. Equal không pop vì xóa equal sớm không cải thiện prefix. Nếu hết input mà budget
còn, stack đang không tăng; xóa tail là cách ít ảnh hưởng nhất và cũng bảo đảm xóa **đúng k**.

```text
OUTPUT: string lớn nhất; PREPARE: không đổi number thành Number
GLOBAL STATE: selectedDigits,remainingRemovals; INIT: [],removeCount
MAIN LOOP: for digit; CURRENT ITEM: digit; PER-ITERATION STATE: previousDigit
CHECK: còn budget? stack có top? top < digit?
BRANCH: while top nhỏ → pop và giảm budget; sau đó push digit
UPDATE: pop, giảm remaining; sau inner while thì push current.
POINTER MOVEMENT: for tự sang digit kế tiếp; inner while chỉ pop stack.
STOP / RETURN: hết input; CLEANUP: budget còn thì truncate tail
RETURN: selectedDigits.join("")
```

Invariant sau mỗi prefix: stack là subsequence lớn nhất theo thứ tự từ điển với số deletion đã
dùng. Pop cải thiện vị trí khác biệt sớm nhất; giữ top lớn/equal tốt hơn thay nó bằng current.

| Digit | Stack trước | Pop | Budget sau | Stack sau |
| --- | --- | --- | ---: | --- |
| 1 | `[]` | không | 2 | `[1]` |
| 9 | `[1]` | pop 1 | 1 | `[9]` |
| 2 | `[9]` | không | 1 | `[9,2]` |
| 4 | `[9,2]` | pop 2 | 0 | `[9,4]` |

Mỗi digit push một, pop tối đa một: `O(n)` time, `O(n)` space. Nested while vẫn tuyến tính.

- Logic: sort digits phá thứ tự; `417725...` không được reorder.
- Off-by-one: truncate `remaining+1`; dãy giảm bị xóa thừa.
- Check/update: giảm budget sau push sai digit.
- Init: remaining bằng `0` thay vì k; không xóa gì.
- Hidden: dãy giảm `4321`, k=2 cần cleanup ra `43`; equal không pop.
- Performance: convert whole string sang Number vừa mất precision vừa không giải bài subsequence.
