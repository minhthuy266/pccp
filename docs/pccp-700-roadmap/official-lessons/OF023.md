# OF023 — Chia lưới điện

- Nguồn đề: [Programmers lesson 86971](https://school.programmers.co.kr/learn/courses/30/lessons/86971?language=javascript)
- Pattern chính: tree edge cut + component size
- Mức trong bank: CORE / representative

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

`n` node và `n-1` wires tạo một cây. Cắt đúng một wire để thành hai component; minimize chênh lệch số node giữa chúng. Trả minimum difference.

## 02. Bound

n nhỏ, có thể thử từng trong `n-1` edge và traversal `O(n)`; tổng `O(n²)`.

## 03. Brute force

Cho mỗi edge, dựng lại graph không có edge đó, BFS cả hai phía và đếm. Đúng nhưng rebuild adjacency lặp.

## 04. Bottleneck

Adjacency không đổi ngoài việc bỏ qua một edge. Vì input là cây, cắt edge chắc chắn tạo đúng hai component. Chỉ cần đếm một component size `c`; bên kia là `n-c`.

## 05. Pattern

Build adjacency một lần. Với từng cut `(a,b)`, traversal từ node 1 nhưng skip cả hướng `a→b` và `b→a`; difference `|c-(n-c)| = |n-2c|`.

## 06. State

- adjacency list;
- current cut endpoints;
- visited, stack;
- `componentSize`, `best`.

## 07. Transition

Pop node, increment size; với neighbor, skip nếu edge đúng cut hoặc visited, còn lại mark/push.

## 08. Invariant

Traversal chỉ đi qua edge chưa cắt và visited chứa đúng node reachable từ start. Khi xong, componentSize là một phía. Tính chất cây bảo đảm mọi node còn lại thuộc duy nhất phía kia.

## 09. Complexity

Build `O(n)`. `n-1` traversal mỗi cái `O(n)`: tổng `O(n²)`, space `O(n)`.

## 10. Pseudocode

```text
build undirected adjacency
best=infinity
for cut edge (a,b):
  traverse from 1, skipping a-b in both directions
  c=count reached
  best=min(best,abs(n-2*c))
return best
```

## 11. Code bước 1 — dựng state

```js
function buildTree(n,wires) {
  const adj=Array.from({length:n+1},()=>[]);
  for (const [a,b] of wires) { adj[a].push(b); adj[b].push(a); }
  return adj;
}
```

## 12. Code bước 2 — viết transition

```js
function isCut(node,neighbor,a,b) {
  return (node===a&&neighbor===b)||(node===b&&neighbor===a);
}
```

Phải bỏ cả hai hướng vì adjacency vô hướng.

## 13. Code bước 3 — ghép vòng lặp

```js
function difference(n,componentSize) {
  return Math.abs(n-2*componentSize);
}
```

Không cần traversal phía hai.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF023.js](../../../solutions/official/OF023.js).

```js
function minimumPowerGridDifference(n, wires) {
  const adjacency = Array.from({ length: n + 1 }, () => []);
  for (const [from, to] of wires) {
    adjacency[from].push(to);
    adjacency[to].push(from);
  }

  let best = Infinity;

  for (const [cutFrom, cutTo] of wires) {
    const visited = Array(n + 1).fill(false);
    const stack = [1];
    visited[1] = true;
    let componentSize = 0;

    while (stack.length > 0) {
      const node = stack.pop();
      componentSize++;

      for (const neighbor of adjacency[node]) {
        const isCutEdge =
          (node === cutFrom && neighbor === cutTo) ||
          (node === cutTo && neighbor === cutFrom);
        if (isCutEdge || visited[neighbor]) continue;
        visited[neighbor] = true;
        stack.push(neighbor);
      }
    }

    best = Math.min(best, Math.abs(n - 2 * componentSize));
  }

  return best;
}
```

## 16. Edge cases

1. n=2: cắt edge duy nhất, diff 0.
2. Star tree: mọi cut tách 1 và n-1.
3. Chain có split cân bằng.
4. Start node nằm ở phía nhỏ hoặc lớn đều dùng công thức được.

## 17. Lỗi JavaScript thường gặp

- Chỉ skip một hướng cut.
- Tái sử dụng visited giữa các edge.
- Đếm edge thay vì node.
- Giả định graph bất kỳ cũng tách đúng hai component; proof dựa vào tree.
- Dựng adjacency lại trong mỗi loop không cần thiết.

### Loop and condition derivation

- **Nhịp lặp:** `thử từng wire làm cut; mỗi lượt traversal đếm component từ node 1.`. Đây là lý do code dùng block bắt đầu bởi `for (const [from, to] of wires) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “neighbor đã visited hoặc cạnh hiện tại chính là cut theo một trong hai hướng.”. Trong dry run `n=4, wires=[[1,2],[2,3],[3,4]]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (isCutEdge \|\| visited[neighbor]) continue;`.
- **Tiến triển:** outer sang wire kế; traversal pop/push qua component.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `tăng componentSize khi lấy node; relax abs(n - 2*componentSize).` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `componentSize++;`.
- **Cleanup:** visited phải tạo mới cho mỗi cut; adjacency được tái sử dụng.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Chia lưới điện:** Guard visited, bounds hoặc stale distance phải chạy trước transition tương ứng. Với BFS, mark visited lúc enqueue để một đỉnh không xếp hàng nhiều lần; với Dijkstra, bỏ entry stale trước khi relax cạnh.

#### 19. Làm bằng tay và brute force executable

Với chain `1—2—3—4`, thử ba cạnh cắt:

| Cạnh cắt | Hai kích thước | Chênh lệch |
| --- | --- | ---: |
| 1—2 | 1 và 3 | 2 |
| 2—3 | 2 và 2 | 0 |
| 3—4 | 3 và 1 | 2 |

Brute force dưới đây dựng lại adjacency cho từng cạnh. Nó dễ kiểm chứng nhưng lặp việc không cần thiết:

```js
function minimumPowerGridDifferenceBrute(n, wires) {
  let best = Infinity;

  for (let removed = 0; removed < wires.length; removed += 1) {
    const adjacency = Array.from({ length: n + 1 }, () => []);
    for (let index = 0; index < wires.length; index += 1) {
      if (index === removed) continue;
      const [from, to] = wires[index];
      adjacency[from].push(to);
      adjacency[to].push(from);
    }

    const stack = [1];
    const visited = new Set([1]);
    while (stack.length > 0) {
      const node = stack.pop();
      for (const neighbor of adjacency[node]) {
        if (visited.has(neighbor)) continue;
        visited.add(neighbor);
        stack.push(neighbor);
      }
    }
    best = Math.min(best, Math.abs(n - 2 * visited.size));
  }
  return best;
}
```
