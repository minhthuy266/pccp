# OF019 — Thi thử

- Nguồn đề: [Programmers lesson 42840](https://school.programmers.co.kr/learn/courses/30/lessons/42840?language=javascript)
- Pattern chính: cycle simulation bằng modulo
- Mức trong bank: TRANSFER / warmup

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Ba người trả lời theo ba pattern tuần hoàn cố định. So với `answers`, tính số câu đúng của từng người và trả mọi số thứ tự người đạt điểm cao nhất theo thứ tự tăng dần.

## 02. Bound

Chỉ ba pattern, nên scan toàn bộ câu hỏi và ba người là `O(n)`. Không cần sinh chuỗi đáp án lặp dài bằng input.

## 03. Brute force

Lặp pattern bằng cách copy/concatenate cho đến đủ số câu, rồi so ba mảng. Đúng nhưng tạo dữ liệu thừa.

## 04. Bottleneck

Đáp án ở câu `i` của pattern dài `L` luôn là `pattern[i % L]`; modulo thay toàn bộ việc materialize pattern lặp.

## 05. Pattern

Cycle indexing:

```text
for question i:
  for each student s:
    if pattern[s][i % pattern[s].length] == answers[i]: score[s]++
```

Sau đó tìm max và collect mọi tie.

## 06. State

- ba `patterns` bất biến;
- `scores[3]`;
- `question`, `student`;
- `best`, `winners`.

## 07. Transition

Mỗi cặp question/student chỉ tăng score nếu answer khớp. Sau scan, duyệt scores từ index 0 lên để winners tự tăng dần.

## 08. Invariant

Sau khi xử lý `q` câu đầu, `scores[s]` bằng đúng số câu người `s` trả lời đúng trong prefix `[0,q)`. Modulo chọn đúng vị trí pattern vì quotient là số vòng hoàn chỉnh, remainder là offset trong vòng.

## 09. Complexity

- Time `O(3n) = O(n)`.
- Space `O(1)` ngoài output.

## 10. Pseudocode

```text
scores = [0,0,0]
for i over answers:
    for s in 0..2:
        if patterns[s][i mod length] equals answers[i]: scores[s]++
best = max(scores)
return all s+1 whose score equals best
```

## 12. Code bước 2 — viết transition

```js
function cyclicAnswer(pattern, question) {
  return pattern[question % pattern.length];

```

Question đang 0-based nên không cộng/trừ thêm.

## 13. Code bước 3 — ghép vòng lặp

```js
function winnerIndices(scores) {
  const best = Math.max(...scores);
  return scores.flatMap((score, index) => score === best ? [index + 1] : []);
}
```

Scan index tăng dần bảo đảm output tăng dần.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF019.js](../../../solutions/official/OF019.js).

```js
const ANSWER_PATTERNS = [
  [1, 2, 3, 4, 5],
  [2, 1, 2, 3, 2, 4, 2, 5],
  [3, 3, 1, 1, 2, 2, 4, 4, 5, 5],
];

function topMockExamScorers(answers) {
  const scores = Array(ANSWER_PATTERNS.length).fill(0);

  for (let question = 0; question < answers.length; question++) {
    for (let student = 0; student < ANSWER_PATTERNS.length; student++) {
      const pattern = ANSWER_PATTERNS[student];
      if (pattern[question % pattern.length] === answers[question]) {
        scores[student] += 1;
      }
    }
  }

  const best = Math.max(...scores);
  const winners = [];
  for (let student = 0; student < scores.length; student++) {
    if (scores[student] === best) {
      winners.push(student + 1);
    }
  }
  return winners;
}
```

## 15. Dry-run

Với answers `[1,2,3,4,5]`, người 1 dùng pattern cùng chu kỳ nên đúng cả 5; hai người còn lại ít hơn, output `[1]`.

Nếu scores `[2,2,2]`, best `2`, scan tạo `[1,2,3]`.

## 16. Edge cases

1. Một câu hỏi.
2. Ba người hòa.
3. Input dài hơn nhiều vòng của mọi pattern.
4. Winner không phải người 1.

## 17. Lỗi JavaScript thường gặp

- Dùng `i % answers.length` thay pattern length.
- Đánh số student 0-based trong output.
- Chỉ trả index của first max, làm mất tie.
- Sort winners không cần thiết nếu scan đúng thứ tự.
- Tạo pattern lặp khổng lồ.

## 18. Bài transfer cùng pattern

- OF010: simulation có state động và time, không chỉ cycle lookup.
- OF048: parsing thành scalar rồi so điều kiện.
- OF006: scan prefix và reduction state tối thiểu.

### Loop and condition derivation

- **Nhịp lặp:** `quét questionIndex qua toàn bộ answers; inner loop quét ba pattern.`. Đây là lý do code dùng block bắt đầu bởi `for (let question = 0; question < answers.length; question++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “pattern[questionIndex % pattern.length] có bằng answers[questionIndex] không.”. Trong dry run `[1,2,3,4,5]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (pattern[question % pattern.length] === answers[question]) {`.
- **Tiến triển:** questionIndex và studentIndex tăng bởi hai vòng for độc lập.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `scores[studentIndex] += 1 chỉ trong nhánh match.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let question = 0; question < answers.length; question++) {`.
- **Cleanup:** không có state tồn đọng; tie được collect sau main loop.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Thi thử:** Condition của scan/simulation phải theo đúng tie-break và thứ tự rule của đề. So sánh strict hay non-strict chỉ đổi khi boundary/tie của bài chứng minh, không vì thói quen viết comparator.

#### 19. Làm bằng tay và brute force executable

Với answers `[1,2,3,4,5]`, pattern người 1 dài 5 khớp cả một vòng. Với input dài hơn, câu thứ
`i` luôn dùng offset `i % pattern.length`; không cần nối thêm bản sao pattern.

```js
function topMockExamScorersBrute(answers) {
  const patterns = [
    [1,2,3,4,5],
    [2,1,2,3,2,4,2,5],
    [3,3,1,1,2,2,4,4,5,5],
  ];
  const repeated = patterns.map((pattern) => {
    const values = [];
    while (values.length < answers.length) values.push(...pattern);
    return values.slice(0, answers.length);
  });
  const scores = repeated.map((values) =>
    values.reduce((score, value, index) => score + Number(value === answers[index]), 0));
  const best = Math.max(...scores);
  return scores.flatMap((score, index) => score === best ? [index + 1] : []);
}
```

Brute materialize ba chuỗi lặp. Bản tối ưu giữ pattern cố định và lookup modulo tại chỗ.

#### 22. Invariant, lỗi lộ diện và recall

Sau q câu, `scores[s]` là số match chính xác trong prefix `[0,q)`. Remainder của phép chia q cho
cycle length là đúng offset sau mọi vòng hoàn chỉnh. Scan winners theo thứ tự tự bảo đảm output tăng.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | --- |
| modulo theo answers length | input dài hơn pattern | theo pattern length |
| chỉ lấy first max | `[1,3,2,4,2]` | `[1,2,3]` |
| trả index 0-based | một câu `[2]` | `[2]` |
