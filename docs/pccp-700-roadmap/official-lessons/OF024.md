# OF024 — Từ điển nguyên âm

- Nguồn đề: [Programmers lesson 84512](https://school.programmers.co.kr/learn/courses/30/lessons/84512?language=javascript)
- Pattern chính: preorder DFS enumeration
- Mức trong bank: TRANSFER / variant

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Từ điển chứa mọi string dài 1..5 dùng `A,E,I,O,U`, sắp xếp từ điển. Trả vị trí 1-based của `word`.

## 02. Bound

Tổng số từ chỉ `5+25+125+625+3125=3905`; DFS enumerate toàn bộ an toàn. Không cần công thức nếu mục tiêu luyện traversal order.

## 03. Brute force

Sinh mọi string, đưa vào array, sort rồi indexOf. Đúng nhưng sort thừa nếu sinh ngay theo lexicographic preorder.

## 04. Bottleneck

Trong dictionary, prefix đứng trước mọi extension của nó: `A`, `AA`, `AAA`... Đây chính là preorder DFS nếu duyệt vowels theo thứ tự.

## 05. Pattern

Tại prefix, lần lượt append A,E,I,O,U; count word mới ngay trước khi recurse sâu hơn. Dừng depth 5 hoặc khi tìm target.

## 06. State

- `prefix` path hiện tại;
- `rank` số từ đã emit;
- `answer`;
- alphabet cố định.

## 07. Transition

`next=prefix+vowel`; rank++; check target; nếu length<5 recurse next. Khi child trả true, propagate để dừng toàn traversal.

## 08. Invariant

Trước mỗi emit, rank bằng số word đứng trước next trong thứ tự từ điển. Preorder đúng vì prefix ngắn đứng trước descendants và sibling vowel được duyệt A→U.

## 09. Complexity

Worst `O(3905*5)` thao tác string, recursion depth 5, space `O(5)` ngoài strings.

## 10. Pseudocode

```text
rank=0
dfs(prefix):
  for vowel in A,E,I,O,U:
    next=prefix+vowel; rank++
    if next==word: save; return true
    if len(next)<5 and dfs(next): return true
  return false
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF024.js](../../../solutions/official/OF024.js).

```js
const VOWELS = ["A", "E", "I", "O", "U"];

function vowelDictionaryRank(word) {
  let rank = 0;
  let answer = 0;

  function dfs(prefix) {
    for (const vowel of VOWELS) {
      const next = prefix + vowel;
      rank++;
      if (next === word) {
        answer = rank;
        return true;
      }
      if (next.length < 5 && dfs(next)) {
        return true;
      }
    }
    return false;
  }

  dfs("");
  return answer;
}
```

## 15. Dry-run

Traversal đầu: `A` rank1, `AA` rank2, `AAA` rank3, `AAAA` rank4, `AAAAA` rank5, `AAAAE` rank6. Vì vậy sample `AAAAE` có rank 6.

## 16. Edge cases

1. `A` rank 1.
2. Word dài 5 ở nhánh sâu.
3. Word bắt đầu U nằm gần cuối.
4. Propagate return để không tiếp tục tăng rank sau khi tìm thấy.

## 17. Lỗi JavaScript thường gặp

- BFS tạo order theo length, không phải dictionary.
- Check target sau recurse, làm prefix đứng sau descendants.
- Recurse khi length đã 5.
- Quên propagate true.
- Sort alphabet sai order.

## 18. Bài transfer cùng pattern

- OF036: binary choice tree, đếm leaf target.
- OF020: permutation và deduplicate prime.
- OF041: DFS path với lexical ordering và used tickets.

Tín hiệu: cần enumerate string theo dictionary trong prefix tree ⇒ preorder DFS với alphabet sorted.

## 19. Làm bằng tay và brute force executable

Preorder ở nhánh đầu là `A, AA, AAA, AAAA, AAAAA, AAAAE, ...`. Prefix phải được ghi nhận trước
mọi extension của nó; đây là điểm phân biệt với BFS theo độ dài.

```js
function vowelDictionaryRankBrute(word) {
  const vowels = ["A", "E", "I", "O", "U"];
  const words = [];

  function generate(prefix) {
    if (prefix.length > 0) words.push(prefix);
    if (prefix.length === 5) return;
    for (const vowel of vowels) {
      generate(prefix + vowel);
    }
  }

  generate("");
  words.sort();
  return words.indexOf(word) + 1;
}
```

Brute force sort lại 3.905 từ. Bản tối ưu sinh đúng lexical preorder nên có thể dừng ngay khi gặp target.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `prefix` | đường từ root tới node hiện tại | chuỗi rỗng |
| `rank` | số từ đã emit | `0` |
| `answer` | rank của target | `0` |
| `next` | child đang xét | `prefix + vowel` |
| giá trị trả về DFS | subtree đã tìm thấy target chưa | boolean |

## 21. Blueprint từ đề đến code

1. Xem mỗi prefix như một node trong cây 5 nhánh.
2. Vì prefix đứng trước extension, chọn preorder chứ không chọn BFS/postorder.
3. Duyệt alphabet theo đúng `A,E,I,O,U` để sibling có lexical order.
4. Tăng rank khi tạo một word, kiểm target trước khi đi sâu.
5. Dừng ở length 5 và truyền `true` ngược lên để dừng toàn traversal.

## 22. Invariant, lỗi lộ diện và recall

Ngay trước khi kiểm `next`, `rank` bằng số word đã xuất trước nó. Preorder bảo đảm toàn bộ subtree
của một vowel được xuất trước sibling vowel tiếp theo, đúng thứ tự từ điển. Khi child trả `true`,
mọi ancestor cũng phải trả ngay; nếu không, rank vẫn tăng sau khi đã tìm đáp án.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| BFS theo length | `"AA"` | 2 |
| check sau khi recurse | `"A"` | 1 |
| recurse quá depth 5 | `"AAAAE"` | 6 |
| không propagate early return | `"E"` | 782 |

Recall: **dictionary của prefix tree ⇒ alphabet sorted + preorder; emit prefix trước descendants.**
