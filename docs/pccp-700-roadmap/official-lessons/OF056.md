# OF056 — Biến đổi số

- Nguồn đề: [Programmers lesson 154538](https://school.programmers.co.kr/learn/courses/30/lessons/154538?language=javascript)
- Pattern chính: BFS trên implicit numeric graph
- Mức trong bank: TRANSFER / BFS-DP state

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Từ `x`, mỗi operation chọn `+n`, `*2` hoặc `*3`. Tìm số operation ít nhất để đạt đúng `y`; không thể trả `-1`. Mọi operation làm số không giảm.

## 02. Bound

State là integer từ x đến y. Graph không cần materialize; mỗi state có tối đa ba neighbor. BFS `O(y-x)` bảo đảm shortest trong graph unweighted.

## 03. Brute force

DFS thử ba choice đến khi vượt y. Có nhiều path tới cùng value, làm lặp exponential và DFS path đầu không chắc shortest.

## 04. Bottleneck

Các expression khác nhau hội tụ cùng number; tương lai từ number đó giống nhau. Mark visited theo value để chỉ xử lý một lần. Mọi edge cost 1 nên BFS layer đầu chạm y là minimum.

## 05. Pattern

Implicit BFS:

```text
dequeue current
generate current+n, current*2, current*3
skip >y or visited
distance[next]=distance[current]+1
```

## 06. State

- queue number và head;
- `distance[value]`, `-1` nghĩa chưa visited;
- upper bound y.

## 07. Transition

Sinh ba neighbor, validate bound trước index array, mark distance lúc enqueue, return ngay khi neighbor là y.

## 08. Invariant

Queue chứa state theo distance không giảm. Khi state được gán distance lần đầu, đó là shortest từ x; mark lúc enqueue ngăn hai parent đưa cùng state vào queue.

## 09. Complexity

Time `O(y-x)` worst case, mỗi state tối đa một lần; space `O(y)`. Với x==y trả 0 trước BFS.

## 10. Pseudocode

```text
if x==y return 0
queue=[x]; distance[x]=0
while queue:
  current=dequeue
  for next in [current+n,current*2,current*3]:
    if next>y or visited: continue
    distance[next]=distance[current]+1
    if next==y return distance[next]
    enqueue next
return -1
```

## 13. Code bước 3 — ghép vòng lặp

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF056.js](../../../solutions/official/OF056.js).

```js
function minimumNumberTransforms(x, y, n) {
  if (x === y) {
    return 0;
  }

  const queue = [x];
  const distance = new Int32Array(y + 1);
  distance.fill(-1);
  distance[x] = 0;
  let head = 0;

  while (head < queue.length) {
    const current = queue[head];
    head += 1;
    const nextValues = [current + n, current * 2, current * 3];

    for (const next of nextValues) {
      if (next > y || distance[next] !== -1) {
        continue;
      }
      distance[next] = distance[current] + 1;
      if (next === y) {
        return distance[next];
      }
      queue.push(next);
    }
  }
  return -1;
}
```

## 15. Dry-run

`x=10,y=40,n=5`: layer 1 có 15,20,30; từ 20 ở layer 2 sinh 40, nên answer 2. Dù DFS có thể đi 10→15→20→25..., BFS vẫn lấy path ngắn nhất.

## 16. Edge cases

1. x==y.
2. Một operation đạt y.
3. Mọi transition đầu vượt y.
4. Cùng state sinh từ nhiều parent.
5. +n với n nhỏ tạo nhiều layer.

## 17. Lỗi JavaScript thường gặp

- Dùng DFS rồi return path đầu.
- Mark visited lúc dequeue, gây duplicate queue.
- Không chặn next>y.
- Dùng `shift()`.
- `Array(y+1).fill([])` cho state phức tạp sẽ alias; typed array tránh vấn đề.

## 19. Làm bằng tay và brute force executable

Với `x=10, y=40, n=5`, layer 0 là 10; layer 1 gồm 15, 20, 30; từ 20 ở layer 2 sinh
40. Hai biểu thức khác nhau có thể tới cùng value, nên value là state cần deduplicate.

```js
function minimumNumberTransformsBrute(x, y, n) {
  let best = Infinity;

  function dfs(current, operations) {
    if (current > y || operations >= best) return;
    if (current === y) {
      best = operations;
      return;
    }
    dfs(current + n, operations + 1);
    dfs(current * 2, operations + 1);
    dfs(current * 3, operations + 1);
  }

  dfs(x, 0);
  return best === Infinity ? -1 : best;
}
```

Brute DFS lặp lại cùng value theo nhiều expression. BFS visited theo value xử lý mỗi state một lần.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `distance[value]` | minimum operations tới value | toàn `-1`, `distance[x]=0` |
| `queue` | value đã discover theo layer | `[x]` |
| `head` | index dequeue | `0` |
| `nextValues` | ba phép biến đổi từ current | `+n`, `*2`, `*3` |

## 21. Blueprint từ đề đến code

1. Xem mỗi integer là node và mỗi operation là edge cost 1.
2. Nhận ra operation chỉ tăng, nên state lớn hơn `y` không thể quay về đáp án.
3. Generate ba neighbor on demand, không dựng graph.
4. Dùng BFS vì cần minimum operations; distance đồng thời là visited.
5. Xử lý `x===y` trước, rồi return ngay khi discover `y`.

## 22. Invariant, lỗi lộ diện và recall

Mọi value trong queue đã có shortest operation count. Vì operation chỉ tăng, bỏ `next > y` là
prune an toàn. Khi cùng value được sinh lần nữa, tương lai của nó không phụ thuộc expression trước,
nên lần sau có thể bỏ.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| quên base `x===y` | `7,7,3` | 0 |
| cho state vượt y vào array | `2,5,4` | -1 |
| không deduplicate value | nhiều đường tới 30 | vẫn xử lý một lần |
| dùng DFS path đầu | `10,40,5` | 2 |

Recall: **minimum operations cost 1 ⇒ BFS trên value; bound trước index; visited là distance.**

## A17. Blueprint đủ trường và Recall ba tầng

```text
OUTPUT: số operation ít nhất biến x thành y, hoặc -1.
PREPARE: state chỉ trong [x,y] vì cả ba operation đều tăng.
GLOBAL STATE: distance array, queue và head.
INIT: distance=-1; distance[x]=0; queue=[x]; head=0.
MAIN LOOP: dequeue current; sinh current+n, current*2, current*3.
CURRENT ITEM: current và từng next value.
PER-ITERATION STATE: nextValues array của current.
CHECK: x===y; next<=y; next unseen; next===y.
BRANCH: out-of-bound/seen continue; discover y return; khác enqueue.
UPDATE: distance[next]=distance[current]+1 trước target check/push.
POINTER MOVEMENT: head tăng riêng; for...of qua ba neighbor.
STOP / RETURN: x===y trả 0; discover y trả distance; queue cạn -1.
CLEANUP: bound trước khi index distance để không đọc ngoài array.
```

- Recall 1: Value là node, ba phép là edge cost 1; BFS và bỏ mọi state vượt y.
- Recall 2: STATE distance/queue → LOOP BFS → CHECK bound/seen/target → UPDATE → RETURN distance/-1.
- Recall 3: Điền `if (next > ___ || distance[next] !== -1) continue`; distance mới `+ ___`.
