# OF056 — Biến đổi số

- Nguồn đề: [Programmers lesson 154538](https://school.programmers.co.kr/learn/courses/30/lessons/154538?language=javascript)
- Pattern chính: BFS trên implicit numeric graph
- Mức trong bank: TRANSFER / BFS-DP state

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Từ `x`, mỗi operation chọn `+n`, `*2` hoặc `*3`. Tìm số operation ít nhất để đạt đúng `y`; không thể trả `-1`. Mọi operation làm số không giảm.

## 02. Bound

State là integer từ x đến y. Graph không cần materialize; mỗi state có tối đa ba neighbor. BFS `O(y-x)` bảo đảm shortest trong graph unweighted.

## 03. Brute force

DFS thử ba choice đến khi vượt y. Có nhiều path tới cùng value, làm lặp exponential và DFS path đầu không chắc shortest.

## 04. Bottleneck

Các expression khác nhau hội tụ cùng number; tương lai từ number đó giống nhau. Mark visited theo value để chỉ xử lý một lần. Mọi edge cost 1 nên BFS layer đầu chạm y là minimum.

## 05. Pattern

Implicit BFS:

```text
dequeue current
generate current+n, current*2, current*3
skip >y or visited
distance[next]=distance[current]+1
```

## 06. State

- queue number và head;
- `distance[value]`, `-1` nghĩa chưa visited;
- upper bound y.

## 07. Transition

Sinh ba neighbor, validate bound trước index array, mark distance lúc enqueue, return ngay khi neighbor là y.

## 08. Invariant

Queue chứa state theo distance không giảm. Khi state được gán distance lần đầu, đó là shortest từ x; mark lúc enqueue ngăn hai parent đưa cùng state vào queue.

## 09. Complexity

Time `O(y-x)` worst case, mỗi state tối đa một lần; space `O(y)`. Với x==y trả 0 trước BFS.

## 10. Pseudocode

```text
if x==y return 0
queue=[x]; distance[x]=0
while queue:
  current=dequeue
  for next in [current+n,current*2,current*3]:
    if next>y or visited: continue
    distance[next]=distance[current]+1
    if next==y return distance[next]
    enqueue next
return -1
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF056.js](../../../solutions/official/OF056.js).

```js
function minimumNumberTransforms(x, y, n) {
  if (x === y) {
    return 0;
  }

  const queue = [x];
  const distance = new Int32Array(y + 1);
  distance.fill(-1);
  distance[x] = 0;
  let head = 0;

  while (head < queue.length) {
    const current = queue[head];
    head += 1;
    const nextValues = [current + n, current * 2, current * 3];

    for (const next of nextValues) {
      if (next > y || distance[next] !== -1) {
        continue;
      }
      distance[next] = distance[current] + 1;
      if (next === y) {
        return distance[next];
      }
      queue.push(next);
    }
  }
  return -1;
}
```

## 16. Edge cases

1. x==y.
2. Một operation đạt y.
3. Mọi transition đầu vượt y.
4. Cùng state sinh từ nhiều parent.
5. +n với n nhỏ tạo nhiều layer.

## 17. Lỗi JavaScript thường gặp

- Dùng DFS rồi return path đầu.
- Mark visited lúc dequeue, gây duplicate queue.
- Không chặn next>y.
- Dùng `shift()`.
- `Array(y+1).fill([])` cho state phức tạp sẽ alias; typed array tránh vấn đề.

### Loop and condition derivation

- **Nhịp lặp:** `dequeue current; sinh current+n, current*2, current*3.`. Đây là lý do code dùng block bắt đầu bởi `while (head < queue.length) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “x===y; next<=y; next unseen; next===y.”. Trong dry run `x=10,y=40,n=5`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (x === y) {`.
- **Tiến triển:** head tăng riêng; for...of qua ba neighbor.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `distance[next]=distance[current]+1 trước target check/push.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `while (head < queue.length) {`.
- **Cleanup:** bound trước khi index distance để không đọc ngoài array.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Biến đổi số:** Base state phải khớp định nghĩa DP; thứ tự loop phải bảo đảm dependency đã tính. Branch không hợp lệ không được ghi đè sentinel hoặc state tốt hơn đã có.

#### 19. Làm bằng tay và brute force executable

Với `x=10, y=40, n=5`, layer 0 là 10; layer 1 gồm 15, 20, 30; từ 20 ở layer 2 sinh
40. Hai biểu thức khác nhau có thể tới cùng value, nên value là state cần deduplicate.

```js
function minimumNumberTransformsBrute(x, y, n) {
  let best = Infinity;

  function dfs(current, operations) {
    if (current > y || operations >= best) return;
    if (current === y) {
      best = operations;
      return;
    }
    dfs(current + n, operations + 1);
    dfs(current * 2, operations + 1);
    dfs(current * 3, operations + 1);
  }

  dfs(x, 0);
  return best === Infinity ? -1 : best;
}
```

Brute DFS lặp lại cùng value theo nhiều expression. BFS visited theo value xử lý mỗi state một lần.
