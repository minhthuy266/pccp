# OF017 — H-Index

- Nguồn đề: [Programmers lesson 42747](https://school.programmers.co.kr/learn/courses/30/lessons/42747?language=javascript)
- Pattern chính: sort descending + rank boundary
- Mức trong bank: TRANSFER / boundary check

## 01. Contract

Tìm h lớn nhất sao cho có ít nhất h paper có citation ít nhất h; các paper còn lại có citation không quá h theo định nghĩa bài.

## 02. Bound

Sort `O(n log n)` rồi scan. Có thể count frequency, nhưng sort boundary dễ chứng minh.

## 03. Brute force

Thử từng h từ 0..n, mỗi lần scan count citation ≥h: `O(n²)`.

## 04. Bottleneck

Sau sort giảm dần, tại index i có `i+1` paper đầu đều ít nhất `sorted[i]`. Điều kiện candidate h=i+1 chỉ cần `sorted[i] >= i+1`.

## 05. Pattern

Sort descending, mở rộng prefix khi citation tại boundary đủ cho prefix size; dừng ở first failure.

## 06. State

`sorted`, `index`, `papers=index+1`, `answer`.

## 07. Transition

Nếu boundary citation ≥ papers, answer=papers; nếu nhỏ, break vì các citation sau còn nhỏ hơn.

## 08. Invariant

Sau index hợp lệ, answer là prefix size lớn nhất đã chứng minh; mọi paper trong prefix có citation ≥answer. First failure loại mọi h lớn hơn do sorted không tăng.

## 09. Complexity

Time `O(n log n)`, space `O(n)` do copy.

## 10. Pseudocode

```text
sort citations descending
answer=0
for i:
  h=i+1
  if citations[i]<h: break
  answer=h
return answer
```

## 11. Code bước 1 — dựng state

```js
const sorted=[...citations].sort((a,b)=>b-a);
```

## 12. Code bước 2 — viết transition

```js
function supportsRank(citation,index) { return citation>=index+1; }
```

## 13. Code bước 3 — ghép vòng lặp

```js
for (let i=0;i<sorted.length;i++) {
  if (!supportsRank(sorted[i],i)) break;
  answer=i+1;
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF017.js](../../../solutions/official/OF017.js).

```js
function hIndex(citations) {
  const sorted=[...citations].sort((a,b)=>b-a);
  let answer=0;
  for (let i=0;i<sorted.length;i++) {
    const papers=i+1;
    if (sorted[i]<papers) break;
    answer=papers;
  }
  return answer;
}
```

## 15. Dry-run

`[3,0,6,1,5]` → `[6,5,3,1,0]`: ranks 1,2,3 pass; rank4 fail vì citation1<4; answer3.

## 16. Edge cases

Toàn zero; mọi citation rất lớn; một paper; boundary equality.

## 17. Lỗi JavaScript thường gặp

Quên numeric comparator; dùng index i thay i+1; tìm citation value thay vì h count; không break tại first failure; mutate input.

## 18. Bài transfer cùng pattern

- OF003: sort rồi adjacent prefix.
- OF015: sort subarray rồi rank lookup.
- OF043: first feasible trên numeric answer.

Tín hiệu: condition liên hệ value sorted tại vị trí với số lượng prefix ⇒ scan rank boundary.

#### 19. Làm tay và brute force

Với `[3,0,6,1,5]`, `h=3` có ba paper đạt ít nhất 3, còn `h=4` chỉ có hai. Brute thử
mọi `h=0..n` rồi đếm lại citations là `O(n²)`. Sort giảm `[6,5,3,1,0]`; tại rank
`papers=index+1`, chỉ cần `sorted[index] >= papers`.

#### 20. State, Blueprint, invariant

| State | Nghĩa | Init |
| --- | --- | --- |
| `sorted` | citations giảm dần, input giữ nguyên | clone+sort |
| `answer` | rank lớn nhất đã chứng minh | `0` |

```text
OUTPUT h; PREPARE sort descending; LOOP index; CURRENT papers=index+1;
CHECK sorted[index] < papers thì break; UPDATE answer=papers; RETURN answer.
```

Prefix đã pass có `papers` phần tử đều ≥ `papers`. Khi first failure xảy ra, value chỉ giảm
còn required rank chỉ tăng, nên mọi rank sau đều fail.
