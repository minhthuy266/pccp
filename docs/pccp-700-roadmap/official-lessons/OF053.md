# OF053 — Tổng dãy con liên tiếp

- Nguồn đề: [Programmers lesson 178870](https://school.programmers.co.kr/learn/courses/30/lessons/178870?language=javascript)
- Pattern chính: positive sliding window / two pointers
- Mức trong bank: CORE / positive two pointers

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Trong dãy số nguyên dương không giảm `sequence`, tìm đoạn liên tiếp có tổng bằng `k`. Nếu nhiều đoạn, chọn đoạn ngắn nhất; nếu vẫn hòa, chọn đoạn có start nhỏ nhất. Trả `[start, end]` theo index 0-based, tính cả hai đầu.

## 02. Bound

Dãy có thể rất dài nên enumerate mọi cặp boundary và tính sum `O(n²)` không phù hợp. Tính dương tạo tính đơn điệu: mở rộng right không làm sum giảm, tăng left không làm sum tăng. Hai pointers chạy `O(n)`.

## 03. Brute force

Với mỗi start, cộng dần đến mọi end, kiểm sum bằng target và giữ candidate tốt nhất. Dù reuse sum trong mỗi start, vẫn có `O(n²)` đoạn.

## 04. Bottleneck

Brute force thử lại nhiều start đã chắc chắn không thể dùng. Khi window sum vượt target và mọi số dương, giữ nguyên left rồi tăng right chỉ làm sum lớn hơn; vì vậy left hiện tại phải bị loại.

Chính monotonicity này cho phép pointers không bao giờ lùi.

## 05. Pattern

Variable window với positive sum:

```text
add sequence[right]
while sum > target: remove sequence[left], left++
if sum == target: evaluate [left, right]
```

Scan right tăng dần; chỉ update khi length nhỏ hơn để tự giữ start sớm hơn khi hòa.

## 06. State

- `left`, `right`: boundary cửa sổ hiện tại;
- `sum`: tổng chính xác `sequence[left..right]`;
- `bestStart`, `bestEnd`, `bestLength`.

`bestLength = Infinity` biểu diễn chưa có candidate.

## 07. Transition

Mỗi right:

1. cộng phần tử mới vào sum;
2. trong khi sum vượt target, trừ phần tử left rồi tăng left;
3. nếu sum bằng target, so độ dài với best;
4. chỉ thay best khi ngắn hơn; candidate bằng độ dài gặp sau không thắng tie start.

## 08. Invariant

Sau vòng `while`, `sum <= target` và bằng đúng tổng đoạn `[left,right]`. Mọi window kết thúc tại `right` có start nhỏ hơn `left` đều có tổng lớn hơn target nên không thể là đáp án.

Mỗi index vào window một lần qua right và rời một lần qua left. Best luôn là candidate tốt nhất trong mọi end đã xử lý theo thứ tự `(length, start)`.

## 09. Complexity

- Time: `O(n)` vì right tăng `n` lần và left tăng tối đa `n` lần.
- Space: `O(1)`.
- Proof phụ thuộc số dương; có số âm thì sum không còn đơn điệu và pattern này có thể sai.

## 10. Pseudocode

```text
left = 0, sum = 0, bestLength = infinity
for right from 0 to n-1:
    sum += sequence[right]
    while sum > target:
        sum -= sequence[left]
        left += 1
    if sum == target:
        length = right-left+1
        if length < bestLength:
            save left, right, length
return saved boundaries
```

## 11. Code bước 1 — dựng state

```js
function createWindowState(sequence) {
  return {
    left: 0,
    sum: 0,
    bestStart: 0,
    bestEnd: sequence.length - 1,
    bestLength: Infinity,
  };
}
```

Contract bảo đảm tồn tại đáp án; fallback boundary sẽ bị thay trước khi return.

## 12. Code bước 2 — viết transition

```js
function shrinkUntilAtMost(sequence, target, state) {
  while (state.sum > target) {
    state.sum -= sequence[state.left];
    state.left++;
  }
}
```

Ta trừ phần tử đang ở left trước rồi mới tăng left để sum tiếp tục khớp window mới.

## 13. Code bước 3 — ghép vòng lặp

```js
function considerCandidate(state, right, target) {
  if (state.sum !== target) return;
  const length = right - state.left + 1;
  if (length < state.bestLength) {
    state.bestLength = length;
    state.bestStart = state.left;
    state.bestEnd = right;
  }
}
```

Không update khi `length === bestLength`, vì scan từ trái sang phải đã lưu start nhỏ hơn.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF053.js](../../../solutions/official/OF053.js).

```js
function shortestSubsequenceWithSum(sequence, target) {
  let left = 0;
  let sum = 0;
  let bestStart = 0;
  let bestEnd = sequence.length - 1;
  let bestLength = Infinity;

  for (let right = 0; right < sequence.length; right++) {
    sum += sequence[right];
    while (sum > target && left <= right) {
      const leavingValue = sequence[left];
      sum -= leavingValue;
      left++;
    }
    if (sum === target) {
      const length = right - left + 1;
      if (length < bestLength) {
        bestLength = length;
        bestStart = left;
        bestEnd = right;
      }
    }
  }
  return [bestStart, bestEnd];
}
```

## 16. Edge cases

1. Một phần tử bằng target.
2. Nhiều đoạn cùng độ dài: giữ start nhỏ nhất.
3. Đáp án là toàn dãy.
4. Duplicate values trong dãy không giảm.
5. Candidate dài xuất hiện trước, candidate ngắn xuất hiện sau: phải replace.

## 17. Lỗi JavaScript thường gặp

- Dùng pattern này khi có số âm; monotonicity không còn đúng.
- Chỉ shrink một lần bằng `if` thay vì `while`.
- Tăng left trước khi trừ `sequence[left]`, làm sum lệch.
- Tính length `right-left` thay vì `+1`.
- Update khi length bằng best và vô tình lấy start muộn hơn.
- Return `[left,right]` cuối loop thay vì best đã lưu.

## 18. Bài transfer cùng pattern

- OF052: fixed window 10, left được xác định bởi size chứ không bởi sum.
- OF058: variable window với Map coverage; shrink khi vẫn đủ loại.
- OF028: inward two pointers trên sorted array, không phải contiguous window.

Tín hiệu: đoạn liên tiếp + số dương + target sum ⇒ window có tính đơn điệu, mỗi pointer chỉ tiến.

### Loop and condition derivation

- **Nhịp lặp:** `for right từ trái sang phải; inner while thu trái khi sum > target.`. Đây là lý do code dùng block bắt đầu bởi `for (let right = 0; right < sequence.length; right++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “sum có vượt target; sau shrink có bằng target; length có nhỏ hơn bestLength.”. Trong dry run `sequence=[1,2,3,4,5]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (sum === target) {`.
- **Tiến triển:** right tăng bởi for; left chỉ tăng trong while và không lùi.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `add entering; subtract leaving trước khi left tăng; save ba best state cùng nhau.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let right = 0; right < sequence.length; right++) {`.
- **Cleanup:** không cần; best giữ candidate đã chốt, window cuối không được trả trực tiếp.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Tổng dãy con liên tiếp:** Boundary inclusive/exclusive và vị trí answer update phải khớp đúng đoạn đang đại diện. Với variable window, chỉ đo answer sau khi validity được phục hồi; với prefix/difference, kiểm tra đúng offset n+1.

#### 19. Problem → Code hoàn chỉnh

**Làm tay:** mở right để cộng số mới; nếu tổng quá lớn, gạch lần lượt số bên trái cho tới khi
tổng `<= target`; bằng target thì ghi candidate. Với `[1,2,3,4,5]`, target 7, khi thêm 4 tổng
10 nên bỏ 1 rồi 2, được đoạn `[3,4]`. Positive là điều kiện sống còn; có số âm thì bỏ left có
thể làm tổng tăng/giảm không dự đoán được.

```js
function shortestSubsequenceBruteForce(sequence, target) {
  let bestStart = 0;
  let bestEnd = sequence.length - 1;
  let bestLength = Infinity;
  for (let start = 0; start < sequence.length; start++) {
    let rangeSum = 0;
    for (let end = start; end < sequence.length; end++) {
      rangeSum += sequence[end];
      if (rangeSum !== target) continue;
      const length = end - start + 1;
      if (length < bestLength) {
        bestStart = start;
        bestEnd = end;
        bestLength = length;
      }
    }
  }
  return [bestStart, bestEnd];
}
```

| State | Kiểu | Lưu gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `left`,`sum` | number | biên trái và tổng window | `0,0` | xuyên loop |
| `bestStart`,`bestEnd`,`bestLength` | number | candidate tốt nhất | full range, `Infinity` | output state |
| `right`,`leavingValue` | number | biên phải/value rời | từ loop/window | iteration |

```text
OUTPUT: [bestStart,bestEnd]; PREPARE: positivity; STATE: left,sum,best; INIT: 0,0,Infinity
LOOP: for right; CURRENT: sequence[right]; CHECK: sum>target / sum===target
BRANCH: while quá lớn; UPDATE: add, rồi subtract leaving và left++; candidate ngắn hơn → save
POINTER: right/left chỉ tiến; STOP: hết input; CLEANUP: không; RETURN: best pair
```

Invariant sau while: sum đúng bằng `[left,right]` và `<=target`; mọi start nhỏ hơn left đã quá
lớn nên bị loại an toàn. Right vào một lần, left ra tối đa một lần: `O(n)` time, `O(1)` space.

**Lỗi/test:** dùng `if` lộ case cần shrink nhiều lần; tăng left trước subtract làm lệch sum;
length quên `+1`; dùng `<=` khi update best phá tie start; input có âm là counterexample; return
window cuối thay best. Recall: `add → while over remove-left → if equal compare length → return best`.
