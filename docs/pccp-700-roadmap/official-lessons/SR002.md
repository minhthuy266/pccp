# SR002 — Nén chuỗi

- Nguồn đề: [Programmers lesson 60057](https://school.programmers.co.kr/learn/courses/30/lessons/60057?language=javascript)
- Coverage: String / Implementation

## 01. Contract

Chọn một unit length cố định, chia string từ trái thành chunks; run chunk giống nhau liên tiếp được ghi `count+chunk`, count1 bỏ. Phần dư giữ nguyên. Tìm compressed length nhỏ nhất trên mọi unit.

## 02. Bound

String ngắn; thử unit `1..floor(n/2)` và scan chunks, khoảng `O(n²)` upper bound đủ.

## 03. Brute force

Thử mọi unit là brute force có kiểm soát; không cần tìm unit bằng greedy.

## 04. Bottleneck

Trong một unit, chỉ cần previous chunk và repetition count. Lỗi thường là không flush run cuối/phần dư.

## 05. Pattern

Run-length encoding theo chunk size; outer loop enumerate unit.

## 06. State

`unit`, `previous`, `repetitions`, accumulated `length`, `best`.

## 07. Transition

Chunk equal ⇒ repetitions++; khác ⇒ flush previous length/count digits, reset. Sau loop flush lần cuối.

## 08. Invariant

Trước chunk mới, accumulated length mô tả đầy đủ các run đã chốt; previous/repetitions mô tả đúng run mở chưa chốt.

## 09. Complexity

Khoảng `O(n²)` time theo implementation slice, `O(n)` transient strings; n nhỏ.

## 10. Pseudocode

```text
best=n
for unit 1..n/2:
  scan chunks; group equal consecutive; sum encoded lengths
  flush last run
  best=min(best,length)
return best
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/SR002.js](../../../solutions/official/SR002.js).

```js
function encodedRunLength(chunk, repetitions) {
  let encodedLength = chunk.length;

  if (repetitions > 1) {
    encodedLength += String(repetitions).length;
  }

  return encodedLength;
}

function compressedLengthForUnit(string, unit) {
  let length = 0;
  let previous = string.slice(0, unit);
  let repetitions = 1;

  for (let start = unit; start < string.length; start += unit) {
    const current = string.slice(start, start + unit);
    if (current === previous) {
      repetitions++;
      continue;
    }
    length += encodedRunLength(previous, repetitions);
    previous = current;
    repetitions = 1;
  }

  length += encodedRunLength(previous, repetitions);
  return length;
}

function shortestCompressedLength(string) {
  if (string.length <= 1) return string.length;
  let best = string.length;
  for (let unit = 1; unit <= Math.floor(string.length / 2); unit++) {
    best = Math.min(best, compressedLengthForUnit(string, unit));
  }
  return best;
}
```

## 15. Dry-run

`aabbaccc`, unit1: `2a2ba3c`, length7. Unit lớn hơn được thử nhưng không thắng.

## 16. Edge cases

Length1; no repetitions; run count≥10; final partial chunk; final repeated run.

## 17. Lỗi JavaScript thường gặp

Không flush cuối; thêm digit `1`; chỉ thử unit1; bỏ phần dư; so overlapping substring thay chunks fixed.

Tín hiệu: compression theo consecutive equal blocks ⇒ state previous+count và explicit final flush.

## 19. Làm bằng tay trước khi code

Với `abcabcab` và unit `3`, cắt từ trái thành `abc | abc | ab`. Hai chunk đầu giống nhau
và đứng liền nhau nên viết `2abc`; `ab` là phần dư nhưng vẫn là chunk cuối cần giữ nguyên.
Chuỗi nén là `2abcab`, dài `6`. Nếu unit `2`, các chunk `ab | ca | bc | ab` không tạo
run; “cùng xuất hiện” không đủ, chúng phải consecutive và theo đúng biên unit.

## 20. Brute force có kiểm soát và dry-run

Enumerate mọi unit chính là brute force đúng bound; bản dễ hiểu xây hẳn chuỗi nén rồi lấy
`.length`:

```js
function shortestCompressedLengthBrute(string) {
  if (string.length <= 1) return string.length;

  let bestLength = string.length;

  for (let unit = 1; unit <= Math.floor(string.length / 2); unit++) {
    let compressed = "";
    let previousChunk = string.slice(0, unit);
    let runCount = 1;

    for (let start = unit; start < string.length; start += unit) {
      const currentChunk = string.slice(start, start + unit);
      if (currentChunk === previousChunk) {
        runCount += 1;
        continue;
      }

      if (runCount > 1) compressed += String(runCount);
      compressed += previousChunk;
      previousChunk = currentChunk;
      runCount = 1;
    }

    if (runCount > 1) compressed += String(runCount);
    compressed += previousChunk;
    bestLength = Math.min(bestLength, compressed.length);
  }

  return bestLength;
}
```

Với unit `3` của `abcabcab`, sau chunk thứ hai run mở là `(abc,2)` nhưng `compressed`
vẫn rỗng. Gặp `ab` thì flush thành `2abc`, mở run `(ab,1)`; sau loop flush lần cuối thành
`2abcab`. Code tối ưu vẫn enumerate unit, nhưng chỉ cộng độ dài thay vì tạo nhiều string tạm.

## 21. Bottleneck chính xác

Không có công thức chọn trước unit tốt nhất: unit thắng phụ thuộc cấu trúc string, nên phải
thử `1..floor(n/2)`. Thứ cần bỏ là việc nối chuỗi output trong mỗi unit. Ta giữ
`compressedLength` và cộng `chunk.length + digits(runCount)` mỗi lần đóng run. Với bound
của bài, tổng công việc có upper bound `O(n²)`; mỗi unit chỉ giữ state scalar ngoài substring tạm.

## 22. Bảng state và init

| State | Kiểu | Lưu chính xác | Init | Vì sao |
| --- | --- | --- | --- | --- |
| `bestLength` | `number` | độ dài nhỏ nhất trong các unit đã hoàn tất | `string.length` | không nén luôn là ứng viên hợp lệ |
| `unit` | `number` | độ dài chunk cố định của lượt ngoài | `1` | unit phải dương |
| `length` | `number` | tổng độ dài của mọi run đã đóng | `0` | chưa flush run nào |
| `previous` | `string` | nội dung run đang mở | chunk đầu | run mở phải có witness |
| `repetitions` | `number` | số chunk liên tiếp trong run đang mở | `1` | chunk đầu đã thuộc run |
| `current` | `string` | chunk tại `start`, có thể là phần dư ngắn | `slice(start,start+unit)` | state mỗi iteration |

## 23. Code Blueprint

```text
OUTPUT: độ dài nén nhỏ nhất qua mọi unit hợp lệ.
PREPARE: nếu length <= 1, trả ngay; bestLength = original length.
GLOBAL STATE: bestLength; unit của outer loop.
INIT: mỗi unit mở run bằng chunk đầu, repetitions=1, length=0.
MAIN LOOP: outer enumerate unit; inner tăng start đúng unit.
CURRENT ITEM: current = slice(start, start+unit).
PER-ITERATION STATE: previous và repetitions của run đang mở.
CHECK: current === previous.
BRANCH: bằng thì tăng count/continue; khác thì flush rồi mở run mới.
UPDATE: length += encodedRunLength(previous, repetitions).
POINTER MOVEMENT: start += unit; outer unit += 1.
STOP / RETURN: sau inner loop flush run cuối; cập nhật min; return bestLength.
CLEANUP: explicit final flush giữ cả run cuối lẫn phần dư.
```

Map sang code: Contract → chỉ cần length; State → run mở + length đã đóng; Loop → unit và
chunk boundaries; Transition → extend hoặc flush/reset; Invariant → mọi run trước đã đóng
đúng một lần; Cleanup → flush cuối; Return → minimum.

## 24. Invariant và chứng minh

Ngay trước khi đọc `current`, `length` là độ dài mã hóa của đúng mọi run đứng trước
`previous`; còn `previous/repetitions` mô tả đầy đủ run duy nhất đang mở. Nếu chunk bằng,
tăng count bảo toàn mô tả run. Nếu khác, helper đóng run cũ đúng một lần và reset run mới
với count `1`. Sau vòng không còn chunk khác để kích hoạt nhánh flush, nên final flush là
bắt buộc. Mỗi unit vì thế cho độ dài đúng; lấy min qua toàn miền unit cho đáp án tối ưu.

## 25. Ma trận lỗi và revealing test

| Lỗi | Test nhỏ | Kết quả đúng | Vì sao lộ lỗi |
| --- | --- | --- | --- |
| quên flush run cuối | `abababab`, unit `2` | `3` (`4ab`) | toàn bộ run kết thúc cùng loop |
| bỏ phần dư ngắn | `abcabcab`, unit `3` | `6` (`2abcab`) | chunk cuối dài dưới unit vẫn phải tính |
| luôn ghi count `1` | `abc`, unit `1` | `3` | `1a1b1c` sai contract |
| count chỉ một chữ số | `aaaaaaaaaaaa`, unit `1` | `3` (`12a`) | prefix count có hai digit |
| so chunk không consecutive | `abcaabca`, unit `2` | `8` | hai `ab` cách nhau không cùng run |
| chỉ thử unit `1` | `ababcdcdababcdcd` | `9` | unit dài hơn mới thắng |
