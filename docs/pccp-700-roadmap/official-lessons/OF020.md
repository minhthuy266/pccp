# OF020 — Tìm số nguyên tố

- Nguồn đề: [Programmers lesson 42839](https://school.programmers.co.kr/learn/courses/30/lessons/42839?language=javascript)
- Pattern chính: permutation backtracking + Set + primality
- Mức trong bank: TRANSFER / variant

## 01. Contract

Từ các chữ số trong string, chọn một hoặc nhiều occurrence và sắp thứ tự để tạo số. Đếm bao nhiêu giá trị số nguyên tố khác nhau. Leading zero có thể tạo cùng numeric value.

## 02. Bound

Số digit rất nhỏ nên tổng partial permutations đủ để DFS. Mỗi candidate kiểm prime tới căn bậc hai.

## 03. Brute force

Sinh mọi permutation cho mọi length rồi kiểm prime. Đây chính là hướng phù hợp theo bound, nhưng phải tránh dùng lại cùng index và deduplicate value.

## 04. Bottleneck

Duplicate digit và leading zero tạo cùng number nhiều lần. Backtracking theo index bảo vệ occurrence; Set numeric value loại kết quả trùng.

## 05. Pattern

Ở mọi prefix, thử từng digit chưa dùng; thêm `Number(next)` vào Set; recurse; restore visited. Sau enumeration, filter prime.

## 06. State

`current` string, `used[index]`, `candidates:Set<number>`; primality helper.

## 07. Transition

Mark index, nối digit, emit candidate, recurse, unmark. Prime check: number≥2 và không có divisor ≤sqrt(number).

## 08. Invariant

Path DFS dùng đúng các index marked một lần. Set chứa mọi numeric value của prefix đã emit, không duplicate. Restore làm sibling nhận state sạch.

## 09. Complexity

Enumeration `O(Σ P(n,k))`; mỗi unique candidate prime test `O(sqrt(value))`; recursion/visited `O(n)`, Set theo số candidate.

## 10. Pseudocode

```text
dfs(current):
  for each unused digit index:
    mark; next=current+digit
    add Number(next)
    dfs(next)
    unmark
count candidates that are prime
```

## 12. Code bước 2 — viết transition

```js
function isPrime(number) {
  if (number<2) return false;
  for (let divisor=2;divisor*divisor<=number;divisor++)
    if (number%divisor===0) return false;
  return true;
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF020.js](../../../solutions/official/OF020.js).

```js
function primePermutationCount(numbers) {
  const digits=[...numbers],used=Array(digits.length).fill(false),candidates=new Set();
  function dfs(current) {
    for (let i=0;i<digits.length;i++) {
      if (used[i]) continue;
      used[i]=true;
      const next=current+digits[i];
      candidates.add(Number(next));
      dfs(next);
      used[i]=false;
    }
  }
  dfs("");
  let count=0; for (const value of candidates) if (isPrime(value)) count++;
  return count;
}
```

## 15. Dry-run

`"011"` sinh string `"011"`, `"11"`, ...; `Number("011")` và `Number("11")` cùng 11 nên Set đếm một. Prime distinct là 11 và 101, answer 2.

## 16. Edge cases

Toàn zero; duplicate digits; number 1; leading zero; prime hai chữ số từ đảo order.

## 17. Lỗi JavaScript thường gặp

Visited theo digit value làm mất duplicate occurrence; coi 1 là prime; test divisor tới number; Set string không gộp leading zero; quên restore.
