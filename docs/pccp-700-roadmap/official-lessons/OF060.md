# OF060 — Tòa nhà không bị phá

- Nguồn đề: [Programmers lesson 92344](https://school.programmers.co.kr/learn/courses/30/lessons/92344?language=javascript)
- Pattern chính: 2D difference + prefix reconstruction
- Mức trong bank: TRANSFER / difference array

## 01. Contract

Nhiều skill cộng/trừ cùng degree trên rectangle inclusive. Sau tất cả skill, đếm cell có durability >0.

## 02. Bound

Update từng cell cho từng skill là `O(SK*RC)`. Four-corner difference cho `O(SK+RC)`.

## 03. Brute force

Với mỗi skill, nested loop rectangle và mutate board; đúng nhưng TLE.

## 04. Bottleneck

Mỗi rectangle có delta đồng nhất. Ghi thay đổi tại bốn corner để prefix sums lan delta vào đúng vùng.

## 05. Pattern

Inclusive rectangle `[r1..r2,c1..c2]`:

```text
diff[r1][c1]+=d; diff[r1][c2+1]-=d
diff[r2+1][c1]-=d; diff[r2+1][c2+1]+=d
```

Prefix horizontal rồi vertical.

## 06. State

Difference `(rows+1)×(cols+1)`, signed delta, answer.

## 07. Transition

Attack delta negative, heal positive. Sau mọi event, accumulate rows và columns; add reconstructed delta to board cell.

## 08. Invariant

Bốn corner làm delta xuất hiện từ top-left và bị hủy ngoài right/bottom. Sau hai prefix pass, `difference[r][c]` bằng tổng mọi skill covering cell đó.

## 09. Complexity

Time `O(SK+RC)`, space `O(RC)`.

## 10. Pseudocode

```text
for skill: write four corners
prefix every row
prefix every column
count board+diff > 0
```

## 11. Code bước 1 — dựng state

```js
const difference=Array.from({length:rows+1},()=>new Int32Array(columns+1));
```

## 12. Code bước 2 — viết transition

```js
difference[r1][c1]+=delta;
difference[r1][c2+1]-=delta;
difference[r2+1][c1]-=delta;
difference[r2+1][c2+1]+=delta;
```

## 13. Code bước 3 — ghép vòng lặp

```js
for (let row=0;row<=rows;row++)
  for (let column=1;column<=columns;column++) difference[row][column]+=difference[row][column-1];
```

Sau đó làm pass dọc tương tự.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF060.js](../../../solutions/official/OF060.js).

```js
function intactBuildingCount(board, skills) {
  const rows = board.length;
  const columns = board[0].length;
  const difference = Array.from({ length: rows + 1 }, () => new Int32Array(columns + 1));

  for (const [type, row1, column1, row2, column2, degree] of skills) {
    const delta = type === 1 ? -degree : degree;
    difference[row1][column1] += delta;
    difference[row1][column2 + 1] -= delta;
    difference[row2 + 1][column1] -= delta;
    difference[row2 + 1][column2 + 1] += delta;
  }

  for (let row = 0; row <= rows; row++) {
    for (let column = 1; column <= columns; column++) {
      difference[row][column] += difference[row][column - 1];
    }
  }
  for (let column = 0; column <= columns; column++) {
    for (let row = 1; row <= rows; row++) {
      difference[row][column] += difference[row - 1][column];
    }
  }

  let answer = 0;
  for (let row = 0; row < rows; row++) {
    for (let column = 0; column < columns; column++) {
      if (board[row][column] + difference[row][column] > 0) answer++;
    }
  }
  return answer;
}
```

## 15. Dry-run

## 16. Edge cases

Rectangle toàn board; một cell; attack làm durability đúng0 (không sống); skills overlap; row/column cuối.

## 17. Lỗi JavaScript thường gặp

Thiếu extra row/column; sai dấu corner chéo; chỉ prefix một chiều; type attack/heal đảo dấu; count `>=0` thay `>0`; alias rows bằng fill.

### Loop and condition derivation

- **Nhịp lặp:** `ghi bốn corner cho skills; prefix theo row; prefix theo column; scan board.`. Đây là lý do code dùng block bắt đầu bởi `for (const [type, row1, column1, row2, column2, degree] of skills) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “skill type để chọn dấu; cuối cùng board[row][column] + difference > 0.”. Trong dry run `board=[[1]], skills=[[1,0,0,0,0,1]]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (board[row][column] + difference[row][column] > 0) answer++;`.
- **Tiến triển:** các for loop đi tăng theo skill, row và column; dependency prefix đã sẵn.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `bốn corner với dấu + - - +; hai prefix pass; cộng answer.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let row = 0; row <= rows; row++) {`.
- **Cleanup:** extra border chỉ hấp thụ boundary event, không được tính vào output.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Tòa nhà không bị phá:** Boundary inclusive/exclusive và vị trí answer update phải khớp đúng đoạn đang đại diện. Với variable window, chỉ đo answer sau khi validity được phục hồi; với prefix/difference, kiểm tra đúng offset n+1.

#### 19. Problem → Code hoàn chỉnh

**Làm tay:** thay vì tô mọi cell của rectangle, đặt bốn “công tắc”: bật delta ở top-left,
tắt sau right, tắt sau bottom, rồi bật lại ở corner chéo vì vùng ngoài đã bị trừ hai lần. Prefix
ngang lan theo cột; prefix dọc lan theo hàng và khôi phục đúng rectangle.

```js
function intactBuildingCountBruteForce(board, skills) {
  const durability = board.map((row) => row.slice());
  for (const skill of skills) {
    const [type, row1, column1, row2, column2, degree] = skill;
    const delta = type === 1 ? -degree : degree;
    for (let row = row1; row <= row2; row++) {
      for (let column = column1; column <= column2; column++) {
        durability[row][column] += delta;
      }
    }
  }
  let answer = 0;
  for (const row of durability) {
    for (const value of row) if (value > 0) answer++;
  }
  return answer;
}
```

Brute force đúng nhưng mỗi skill chạm mọi cell rectangle: `O(SK*R*C)`. Difference chỉ ghi bốn
corner `O(1)` mỗi skill, rồi reconstruct một lần.

| State | Kiểu | Lưu gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `difference` | `(R+1)x(C+1)` | boundary delta chưa/đã prefix | zeros, extra border | toàn hàm |
| `delta` | number | attack âm/heal dương | từ skill | mỗi skill |
| `answer` | number | cell cuối >0 | `0` | output |

```text
OUTPUT: alive count; PREPARE: difference extra row/column; STATE: diff,answer
INIT: all zero, answer=0; LOOP: skills → row prefix → column prefix → cells
CURRENT: skill/cell; CHECK: type, final durability>0
BRANCH: attack negative/heal positive; UPDATE: four corners, two prefix passes, count
POINTER: for loops theo biên rõ; STOP: hết cells; CLEANUP: board+diff; RETURN: answer
```

Invariant sau hai prefix pass: `difference[r][c]` bằng tổng delta của đúng mọi rectangle phủ
cell đó. Complexity `O(SK+R*C)` time, `O(R*C)` space. Extra border làm `r2+1,c2+1` luôn hợp lệ.

**Dry run một cell:** `+d` tại `(0,0)`, `-d` ở `(0,1)` và `(1,0)`, `+d` ở `(1,1)`; hai
prefix khiến chỉ cell `(0,0)` nhận d. **Lỗi/test:** thiếu border khi rectangle chạm cuối; corner
chéo sai dấu; chỉ prefix ngang; attack/heal đảo dấu; count `>=0`; dùng `fill(sameRow)` alias.
Recall: `four corners → prefix rows → prefix columns → board+diff > 0`.
