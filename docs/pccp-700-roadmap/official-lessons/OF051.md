# OF051 — Game gắp thú

- Nguồn đề: [Programmers lesson 64061](https://school.programmers.co.kr/learn/courses/30/lessons/64061?language=javascript)
- Pattern chính: matrix scan + mutation + stack reduction
- Mức trong bank: CORE / implementation integration

Tài liệu này diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

`board` là ma trận vuông. `0` là ô trống; số dương biểu diễn loại thú. Mỗi `move` chọn một cột theo số thứ tự 1-based. Cần lấy đúng con thú khác `0` đầu tiên khi quét từ trên xuống; cột rỗng thì move không làm gì.

Thú đã lấy biến mất khỏi board và được đặt lên đỉnh giỏ. Nếu nó giống đỉnh giỏ cũ, hai con biến mất. Trả tổng số thú đã biến mất, tức mỗi lần ghép cặp cộng `2`.

## 02. Bound

Theo bài official, board nhỏ và số move hữu hạn; quét tối đa toàn bộ chiều cao cho mỗi move là an toàn.

Với `n = board.length`, `m = moves.length`, mục tiêu đơn giản `O(m*n)` phù hợp. Stack có tối đa `m` phần tử.

## 03. Brute force

Cho từng move:

1. quét mọi row trong cột;
2. tìm doll đầu tiên;
3. xóa khỏi board;
4. thêm vào một mảng basket;
5. sau mỗi lần thêm, quét hoặc mô phỏng lại basket để tìm cặp liền nhau.

Cách này đúng nhưng bước 5 có thể lặp lại việc kiểm tra cả basket.

## 04. Bottleneck

Cặp chỉ có thể mới xuất hiện giữa doll vừa lấy và phần tử đang ở đỉnh basket. Không cần quét lại toàn bộ basket.

Hai lỗi implementation độc lập còn nguy hiểm hơn hiệu năng:

- dùng `board[row][column] === 0` chỉ **so sánh**, không xóa doll;
- quên `break`, khiến một move lấy nhiều doll trong cùng cột.

## 05. Pattern

Kết hợp hai pattern:

```text
matrix column scan: tìm first non-zero
stack reduction: current giống top → pop; khác → push
```

Mutation board phải xảy ra đúng sau khi đọc doll và trước khi xử lý move tiếp theo.

## 06. State

- `board`: trạng thái các doll còn lại;
- `basket`: stack các doll chưa bị ghép;
- `removed`: số doll đã biến mất;
- `column = move - 1`;
- vòng `row` tìm first non-zero.

## 07. Transition

Khi tìm thấy `doll`:

```text
doll = board[row][column]
board[row][column] = 0
if basket.top == doll:
    basket.pop()
    removed += 2
else:
    basket.push(doll)
break row loop
```

Nếu quét hết cột mà không thấy doll, không state nào đổi.

## 08. Invariant

Trước mỗi move:

- board chứa đúng các doll chưa được lấy;
- basket là kết quả đã rút gọn hoàn toàn của chuỗi doll lấy được từ các move trước;
- `removed` bằng hai lần số cặp đã pop.

Trong vòng row, mọi ô phía trên row hiện tại của cột đều bằng `0`. Doll khác `0` đầu tiên chính là doll contract yêu cầu.

## 09. Complexity

- Time: `O(m*n)` trong trường hợp mỗi move quét hết một cột.
- Space: `O(m)` cho basket.
- Mỗi doll vào basket tối đa một lần và bị pop tối đa một lần.

Có thể tiền xử lý mỗi cột thành stack để gần `O(n²+m)`, nhưng bound không yêu cầu và implementation phức tạp hơn.

## 10. Pseudocode

```text
basket = empty stack
removed = 0
for move in moves:
    column = move - 1
    for row from top to bottom:
        if cell is zero: continue
        doll = cell
        set cell to zero
        if basket top equals doll:
            pop basket
            removed += 2
        else:
            push doll
        break
return removed
```

## 12. Code bước 2 — viết transition lấy doll

```js
function takeTopDoll(board, column) {
  for (let row = 0; row < board.length; row++) {
    if (board[row][column] === 0) continue;

    const doll = board[row][column];
    board[row][column] = 0;
    return doll;
  }

  return null;
}
```

Phải là phép gán `=`. Biểu thức `board[row][column] === 0` chỉ trả boolean rồi bị bỏ đi, nên lần sau vẫn lấy lại doll cũ.

## 13. Code bước 3 — ghép stack reduction

```js
function placeInBasket(basket, doll) {
  if (basket.length > 0 && basket.at(-1) === doll) {
    basket.pop();
    return 2;
  }

  basket.push(doll);
  return 0;
}
```

Với mỗi move, gọi `takeTopDoll`; nếu nhận `null` thì bỏ qua, nếu có doll thì cộng kết quả `placeInBasket`.

## 14. Code hoàn chỉnh

Code executable nằm tại [solutions/official/OF051.js](../../../solutions/official/OF051.js).

```js
function craneGame(board, moves) {
  const basket = [];
  let removedDollCount = 0;

  for (const move of moves) {
    const column = move - 1;

    for (let row = 0; row < board.length; row++) {
      const currentCell = board[row][column];
      const cellIsEmpty = currentCell === 0;
      if (cellIsEmpty) {
        continue;
      }

      const pickedDoll = currentCell;
      board[row][column] = 0;

      const basketIsNotEmpty = basket.length > 0;
      const matchesBasketTop = basketIsNotEmpty && basket.at(-1) === pickedDoll;
      if (matchesBasketTop) {
        basket.pop();
        removedDollCount += 2;
      } else {
        basket.push(pickedDoll);
      }

      // Một move chỉ được lấy con thú đầu tiên còn lại trong cột.
      break;
    }
  }

  return removedDollCount;
}
```

## 15. Dry-run

Xét hai lần chọn liên tiếp lấy được doll `4`, rồi `4`:

| Event | Basket trước | Action | Basket sau | removed |
|---|---|---|---|---:|
| doll `4` đầu | `[]` | top khác/rỗng → push | `[4]` | 0 |
| doll `4` sau | `[4]` | top giống → pop | `[]` | 2 |

Với sample official đầy đủ, các move tạo hai lần pop nên kết quả là `4`, không phải `2`.

Nếu viết `board[row][column] === 0`, doll đầu cột không bị xóa. Những lần chọn lại cột đó có thể lấy lại cùng doll, làm chuỗi basket và answer sai.

## 16. Edge cases

1. Chọn cột toàn `0`: không push, không tăng answer.
2. Board `1×1`, chọn cùng cột nhiều lần: chỉ lần đầu có doll.
3. Hai doll giống nhau liên tiếp: cộng đúng `2`, không phải `1`.
4. Phản ứng dây chuyền: sau pop, doll tương lai có thể ghép với top mới; invariant stack tự xử lý.
5. Nhiều `0` phía trên doll: phải `continue`, không `break`.

## 17. Lỗi JavaScript thường gặp

- `board[row][column] === 0` thay vì `board[row][column] = 0`.
- Quên `move - 1`.
- Quên `break` sau khi lấy doll.
- Gặp `0` thì `break`, khiến không tìm xuống dưới.
- Đọc `basket[-1]`: JavaScript trả `undefined`; dùng `basket.at(-1)` hoặc `basket[basket.length - 1]`.
- `answer++` khi pop: đề đếm doll biến mất nên phải `+= 2`.
- Không nhận ra hàm mutate `board`; nếu test lại cùng object phải clone trước.

## 18. Bài transfer cùng pattern

- OF006: output array đóng vai trò stack để loại duplicate liên tiếp.
- OF008: stack giữ opening chưa được ghép.
- OF027: monotonic stack kết hợp greedy deletion budget.
- OF061: stack giữ các index chưa tìm được đáp án.
- SR003: rotation/deque ở ngoài, matching stack ở trong.

Tín hiệu cần nhớ: nếu phần tử mới chỉ tương tác với phần tử gần nhất còn sống, thử mô hình stack trước.

## 19. Tự dựng code từ hai transition độc lập

### Làm bằng tay và brute force

Với mỗi move, dùng ngón tay quét đúng cột từ trên xuống. Gặp ô khác `0` đầu tiên thì lấy con
thú, gạch ô đó thành `0`, rồi dừng quét. Sau đó mới nhìn giỏ: giống top thì bỏ top và con mới;
khác top thì đặt con mới lên giỏ. Cột rỗng không làm thay đổi state nào.

```js
function craneGameBruteForce(board, moves) {
  const pickedDolls = [];
  for (const move of moves) {
    const column = move - 1;
    for (let row = 0; row < board.length; row++) {
      if (board[row][column] === 0) continue;
      pickedDolls.push(board[row][column]);
      board[row][column] = 0;
      break;
    }
  }

  let changed = true;
  let removedDollCount = 0;
  while (changed) {
    changed = false;
    for (let index = 1; index < pickedDolls.length; index++) {
      if (pickedDolls[index - 1] !== pickedDolls[index]) continue;
      pickedDolls.splice(index - 1, 2);
      removedDollCount += 2;
      changed = true;
      break;
    }
  }
  return removedDollCount;
}
```

Brute force tách “lấy thú” và “xóa cặp” nên đúng, nhưng liên tục scan/splice lại giỏ. Cặp mới
chỉ có thể xuất hiện giữa `pickedDoll` và top đang sống; stack xử lý ngay trong `O(1)`.

### State và init

| State | Kiểu | Lưu chính xác gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `board` | matrix | thú chưa được lấy | input mutable | xuyên mọi move |
| `basket` | number[] | chuỗi thú đã rút gọn hoàn toàn | `[]` | xuyên mọi move |
| `removedDollCount` | number | tổng số thú đã pop theo cặp | `0` | output state |
| `column` | number | cột 0-based của move | `move-1` | mỗi move |
| `currentCell`,`pickedDoll` | number | ô đang đọc/thú vừa lấy | từ board | mỗi row/move |

### Transition, invariant và loop choice

Outer `for` dùng vì “với từng move”. Inner `for` dùng vì “quét row từ trên xuống”. `break`
bắt buộc vì một move chỉ lấy một con. Stack không cần inner `while`: một doll mới chỉ tạo tối
đa một cặp với top hiện tại.

```text
OUTPUT: removedDollCount; PREPARE: basket; GLOBAL STATE: board,basket,count
INIT: basket=[], count=0; MAIN LOOP: for move, bên trong for row
CURRENT ITEM: currentCell; PER-ITERATION STATE: column,pickedDoll,matchesBasketTop
CHECK: cell khác 0? pickedDoll có bằng basket top?
BRANCH: empty → continue; match → pop+2; khác → push
UPDATE: cell=0 trước xử lý basket.
POINTER MOVEMENT: row tự tăng; break ngay sau khi lấy đúng một doll cho move.
STOP / RETURN: hết moves; CLEANUP: không; RETURN: removedDollCount
```

Trước mỗi move, board chứa đúng thú chưa lấy; basket là kết quả rút gọn của mọi doll trước;
count bằng hai lần số pop. Gán cell về 0 bảo toàn board state; push/pop bảo toàn basket đã rút gọn.

| Move event | Basket trước | Update | Basket sau | Count |
| --- | --- | --- | --- | ---: |
| lấy 4 | `[]` | push | `[4]` | 0 |
| cột rỗng | `[4]` | không đổi | `[4]` | 0 |
| lấy 4 | `[4]` | pop, `+2` | `[]` | 2 |

Time `O(m*n)` do mỗi move có thể quét n row; mỗi doll push tối đa một và pop tối đa một.
Basket tối đa `O(m)`. Tiền xử lý cột thành stack nhanh hơn nhưng phức tạp và không cần theo bound.

- Logic: dùng `Set` cho basket; chuỗi thứ tự/cặp bị mất.
- Off-by-one: quên `move-1`; move 1 phải đọc column 0.
- Check/update: viết `=== 0` thay cho `= 0`; chọn lại cột sẽ lấy cùng doll.
- Init: `removedDollCount=1`; mọi answer lệch.
- Hidden: cột toàn 0 và nhiều 0 trên top; phải continue row, không break.
- Performance: scan/splice toàn basket sau từng move.

```text
Recall 1: scan first non-zero → set zero → compare top → pop+2 hoặc push → break.
Recall 2: STATE board/basket/count; LOOP moves/rows; CHECK cell/top; UPDATE; RETURN count.
Recall 3: board[row][column] = ____; if (basket.at(-1) ____ picked) { ____; count += ____; }
OUT: removed count; LIMIT: O(mn) đủ; HAND: gạch board rồi xử lý giỏ
BRUTE: lấy hết rồi scan/splice cặp; SLOW: rescan basket; PATTERN: matrix scan + stack
STATE + INIT: basket=[],count=0; LOOP + INVARIANT: basket luôn reduced
UPDATE + STOP: mutate cell, push/pop, break row
```
