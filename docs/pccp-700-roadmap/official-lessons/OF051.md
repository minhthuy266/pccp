# OF051 — Game gắp thú

- Nguồn đề: [Programmers lesson 64061](https://school.programmers.co.kr/learn/courses/30/lessons/64061?language=javascript)
- Pattern chính: matrix scan + mutation + stack reduction
- Mức trong bank: CORE / implementation integration

Tài liệu này diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

`board` là ma trận vuông. `0` là ô trống; số dương biểu diễn loại thú. Mỗi `move` chọn một cột theo số thứ tự 1-based. Cần lấy đúng con thú khác `0` đầu tiên khi quét từ trên xuống; cột rỗng thì move không làm gì.

Thú đã lấy biến mất khỏi board và được đặt lên đỉnh giỏ. Nếu nó giống đỉnh giỏ cũ, hai con biến mất. Trả tổng số thú đã biến mất, tức mỗi lần ghép cặp cộng `2`.

## 02. Bound

Theo bài official, board nhỏ và số move hữu hạn; quét tối đa toàn bộ chiều cao cho mỗi move là an toàn.

Với `n = board.length`, `m = moves.length`, mục tiêu đơn giản `O(m*n)` phù hợp. Stack có tối đa `m` phần tử.

## 03. Brute force

Cho từng move:

1. quét mọi row trong cột;
2. tìm doll đầu tiên;
3. xóa khỏi board;
4. thêm vào một mảng basket;
5. sau mỗi lần thêm, quét hoặc mô phỏng lại basket để tìm cặp liền nhau.

Cách này đúng nhưng bước 5 có thể lặp lại việc kiểm tra cả basket.

## 04. Bottleneck

Cặp chỉ có thể mới xuất hiện giữa doll vừa lấy và phần tử đang ở đỉnh basket. Không cần quét lại toàn bộ basket.

Hai lỗi implementation độc lập còn nguy hiểm hơn hiệu năng:

- dùng `board[row][column] === 0` chỉ **so sánh**, không xóa doll;
- quên `break`, khiến một move lấy nhiều doll trong cùng cột.

## 05. Pattern

Kết hợp hai pattern:

```text
matrix column scan: tìm first non-zero
stack reduction: current giống top → pop; khác → push
```

Mutation board phải xảy ra đúng sau khi đọc doll và trước khi xử lý move tiếp theo.

## 06. State

- `board`: trạng thái các doll còn lại;
- `basket`: stack các doll chưa bị ghép;
- `removed`: số doll đã biến mất;
- `column = move - 1`;
- vòng `row` tìm first non-zero.

## 07. Transition

Khi tìm thấy `doll`:

```text
doll = board[row][column]
board[row][column] = 0
if basket.top == doll:
    basket.pop()
    removed += 2
else:
    basket.push(doll)
break row loop
```

Nếu quét hết cột mà không thấy doll, không state nào đổi.

## 08. Invariant

Trước mỗi move:

- board chứa đúng các doll chưa được lấy;
- basket là kết quả đã rút gọn hoàn toàn của chuỗi doll lấy được từ các move trước;
- `removed` bằng hai lần số cặp đã pop.

Trong vòng row, mọi ô phía trên row hiện tại của cột đều bằng `0`. Doll khác `0` đầu tiên chính là doll contract yêu cầu.

## 09. Complexity

- Time: `O(m*n)` trong trường hợp mỗi move quét hết một cột.
- Space: `O(m)` cho basket.
- Mỗi doll vào basket tối đa một lần và bị pop tối đa một lần.

Có thể tiền xử lý mỗi cột thành stack để gần `O(n²+m)`, nhưng bound không yêu cầu và implementation phức tạp hơn.

## 10. Pseudocode

```text
basket = empty stack
removed = 0
for move in moves:
    column = move - 1
    for row from top to bottom:
        if cell is zero: continue
        doll = cell
        set cell to zero
        if basket top equals doll:
            pop basket
            removed += 2
        else:
            push doll
        break
return removed
```

## 12. Code bước 2 — viết transition lấy doll

```js
function takeTopDoll(board, column) {
  for (let row = 0; row < board.length; row++) {
    if (board[row][column] === 0) continue;

    const doll = board[row][column];
    board[row][column] = 0;
    return doll;
  }

  return null;
}
```

Phải là phép gán `=`. Biểu thức `board[row][column] === 0` chỉ trả boolean rồi bị bỏ đi, nên lần sau vẫn lấy lại doll cũ.

## 13. Code bước 3 — ghép stack reduction

```js
function placeInBasket(basket, doll) {
  if (basket.length > 0 && basket.at(-1) === doll) {
    basket.pop();
    return 2;
  }

  basket.push(doll);
  return 0;
}
```

Với mỗi move, gọi `takeTopDoll`; nếu nhận `null` thì bỏ qua, nếu có doll thì cộng kết quả `placeInBasket`.

## 14. Code hoàn chỉnh

Code executable nằm tại [solutions/official/OF051.js](../../../solutions/official/OF051.js).

```js
function craneGame(board, moves) {
  const basket = [];
  let removed = 0;

  for (const move of moves) {
    const column = move - 1;

    for (let row = 0; row < board.length; row++) {
      if (board[row][column] === 0) continue;

      const doll = board[row][column];
      board[row][column] = 0;

      if (basket.length > 0 && basket.at(-1) === doll) {
        basket.pop();
        removed += 2;
      } else {
        basket.push(doll);
      }

      break;
    }
  }

  return removed;
}
```

## 15. Dry-run

Xét hai lần chọn liên tiếp lấy được doll `4`, rồi `4`:

| Event | Basket trước | Action | Basket sau | removed |
|---|---|---|---|---:|
| doll `4` đầu | `[]` | top khác/rỗng → push | `[4]` | 0 |
| doll `4` sau | `[4]` | top giống → pop | `[]` | 2 |

Với sample official đầy đủ, các move tạo hai lần pop nên kết quả là `4`, không phải `2`.

Nếu viết `board[row][column] === 0`, doll đầu cột không bị xóa. Những lần chọn lại cột đó có thể lấy lại cùng doll, làm chuỗi basket và answer sai.

## 16. Edge cases

1. Chọn cột toàn `0`: không push, không tăng answer.
2. Board `1×1`, chọn cùng cột nhiều lần: chỉ lần đầu có doll.
3. Hai doll giống nhau liên tiếp: cộng đúng `2`, không phải `1`.
4. Phản ứng dây chuyền: sau pop, doll tương lai có thể ghép với top mới; invariant stack tự xử lý.
5. Nhiều `0` phía trên doll: phải `continue`, không `break`.

## 17. Lỗi JavaScript thường gặp

- `board[row][column] === 0` thay vì `board[row][column] = 0`.
- Quên `move - 1`.
- Quên `break` sau khi lấy doll.
- Gặp `0` thì `break`, khiến không tìm xuống dưới.
- Đọc `basket[-1]`: JavaScript trả `undefined`; dùng `basket.at(-1)` hoặc `basket[basket.length - 1]`.
- `answer++` khi pop: đề đếm doll biến mất nên phải `+= 2`.
- Không nhận ra hàm mutate `board`; nếu test lại cùng object phải clone trước.
