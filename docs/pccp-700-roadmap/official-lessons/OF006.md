# OF006 — Không thích số giống nhau

- Nguồn đề: [Programmers lesson 12906](https://school.programmers.co.kr/learn/courses/30/lessons/12906?language=javascript)
- Pattern chính: prefix reduction / output-as-stack
- Mức trong bank: TRANSFER / warmup

## 01. Contract

Từ mảng số, xóa phần tử trùng **liên tiếp**, giữ một đại diện mỗi run và giữ thứ tự. Duplicate cách nhau phải được giữ.

## 02. Bound

Một scan `O(n)` là tối ưu vì phải đọc mọi phần tử.

## 03. Brute force

Lặp tìm cặp adjacent bằng nhau rồi splice đến khi ổn định; có thể `O(n²)` do scan/dịch mảng.

## 04. Bottleneck

Quyết định giữ current chỉ phụ thuộc phần tử cuối đã giữ, không phụ thuộc toàn output.

## 05. Pattern

Output đóng vai trò stack: top khác current hoặc output rỗng thì push; giống thì skip.

## 06. State

`reduced` là kết quả của prefix đã đọc; `reduced.at(-1)` là đại diện run cuối.

## 07. Transition

Với mỗi value: `empty || top !== value` ⇒ push; ngược lại không đổi.

## 08. Invariant

Sau mỗi phần tử, reduced bằng chính xác mảng prefix sau khi nén từng run liên tiếp thành một value.

## 09. Complexity

Time `O(n)`, output space `O(n)` worst case.

## 10. Pseudocode

```text
result=[]
for value:
  if result empty or top != value: push value
return result
```

## 11. Code bước 1 — dựng state

```js
const reduced=[];
```

## 12. Code bước 2 — viết transition

```js
function beginsNewRun(reduced,value) {
  return reduced.length===0 || reduced.at(-1)!==value;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
for (const value of array) if (beginsNewRun(reduced,value)) reduced.push(value);
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF006.js](../../../solutions/official/OF006.js).

```js
function removeConsecutiveDuplicates(array) {
  const reduced = [];

  for (const currentValue of array) {
    const outputIsEmpty = reduced.length === 0;
    if (outputIsEmpty) {
      reduced.push(currentValue);
      continue;
    }

    const previousKeptValue = reduced.at(-1);
    const beginsNewRun = previousKeptValue !== currentValue;
    if (beginsNewRun) {
      reduced.push(currentValue);
    }
  }

  return reduced;
}
```

## 15. Dry-run

`[1,1,2,1]`: push1, skip1, push2, push1 ⇒ `[1,2,1]`; Set sẽ sai thành `[1,2]`.

## 16. Edge cases

Một run dài; không duplicate; duplicate cách nhau; một phần tử.

## 17. Lỗi JavaScript thường gặp

Dùng Set; so current với input trước thay vì output top trong biến thể reduction; splice input khi iterate; quên return array.

## 18. Bài transfer cùng pattern

- OF051: top giống thì pop thay vì skip.
- OF008: prefix state là balance/opening.
- OF027: monotonic reduction có deletion budget.

Tín hiệu: output prefix chỉ cần tương tác với phần tử sống cuối cùng ⇒ output-as-stack.

## 19. Tự đi từ đề đến code

### Làm bằng tay

Với `[1,1,2,2,1]`, đừng nghĩ “xóa mọi số trùng”. Hãy đọc lần lượt:

1. output đang rỗng nên giữ số `1` đầu tiên;
2. số `1` tiếp theo giống số vừa giữ nên bỏ qua;
3. số `2` khác số vừa giữ nên bắt đầu một run mới;
4. số `2` tiếp theo thuộc cùng run nên bỏ qua;
5. số `1` cuối khác top `2`, vì vậy **phải giữ**. Kết quả là `[1,2,1]`.

Điểm quan trọng: duplicate cách nhau không bị xóa. Vì vậy `Set` không đúng contract.

### Brute force đầy đủ

```js
function removeConsecutiveDuplicatesBruteForce(array) {
  const copied = array.slice();
  let index = 1;

  while (index < copied.length) {
    const previousValue = copied[index - 1];
    const currentValue = copied[index];

    if (previousValue === currentValue) {
      copied.splice(index, 1);
      // Không tăng index: sau splice, phần tử mới vừa trượt vào index này
      // vẫn phải được so với đại diện của run.
      continue;
    }

    index++;
  }

  return copied;
}
```

Brute force đúng vì mỗi lần splice chỉ xóa một phần tử có đại diện bằng nó ngay bên trái.
Nhưng `splice` phải dịch suffix; một run dài có thể làm tổng chi phí thành `O(n²)`. Thông tin
cần giữ thực ra chỉ là phần tử cuối đã đưa vào output.

### State, init và scope

| State | Kiểu dữ liệu | Lưu chính xác cái gì | Tại sao cần | Init | Vì sao init như vậy | Scope |
| --- | --- | --- | --- | --- | --- | --- |
| `reduced` | number[] | kết quả đúng của prefix đã đọc | vừa là output, vừa cho biết run cuối | `[]` | chưa đọc phần tử nào | xuyên loop |
| `currentValue` | number | phần tử input đang xét | quyết định giữ hay bỏ | từ `for...of` | mỗi lượt đọc lại | iteration |
| `previousKeptValue` | number | đại diện run cuối | so với current | `reduced.at(-1)` sau empty check | không được đọc khi rỗng | iteration |
| `beginsNewRun` | boolean | current có mở run mới không | làm branch dễ đọc | phép so sánh | tính lại mỗi lượt | iteration |

Quy tắc scope hiện rõ: `reduced` phải sống sang lượt sau nên nằm ngoài loop; ba biến mô tả
current/check chỉ dùng trong một lượt nên nằm trong loop.

### Một iteration và invariant

1. lấy `currentValue`;
2. nếu output rỗng, push current rồi `continue`;
3. đọc `previousKeptValue` từ top output;
4. nếu hai value khác nhau, push current;
5. nếu bằng nhau, không cập nhật gì;
6. `for...of` tự chuyển sang phần tử tiếp theo.

Sau mỗi iteration, `reduced` bằng chính xác prefix đã đọc sau khi nén mỗi run còn một đại diện.
Push khi rỗng tạo đại diện đầu; push khi khác mở run mới; skip khi giống không làm mất run nào.

### Code Blueprint

```text
OUTPUT: reduced
PREPARE: không mutate input
GLOBAL STATE: reduced
INIT: reduced = []
MAIN LOOP: for từng currentValue vì mỗi input được xét đúng một lần
CURRENT ITEM: currentValue
PER-ITERATION STATE: outputIsEmpty, previousKeptValue, beginsNewRun
CHECK: output rỗng? nếu không, top có khác current không?
BRANCH: rỗng → push+continue; khác → push; giống → skip
UPDATE: reduced.push(currentValue) chỉ khi bắt đầu run
POINTER MOVEMENT: for...of tự tiến
STOP / RETURN: hết input thì return reduced
CLEANUP: không có state tồn đọng
```

`Contract → output array`; `State → reduced`; `một lượt → for...of`; `Invariant → output là
prefix đã nén`; `Transition → hai branch push/skip`; `Stop → hết input`; `Cleanup → không có`.

### Dry run nhìn thấy state

| Current | `reduced` trước | Check | Update | `reduced` sau |
| --- | --- | --- | --- | --- |
| 1 | `[]` | rỗng | push 1 | `[1]` |
| 1 | `[1]` | top bằng current | skip | `[1]` |
| 2 | `[1]` | top khác current | push 2 | `[1,2]` |
| 1 | `[1,2]` | top khác current | push 1 | `[1,2,1]` |

Mỗi input được đọc một lần và push tối đa một lần: `O(n)` time. Output lớn nhất `n` khi không
có hai phần tử kề nhau giống nhau, nên space `O(n)` tính cả output.

### Lỗi thường gặp và test lộ lỗi

- Logic — dùng `Set`: `[1,1,2,1]` phải ra `[1,2,1]`, không phải `[1,2]`.
- Off-by-one — bắt đầu loop ở phần tử thứ hai nhưng quên seed output: `[7]` bị trả `[]`.
- Check/update — đọc top rồi push trước khi so: `[1,1]` bị giữ cả hai.
- Init — seed bằng `array[0]` mà không xử lý empty: `[]` tạo `[undefined]`.
- Hidden — một run dài: `[3,3,3,3] → [3]`.
- Performance — `splice` trong loop trên hàng chục nghìn phần tử giống nhau có thể quadratic.
