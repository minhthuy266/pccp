# OF032 — Tam giác số nguyên

- Nguồn đề: [Programmers lesson 43105](https://school.programmers.co.kr/learn/courses/30/lessons/43105?language=javascript)
- Pattern chính: bottom-up triangle DP
- Mức trong bank: CORE / representative

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Bắt đầu đỉnh tam giác. Từ `(row,column)` chỉ đi xuống `(row+1,column)` hoặc `(row+1,column+1)`. Tìm tổng lớn nhất từ đỉnh tới đáy.

## 02. Bound

Mỗi bước có hai choice nên DFS path là `2^(height-1)`. Các path hội tụ cùng cell; DP tính mỗi state một lần.

## 03. Brute force

DFS mọi path và cộng sum. Hai prefix khác nhau tới cùng cell có cùng future choices nhưng brute force giải lại suffix.

## 04. Bottleneck

Future optimum từ cell chỉ phụ thuộc cell, không phụ thuộc path tới nó. Bottom-up lưu best sum từ cell xuống đáy.

## 05. Pattern

State `best[column]` ban đầu là row đáy. Đi row từ dưới lên:

```text
best[col] = triangle[row][col] + max(best[col], best[col+1])
```

## 06. State

`best[col]` trước khi xử lý row r là maximum path từ cell ở row r+1, col xuống đáy. Sau update, prefix best tương ứng row r.

## 07. Transition

Cell có đúng hai child. Chọn child có suffix sum lớn hơn rồi cộng value hiện tại. Update column trái sang phải an toàn vì `best[col+1]` chưa bị update trong row này.

## 08. Invariant

Trước row r, best chứa optimum của row r+1. Sau khi update mọi col hợp lệ, best[col] là optimum từ `(r,col)`. Induction từ đáy chứng minh `best[0]` là answer.

## 09. Complexity

Time `O(total cells)`, space `O(height)`; copy row đáy nên không mutate triangle.

## 10. Pseudocode

```text
best=copy last row
for row from h-2 down to 0:
  for col 0..row:
    best[col]=triangle[row][col]+max(best[col],best[col+1])
return best[0]
```

## 11. Code bước 1 — dựng state

```js
function baseRow(triangle) {
  return [...triangle.at(-1)];
}
```

## 12. Code bước 2 — viết transition

```js
function bestFrom(value,leftChild,rightChild) {
  return value+Math.max(leftChild,rightChild);
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function reduceRow(triangle,row,best) {
  for (let col=0;col<triangle[row].length;col++)
    best[col]=bestFrom(triangle[row][col],best[col],best[col+1]);
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF032.js](../../../solutions/official/OF032.js).

```js
function maximumTrianglePath(triangle) {
  const best=[...triangle.at(-1)];
  for (let row=triangle.length-2;row>=0;row--)
    for (let col=0;col<triangle[row].length;col++)
      best[col]=triangle[row][col]+Math.max(best[col],best[col+1]);
  return best[0];
}
```

## 15. Dry-run

Triangle `[[-1],[-2,-3]]`: base `[-2,-3]`; top update `-1+max(-2,-3)=-3`. Khởi tạo best bằng 0 sẽ sai với số âm.

## 16. Edge cases

1. Một row.
2. Giá trị âm.
3. Hai child bằng nhau.
4. Optimum đổi hướng nhiều lần.

## 17. Lỗi JavaScript thường gặp

- Greedy chọn child lớn tại từng bước mà bỏ future.
- DP khởi tạo zero khi value có thể âm.
- Update right-to-left với layout 1D này làm đọc value đã đổi.
- Mutate row đáy input do không copy.
