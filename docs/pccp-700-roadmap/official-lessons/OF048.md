# OF048 — Hạn lưu trữ dữ liệu cá nhân

- Nguồn đề: [Programmers lesson 150370](https://school.programmers.co.kr/learn/courses/30/lessons/150370?language=javascript)
- Pattern chính: parsing + scalar date + Hash lookup
- Mức trong bank: CORE / implementation

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Mọi tháng được quy ước đúng 28 ngày. `terms` ánh xạ mã điều khoản sang số tháng lưu trữ. Mỗi privacy có ngày bắt đầu và mã. Tại `today`, trả index 1-based của các privacy đã hết hạn theo thứ tự tăng dần.

Nếu ngày hết hạn exclusive bằng today thì dữ liệu đã phải hủy.

## 02. Bound

Dữ liệu không lớn, nhưng so date bằng string hoặc xử lý mượn ngày/tháng thủ công dễ lỗi. Quy ước 28 ngày cho phép đổi mọi date thành một số ngày tuyến tính và so `O(1)`.

## 03. Brute force

Cho từng privacy, cộng term từng tháng/ngày trên ba field year-month-day, xử lý overflow và trừ một ngày cuối hiệu lực. Đúng nếu cực kỳ cẩn thận nhưng nhiều boundary.

## 04. Bottleneck

Date ba chiều gây mượn/carry. Đổi sang serial day làm phép cộng term thành `start + months*28`. Dùng mốc hết hạn exclusive tránh phép “trừ một ngày” riêng.

## 05. Pattern

Normalize then compare:

```text
date → scalar day
term code → months Map
expiryExclusive = startSerial + months*28
expired iff expiryExclusive <= todaySerial
```

## 06. State

- `termMonths: Map<code, months>`;
- `todaySerial`;
- từng privacy: `startDate`, `code`, `expiryExclusive`;
- `expired` index output.

## 07. Transition

Parse `YYYY.MM.DD` bằng split và Number. Serial dùng `(month-1)`, `(day-1)` để mốc đầu năm có offset zero. Với mỗi privacy, lookup months, cộng duration và so.

## 08. Invariant

`dateToSerial` bảo toàn thứ tự ngày vì mỗi năm có `12*28` ngày và mỗi tháng 28 ngày. Sau khi xử lý `i` privacy, output chứa đúng index hết hạn trong prefix, vốn tăng dần do scan input.

## 09. Complexity

- Build terms `O(t)`.
- Scan privacies `O(p)`.
- Space `O(t+p)` tính cả output.

## 10. Pseudocode

```text
parse terms into map
todayDay = serial(today)
for privacy at index i:
    parse start, code
    expiry = serial(start) + terms[code]*28
    if expiry <= todayDay: append i+1
return output
```

## 11. Code bước 1 — dựng state

```js
function dateToSerial(date) {
  const [year, month, day] = date.split(".").map(Number);
  return year * 12 * 28 + (month - 1) * 28 + (day - 1);
}
```

Mốc tuyệt đối tùy ý; chỉ hiệu và thứ tự quan trọng.

## 12. Code bước 2 — viết transition

```js
function parseTerms(terms) {
  const map = new Map();
  for (const term of terms) {
    const [code, rawMonths] = term.split(" ");
    map.set(code, Number(rawMonths));
  }
  return map;
}
```

Không so mã term bằng nhiều `if`; Map phản ánh đúng lookup contract.

## 13. Code bước 3 — ghép vòng lặp

```js
function isExpired(startDate, months, todaySerial) {
  const expiryExclusive = dateToSerial(startDate) + months * 28;
  return expiryExclusive <= todaySerial;
}
```

Dấu `<=` là boundary quan trọng.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF048.js](../../../solutions/official/OF048.js).

```js
function expiredPrivacyIndices(today, terms, privacies) {
  const termMonths = parseTerms(terms);
  const todaySerial = dateToSerial(today);
  const expired = [];
  for (let i=0; i<privacies.length; i++) {
    const [start, code] = privacies[i].split(" ");
    const expiry = dateToSerial(start) + termMonths.get(code) * 28;
    if (expiry <= todaySerial) expired.push(i+1);
  }
  return expired;
}
```

## 15. Dry-run

Start `2022.01.01`, term 1 tháng: expiry exclusive là `2022.02.01`. Today đúng `2022.02.01` ⇒ `expiry <= today` ⇒ đã hết hạn. Today `2022.01.28` thì chưa.

## 16. Edge cases

1. Expiry đúng today.
2. Qua tháng 12 sang năm sau.
3. Ngày 28 sang ngày 1 tháng kế.
4. Nhiều privacy cùng term.
5. Không privacy nào hết hạn.

## 17. Lỗi JavaScript thường gặp

- Dùng `new Date()` với lịch thật 30/31 ngày, trái quy ước đề.
- So chuỗi sau khi tự cộng date không normalize.
- Dùng `<` thay `<=`.
- Quên output 1-based.
- Không `Number(rawMonths)`, dựa vào coercion.
