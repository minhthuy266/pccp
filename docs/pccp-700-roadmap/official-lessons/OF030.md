# OF030 — Camera kiểm soát

- Nguồn đề: [Programmers lesson 42884](https://school.programmers.co.kr/learn/courses/30/lessons/42884?language=javascript)
- Pattern chính: interval stabbing theo earliest exit
- Mức trong bank: TRANSFER / variant

## 01. Contract

Mỗi xe đi qua đoạn đóng `[entry,exit]`; camera tại một tọa độ phát hiện xe nếu nằm trong đoạn. Đặt ít camera nhất để cover mọi route.

## 02. Bound

Sort interval theo exit rồi scan `O(n log n)`.

## 03. Brute force

Thử subset endpoint làm camera và kiểm cover, exponential.

## 04. Bottleneck

Route có exit sớm nhất chưa cover bắt buộc một camera không muộn hơn exit. Đặt đúng exit là vị trí muộn nhất còn hợp lệ và cover tốt nhất các route sau.

## 05. Pattern

Sort exit tăng; nếu entry `<= lastCamera`, route đã cover; nếu entry `> lastCamera`, đặt camera tại exit.

## 06. State

`lastCamera`, `cameras`, sorted routes.

## 07. Transition

Uncovered route tăng count và cập nhật lastCamera=exit; covered giữ state.

## 08. Invariant

Sau prefix sorted, cameras là minimum cho prefix và camera cuối nằm tại earliest exit của group cuối. Exchange mọi camera cover route earliest-exit sang endpoint đó không làm mất route nào có entry trước/equal endpoint.

## 09. Complexity

Time `O(n log n)`, space `O(n)` do copy.

## 10. Pseudocode

```text
sort by exit
last=-infinity; count=0
for [entry,exit]:
  if entry>last: count++; last=exit
return count
```

## 11. Code bước 1 — dựng state

```js
const sorted=[...routes].sort((a,b)=>a[1]-b[1]);
```

## 12. Code bước 2 — viết transition

```js
function isCovered(entry,lastCamera) { return entry<=lastCamera; }
```

## 13. Code bước 3 — ghép vòng lặp

```js
if (!isCovered(entry,lastCamera)) { cameras++; lastCamera=exit; }
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF030.js](../../../solutions/official/OF030.js).

```js
function minimumSpeedCameras(routes) {
  const sorted=[...routes].sort((a,b)=>a[1]-b[1]);
  let cameras=0,lastCamera=-Infinity;
  for (const [entry,exit] of sorted) {
    if (entry<=lastCamera) continue;
    cameras++; lastCamera=exit;
  }
  return cameras;
}
```

## 15. Dry-run

`[1,2],[2,3]`: đặt camera tại2 cho route đầu; route hai có entry2≤camera2 nên cùng được cover, answer1.

## 16. Edge cases

Intervals chạm endpoint; nested; all overlap; all disjoint; tọa độ âm.

## 17. Lỗi JavaScript thường gặp

Dùng `<` thay `<=` cho interval đóng; sort entry; đặt midpoint; khởi tạo lastCamera=0 làm sai tọa độ âm.
