# OF030 — Camera kiểm soát

- Nguồn đề: [Programmers lesson 42884](https://school.programmers.co.kr/learn/courses/30/lessons/42884?language=javascript)
- Pattern chính: interval stabbing theo earliest exit
- Mức trong bank: TRANSFER / variant

## 01. Contract

Mỗi xe đi qua đoạn đóng `[entry,exit]`; camera tại một tọa độ phát hiện xe nếu nằm trong đoạn. Đặt ít camera nhất để cover mọi route.

## 02. Bound

Sort interval theo exit rồi scan `O(n log n)`.

## 03. Brute force

Thử subset endpoint làm camera và kiểm cover, exponential.

## 04. Bottleneck

Route có exit sớm nhất chưa cover bắt buộc một camera không muộn hơn exit. Đặt đúng exit là vị trí muộn nhất còn hợp lệ và cover tốt nhất các route sau.

## 05. Pattern

Sort exit tăng; nếu entry `<= lastCamera`, route đã cover; nếu entry `> lastCamera`, đặt camera tại exit.

## 06. State

`lastCamera`, `cameras`, sorted routes.

## 07. Transition

Uncovered route tăng count và cập nhật lastCamera=exit; covered giữ state.

## 08. Invariant

Sau prefix sorted, cameras là minimum cho prefix và camera cuối nằm tại earliest exit của group cuối. Exchange mọi camera cover route earliest-exit sang endpoint đó không làm mất route nào có entry trước/equal endpoint.

## 09. Complexity

Time `O(n log n)`, space `O(n)` do copy.

## 10. Pseudocode

```text
sort by exit
last=-infinity; count=0
for [entry,exit]:
  if entry>last: count++; last=exit
return count
```

## 11. Code bước 1 — dựng state

```js
const sorted=[...routes].sort((a,b)=>a[1]-b[1]);
```

## 12. Code bước 2 — viết transition

```js
function isCovered(entry,lastCamera) { return entry<=lastCamera; }
```

## 13. Code bước 3 — ghép vòng lặp

```js
if (!isCovered(entry,lastCamera)) { cameras++; lastCamera=exit; }
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF030.js](../../../solutions/official/OF030.js).

```js
function minimumSpeedCameras(routes) {
  const sortedRoutes = [...routes].sort((first, second) => first[1] - second[1]);
  let cameraCount = 0;
  let lastCameraPosition = -Infinity;

  for (const [entry, exit] of sortedRoutes) {
    const alreadyCovered = entry <= lastCameraPosition;
    if (alreadyCovered) continue;
    cameraCount++;
    lastCameraPosition = exit;
  }

  return cameraCount;
}
```

## 15. Dry-run

`[1,2],[2,3]`: đặt camera tại2 cho route đầu; route hai có entry2≤camera2 nên cùng được cover, answer1.

## 16. Edge cases

Intervals chạm endpoint; nested; all overlap; all disjoint; tọa độ âm.

## 17. Lỗi JavaScript thường gặp

Dùng `<` thay `<=` cho interval đóng; sort entry; đặt midpoint; khởi tạo lastCamera=0 làm sai tọa độ âm.

## 19. Problem → Code hoàn chỉnh

**Làm tay:** lấy route chưa cover có exit sớm nhất. Một camera bắt buộc phải nằm không muộn hơn
exit đó; đặt đúng exit là vị trí muộn nhất còn hợp lệ, nên có cơ hội cover nhiều route sau nhất.

```js
function minimumCamerasBruteForce(routes) {
  const candidates = [...new Set(routes.flat())];
  let best = Infinity;
  function choose(index, cameras) {
    if (cameras.length >= best) return;
    if (index === candidates.length) {
      const coversAll = routes.every(([entry, exit]) =>
        cameras.some((position) => entry <= position && position <= exit),
      );
      if (coversAll) best = cameras.length;
      return;
    }
    choose(index + 1, cameras);
    cameras.push(candidates[index]);
    choose(index + 1, cameras);
    cameras.pop();
  }
  choose(0, []);
  return best;
}
```

| State | Kiểu | Lưu gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `sortedRoutes` | interval[] | route theo exit tăng | sorted copy | toàn hàm |
| `lastCameraPosition` | number | camera cuối | `-Infinity` cho tọa độ âm | xuyên loop |
| `cameraCount` | number | camera đã đặt | `0` | output |

```text
OUTPUT: cameraCount; PREPARE: sort by exit; STATE: lastCamera,count; INIT: -Infinity,0
LOOP: for route; CURRENT: [entry,exit]; CHECK: entry<=lastCamera?
BRANCH: covered → continue; uncovered → count++,lastCamera=exit
POINTER: for; STOP: hết routes; CLEANUP: không; RETURN count
```

Invariant: camera set là minimum cho prefix sorted; exchange camera cover earliest-exit route
sang exit không làm mất route đang overlap. Sort `O(n log n)`, scan `O(n)`. **Lỗi/test:** interval
đóng dùng `<=`; `[1,2],[2,3]` cần một camera; sort entry sai proof; init 0 sai tọa độ âm;
mutate input khi sort. Recall: `sort exit → if entry>last place at exit`.

## A17. Blueprint đủ trường và Recall ba tầng

```text
OUTPUT: số camera ít nhất cover mọi closed interval route.
PREPARE: clone routes rồi sort theo exit tăng để không mutate input.
GLOBAL STATE: lastCameraPosition và cameraCount.
INIT: lastCameraPosition = -Infinity; cameraCount = 0.
MAIN LOOP: quét từng [entry, exit] trong sortedRoutes.
CURRENT ITEM: route hiện tại với entry và exit.
PER-ITERATION STATE: alreadyCovered = entry <= lastCameraPosition.
CHECK: camera cuối có nằm trong closed interval hiện tại không.
BRANCH: covered thì continue; uncovered thì đặt camera mới tại exit.
UPDATE: cameraCount += 1 và lastCameraPosition = exit trong cùng nhánh uncovered.
POINTER MOVEMENT: for...of tự sang route có exit kế tiếp.
STOP / RETURN: hết routes thì return cameraCount.
CLEANUP: không cần; camera cuối đại diện đủ cho quyết định suffix.
```

- Recall 1: Sort theo exit; route chưa được cover buộc đặt camera tại exit sớm nhất của nó.
- Recall 2: STATE last/count → LOOP sorted routes → CHECK entry<=last → UPDATE exit/count → RETURN count.
- Recall 3: Điền `alreadyCovered = entry ___ lastCameraPosition`; uncovered thì `lastCameraPosition = ___`.
