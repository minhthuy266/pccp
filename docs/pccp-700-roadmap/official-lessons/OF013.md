# OF013 — Bộ điều khiển đĩa

- Nguồn đề: [Programmers lesson 42627](https://school.programmers.co.kr/learn/courses/30/lessons/42627?language=javascript)
- Pattern chính: event sweep + shortest-job min-heap
- Mức trong bank: CORE / integration

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Mỗi job `[request,duration]`. Disk xử lý một job tại một thời điểm, không preempt. Khi rảnh, chọn trong các job đã request theo duration ngắn nhất. Tính floor của average turnaround `completion-request`.

## 02. Bound

Mỗi lần scan toàn jobs chờ để tìm shortest thành `O(n²)`. Sort request một lần và min-heap waiting theo duration cho `O(n log n)`.

## 03. Brute force

Mỗi tick thêm job mới, scan list waiting tìm duration min, xóa nó, rồi tăng time từng đơn vị. Lặp scan và lãng phí idle ticks.

## 04. Bottleneck

Có hai order khác nhau: arrivals theo request time và selection theo duration. Một cấu trúc không phục vụ tốt cả hai; dùng sorted input + heap. Khi heap rỗng phải jump tới request kế, không tick qua khoảng trống.

## 05. Pattern

```text
if waiting empty: time=max(time,next request)
push all request<=time
pop shortest duration
time += duration
turnaround += time-request
```

## 06. State

- jobs sort request và pointer `next`;
- min-heap waiting theo `(duration,request)`;
- `time`, `completed`, `totalTurnaround`.

## 07. Transition

Jump idle; batch enqueue mọi arrival tính đến current time; pop một job, advance time đến completion, cộng turnaround.

## 08. Invariant

Trước selection, heap chứa đúng mọi job request `<=time` chưa xử lý. Pointer trỏ arrival đầu chưa enqueue. Heap root là job duration nhỏ nhất hợp lệ. Sau execution, time là completion của job vừa chọn.

## 09. Complexity

Sort `O(n log n)`, mỗi job heap push/pop một lần `O(n log n)`, space `O(n)`.

## 10. Pseudocode

```text
sort by request
while completed<n:
  if heap empty and next request>time: jump time
  enqueue all request<=time
  job=pop shortest
  time+=duration
  total+=time-request
return floor(total/n)
```

## 13. Code bước 3 — ghép vòng lặp

## 14. Code hoàn chỉnh

Code executable gồm heap: [solutions/official/OF013.js](../../../solutions/official/OF013.js).

```js
class JobMinHeap {
  constructor() {
    this.values = [];
  }
  get size() {
    return this.values.length;
  }
  compare(first, second) {
    return first.duration - second.duration || first.request - second.request;
  }
  push(job) {
    const heap = this.values;
    heap.push(job);
    let child = heap.length - 1;
    while (child > 0) {
      const parent = Math.floor((child - 1) / 2);
      if (this.compare(heap[parent], heap[child]) <= 0) {
        break;
      }
      [heap[parent], heap[child]] = [heap[child], heap[parent]];
      child = parent;
    }
  }
  pop() {
    const heap = this.values;
    if (heap.length === 1) {
      return heap.pop();
    }
    const minimum = heap[0];
    heap[0] = heap.pop();
    let parent = 0;
    while (true) {
      const left = parent * 2 + 1;
      const right = left + 1;
      let smallest = parent;
      if (left < heap.length && this.compare(heap[left], heap[smallest]) < 0) {
        smallest = left;
      }
      if (right < heap.length && this.compare(heap[right], heap[smallest]) < 0) {
        smallest = right;
      }
      if (smallest === parent) {
        break;
      }
      [heap[parent], heap[smallest]] = [heap[smallest], heap[parent]];
      parent = smallest;
    }
    return minimum;
  }
}

function averageDiskTurnaround(jobs) {
  const ordered = jobs
    .map(([request, duration]) => ({ request, duration }))
    .sort((a, b) => a.request - b.request);
  const waiting = new JobMinHeap();
  let next = 0;
  let completed = 0;
  let time = 0;
  let totalTurnaround = 0;

  while (completed < ordered.length) {
    if (waiting.size === 0 && next < ordered.length && time < ordered[next].request) {
      time = ordered[next].request;
    }

    while (next < ordered.length && ordered[next].request <= time) {
      waiting.push(ordered[next]);
      next += 1;
    }

    const job = waiting.pop();
    time += job.duration;
    totalTurnaround += time - job.request;
    completed += 1;
  }

  return Math.floor(totalTurnaround / jobs.length);
}
```

## 15. Dry-run

`[0,3],[1,9],[2,6]`: time0 chọn 3 → complete3/turn3; lúc3 heap có duration9,6 nên chọn6 → complete9/turn7; rồi9 → complete18/turn17; floor `(3+7+17)/3=9`.

## 16. Edge cases

1. Job đầu request sau time 0.
2. Nhiều job cùng request.
3. Heap rỗng giữa hai arrival group.
4. Tie duration; request tie-break giúp deterministic.

## 17. Lỗi JavaScript thường gặp

- Heap sort theo request thay duration.
- Chỉ enqueue một arrival, bỏ các job cùng thời điểm.
- Tăng time từng tick khi idle.
- Turnaround dùng duration thay `completion-request`.
- Dùng `shift()` sorted jobs.

## 18. Bài transfer cùng pattern

- OF012: heap pure combine, không có event time.
- OF010: event queue theo exit time, không priority selection.
- SR005: preemption và resume LIFO.

Tín hiệu: arrivals theo time nhưng chọn waiting theo tiêu chí khác ⇒ sort event + priority queue.

## 19. Làm bằng tay và brute force executable

Với jobs `[0,3],[1,9],[2,6]`: tại time 0 chỉ job duration 3 eligible; hoàn tất ở 3. Lúc đó
hai job còn lại đều đã tới, nên chọn duration 6 trước 9. Turnaround là `3,7,17`, average floor 9.

```js
function averageDiskTurnaroundBrute(jobs) {
  const remaining = jobs.map(([request, duration]) => ({ request, duration }));
  let time = 0;
  let total = 0;

  while (remaining.length > 0) {
    const eligible = remaining
      .map((job, index) => ({ ...job, index }))
      .filter((job) => job.request <= time)
      .sort((a, b) => a.duration - b.duration || a.request - b.request);

    if (eligible.length === 0) {
      time = Math.min(...remaining.map((job) => job.request));
      continue;
    }

    const job = eligible[0];
    remaining.splice(job.index, 1);
    time += job.duration;
    total += time - job.request;
  }
  return Math.floor(total / jobs.length);
}
```

Brute scan/sort toàn waiting set mỗi lần. Bản tối ưu tách arrival order khỏi selection order.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `ordered` | jobs theo request time | copy + sort input |
| `next` | arrival đầu chưa enqueue | `0` |
| `waiting` | jobs eligible theo `(duration,request)` | heap rỗng |
| `time` | thời điểm disk rảnh kế tiếp | `0` |
| `completed` | số job đã chạy xong | `0` |
| `totalTurnaround` | tổng `completion-request` | `0` |

## 21. Blueprint từ đề đến code

1. Tách hai order: job trở nên eligible theo request, job được chọn theo duration.
2. Sort input một lần theo request và giữ pointer `next`.
3. Trước mỗi selection, enqueue **tất cả** job có `request <= time`.
4. Heap rỗng thì jump time tới arrival kế, không tick từng đơn vị.
5. Pop shortest eligible job, advance tới completion, cộng turnaround.
6. Lặp tới khi completed bằng số job; floor average ở cuối.

## 22. Invariant, lỗi lộ diện và recall

Ngay trước mỗi pop, heap chứa đúng mọi job đã request nhưng chưa chạy; job sau `next` chưa eligible.
Vì vậy root là shortest trong đúng tập được phép chọn. Sau khi chạy non-preemptive, `time` là thời
điểm disk rảnh mới và batch arrival tiếp theo được đưa vào trước quyết định kế.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| đưa job tương lai vào heap | `[0,10],[1,1]` | job 10 phải chạy trước |
| chỉ enqueue một arrival | ba job cùng request 0 | chọn duration tăng dần |
| không jump khi idle | `[[5,2]]` | 2 |
| cộng waiting time thay turnaround | `[0,3],[1,9],[2,6]` | 9 |

Recall: **event order và priority order khác nhau ⇒ sorted pointer + heap; enqueue toàn eligible rồi mới pop.**
