# OF013 — Bộ điều khiển đĩa

- Nguồn đề: [Programmers lesson 42627](https://school.programmers.co.kr/learn/courses/30/lessons/42627?language=javascript)
- Pattern chính: event sweep + shortest-job min-heap
- Mức trong bank: CORE / integration

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Mỗi job `[request,duration]`. Disk xử lý một job tại một thời điểm, không preempt. Khi rảnh, chọn trong các job đã request theo duration ngắn nhất. Tính floor của average turnaround `completion-request`.

## 02. Bound

Mỗi lần scan toàn jobs chờ để tìm shortest thành `O(n²)`. Sort request một lần và min-heap waiting theo duration cho `O(n log n)`.

## 03. Brute force

Mỗi tick thêm job mới, scan list waiting tìm duration min, xóa nó, rồi tăng time từng đơn vị. Lặp scan và lãng phí idle ticks.

## 04. Bottleneck

Có hai order khác nhau: arrivals theo request time và selection theo duration. Một cấu trúc không phục vụ tốt cả hai; dùng sorted input + heap. Khi heap rỗng phải jump tới request kế, không tick qua khoảng trống.

## 05. Pattern

```text
if waiting empty: time=max(time,next request)
push all request<=time
pop shortest duration
time += duration
turnaround += time-request
```

## 06. State

- jobs sort request và pointer `next`;
- min-heap waiting theo `(duration,request)`;
- `time`, `completed`, `totalTurnaround`.

## 07. Transition

Jump idle; batch enqueue mọi arrival tính đến current time; pop một job, advance time đến completion, cộng turnaround.

## 08. Invariant

Trước selection, heap chứa đúng mọi job request `<=time` chưa xử lý. Pointer trỏ arrival đầu chưa enqueue. Heap root là job duration nhỏ nhất hợp lệ. Sau execution, time là completion của job vừa chọn.

## 09. Complexity

Sort `O(n log n)`, mỗi job heap push/pop một lần `O(n log n)`, space `O(n)`.

## 10. Pseudocode

```text
sort by request
while completed<n:
  if heap empty and next request>time: jump time
  enqueue all request<=time
  job=pop shortest
  time+=duration
  total+=time-request
return floor(total/n)
```

## 11. Code bước 1 — dựng state

```js
function orderedJobs(jobs) {
  return jobs.map(([request,duration])=>({request,duration}))
    .sort((a,b)=>a.request-b.request);
}
```

## 12. Code bước 2 — viết transition

```js
function turnaround(completion,request) {
  return completion-request;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function jumpIfIdle(time,nextRequest,heapSize) {
  return heapSize===0 && time<nextRequest ? nextRequest : time;
}
```

## 14. Code hoàn chỉnh

Code executable gồm heap: [solutions/official/OF013.js](../../../solutions/official/OF013.js).

```js
function averageDiskTurnaround(jobs) {
  const ordered=orderedJobs(jobs), waiting=new JobMinHeap();
  let next=0,completed=0,time=0,total=0;
  while (completed<ordered.length) {
    if (!waiting.size && next<ordered.length && time<ordered[next].request) time=ordered[next].request;
    while (next<ordered.length && ordered[next].request<=time) waiting.push(ordered[next++]);
    const job=waiting.pop();
    time+=job.duration; total+=time-job.request; completed++;
  }
  return Math.floor(total/jobs.length);
}
```

## 15. Dry-run

`[0,3],[1,9],[2,6]`: time0 chọn 3 → complete3/turn3; lúc3 heap có duration9,6 nên chọn6 → complete9/turn7; rồi9 → complete18/turn17; floor `(3+7+17)/3=9`.

## 16. Edge cases

1. Job đầu request sau time 0.
2. Nhiều job cùng request.
3. Heap rỗng giữa hai arrival group.
4. Tie duration; request tie-break giúp deterministic.

## 17. Lỗi JavaScript thường gặp

- Heap sort theo request thay duration.
- Chỉ enqueue một arrival, bỏ các job cùng thời điểm.
- Tăng time từng tick khi idle.
- Turnaround dùng duration thay `completion-request`.
- Dùng `shift()` sorted jobs.

## 18. Bài transfer cùng pattern

- OF012: heap pure combine, không có event time.
- OF010: event queue theo exit time, không priority selection.
- SR005: preemption và resume LIFO.

Tín hiệu: arrivals theo time nhưng chọn waiting theo tiêu chí khác ⇒ sort event + priority queue.
