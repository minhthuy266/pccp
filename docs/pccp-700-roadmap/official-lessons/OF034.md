# OF034 — Số học

- Nguồn đề: [Programmers lesson 1843](https://school.programmers.co.kr/learn/courses/30/lessons/1843?language=javascript)
- Pattern chính: interval DP giữ minimum và maximum
- Mức trong bank: STRETCH / advanced

## 01. Contract

Biểu thức gồm số và phép `+/-` xen kẽ. Đặt ngoặc tùy ý nhưng giữ nguyên thứ tự token để giá trị lớn nhất. Trả maximum.

## 02. Bound

Số cách đặt ngoặc là Catalan exponential. Interval DP xét mọi range và split `O(n³)`.

## 03. Brute force

Sinh mọi binary parenthesization, evaluate và lấy max. Nhiều subtree interval được tính lặp.

## 04. Bottleneck

Với phép trừ, maximum của whole có thể cần minimum của right; chỉ lưu maximum interval là thiếu state.

## 05. Pattern

`maximum[l][r]`, `minimum[l][r]`. Base single number. Với split k:

- plus: maxL+maxR, minL+minR;
- minus: maxL-minR, minL-maxR.

## 06. State

Hai bảng min/max theo interval số; operators[k] nằm giữa number k và k+1.

## 07. Transition

Iterate length tăng để subinterval đã có. Relax mọi split theo operator.

## 08. Invariant

Sau khi xử lý length L, min/max của mọi interval dài≤L là cực trị trên tất cả parenthesization. Root split cuối phân hoạch mọi expression thành hai interval nhỏ hơn, nên transition đầy đủ.

## 09. Complexity

Time `O(n³)`, space `O(n²)`.

## 10. Pseudocode

```text
base min[i][i]=max[i][i]=number[i]
for length 2..n:
 for interval l,r:
  for split k:
   relax based on + or -
return max[0][n-1]
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF034.js](../../../solutions/official/OF034.js).

```js
function maximumArithmeticExpressionValue(tokens) {
  const numbers = tokens.filter((_, index) => index % 2 === 0).map(Number);
  const operators = tokens.filter((_, index) => index % 2 === 1);
  const count = numbers.length;
  const minimum = Array.from({ length: count }, () => Array(count).fill(Infinity));
  const maximum = Array.from({ length: count }, () => Array(count).fill(-Infinity));

  for (let index = 0; index < count; index++) {
    minimum[index][index] = numbers[index];
    maximum[index][index] = numbers[index];
  }

  for (let length = 2; length <= count; length++) {
    for (let left = 0; left + length <= count; left++) {
      const right = left + length - 1;

      for (let split = left; split < right; split++) {
        if (operators[split] === "+") {
          maximum[left][right] = Math.max(
            maximum[left][right],
            maximum[left][split] + maximum[split + 1][right],
          );
          minimum[left][right] = Math.min(
            minimum[left][right],
            minimum[left][split] + minimum[split + 1][right],
          );
        } else {
          maximum[left][right] = Math.max(
            maximum[left][right],
            maximum[left][split] - minimum[split + 1][right],
          );
          minimum[left][right] = Math.min(
            minimum[left][right],
            minimum[left][split] - maximum[split + 1][right],
          );
        }
      }
    }
  }

  return maximum[0][count - 1];
}
```

### Loop and condition derivation

- **Nhịp lặp:** `tăng intervalLength từ 2; quét start; thử mọi split.`. Đây là lý do code dùng block bắt đầu bởi `for (let index = 0; index < count; index++) {`, thay vì chọn loop theo thói quen.

- **Thứ tự:** phải hoàn thành `relax minimum và maximum của interval qua mọi split.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let index = 0; index < count; index++) {`.
- **Cleanup:** không bỏ minimum vì nó có thể làm right operand cho phép trừ.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

  const numbers = tokens.filter((_, index) => index % 2 === 0).map(Number);
  const operators = tokens.filter((_, index) => index % 2 === 1);
  const count = numbers.length;
  const minimum = Array.from({ length: count }, () => Array(count).fill(Infinity));
  const maximum = Array.from({ length: count }, () => Array(count).fill(-Infinity));
  for (let index = 0; index < count; index++) {
    minimum[index][index] = numbers[index];
    maximum[index][index] = numbers[index];
  }
  for (let length = 2; length <= count; length++) {
    for (let left = 0; left + length <= count; left++) {
      const right = left + length - 1;

      for (let split = left; split < right; split++) {
        if (operators[split] === "+") {
          maximum[left][right] = Math.max(
            maximum[left][right],
            maximum[left][split] + maximum[split + 1][right],
          );
          minimum[left][right] = Math.min(
            minimum[left][right],
            minimum[left][split] + minimum[split + 1][right],
          );
        } else {
          maximum[left][right] = Math.max(
            maximum[left][right],
            maximum[left][split] - minimum[split + 1][right],
          );
          minimum[left][right] = Math.min(
            minimum[left][right],
            minimum[left][split] - maximum[split + 1][right],
          );
        }
      }
    }
  }
}

#### 19. Làm bằng tay và brute force executable

Với `1-3+5-8`, giá trị lớn nhất có thể cần một right subtree nhỏ nhất vì `left - right` tăng khi
right giảm. Đây là lý do state chỉ giữ maximum không đủ.

```js
function maximumArithmeticExpressionValueBrute(tokens) {
  function evaluate(leftToken, rightToken) {
    if (leftToken === rightToken) return [Number(tokens[leftToken])];
    const values = [];

    for (let operator = leftToken + 1; operator < rightToken; operator += 2) {
      const leftValues = evaluate(leftToken, operator - 1);
      const rightValues = evaluate(operator + 1, rightToken);
      for (const left of leftValues) {
        for (const right of rightValues) {
          values.push(tokens[operator] === "+" ? left + right : left - right);
        }
      }
    }
    return values;
  }

  return Math.max(...evaluate(0, tokens.length - 1));
}
```

Brute sinh mọi parenthesization và tính lại cùng interval. Interval DP memo cực trị của mỗi range.

#### 21. Blueprint từ đề đến code

1. Nhận ra lựa chọn là vị trí root operator của từng interval.
2. Phép trừ không monotone theo right operand, nên giữ cả minimum và maximum.
3. Base interval một số có min=max=value.
4. Duyệt interval length tăng để hai subinterval đã được giải.
5. Với plus ghép max+max/min+min; với minus ghép max-min và min-max.
6. Relax qua mọi split rồi trả maximum toàn interval.
