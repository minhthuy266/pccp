# OF033 — Đường đến trường

- Nguồn đề: [Programmers lesson 42898](https://school.programmers.co.kr/learn/courses/30/lessons/42898?language=javascript)
- Pattern chính: grid path-count DP + obstacle
- Mức trong bank: CORE / representative

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Grid rộng `m`, cao `n`; từ góc trên trái tới góc dưới phải, chỉ đi phải hoặc xuống. Một số tọa độ `[x,y]` là puddle không đi được. Đếm số đường modulo `1,000,000,007`.

## 02. Bound

Số path combinatorial; enumerate không được. Mỗi cell nhận path từ top và left, DP `O(mn)`.

## 03. Brute force

DFS hai nhánh cho tới destination, dừng ở boundary/puddle. Nhiều route cùng tới một cell rồi giải lại suffix.

## 04. Bottleneck

Số cách tới cell chỉ phụ thuộc top/left và puddle status. Đây là optimal substructure/counting recurrence trực tiếp.

## 05. Pattern

```text
dp[0][0]=1
puddle => dp=0
otherwise dp[r][c]=(dp[r-1][c]+dp[r][c-1]) mod M
```

## 06. State

`dp[row][column]` là số route hợp lệ từ start tới cell đó. `blocked` Set dùng key row,column sau khi đổi input `[x,y]`.

## 07. Transition

Iterate row-major vì top và left đã được tính. Puddle được set 0 và skip. Boundary thiếu parent đóng góp 0.

## 08. Invariant

Trước khi tính cell `(r,c)`, mọi cell top/left cần cho transition đã đúng. Mỗi path tới current có bước cuối duy nhất từ top hoặc left, hai tập không giao, nên cộng count.

## 09. Complexity

Time `O(mn+p)`, space `O(mn)`. Mỗi sum dưới khoảng `2*MOD`, an toàn trong Number trước modulo.

## 10. Pseudocode

```text
blocked=Set puddles converted y-1,x-1
dp[0][0]=1
for rows then columns:
  skip start
  if blocked: dp=0
  else dp=(top+left)%MOD
return destination
```

## 11. Code bước 1 — dựng state

```js
function blockedCells(puddles) {
  return new Set(puddles.map(([x,y])=>`${y-1},${x-1}`));
}
```

Input là x,y; array là row=y, column=x.

## 12. Code bước 2 — viết transition

```js
function pathTransition(top,left) {
  return (top+left)%1_000_000_007;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function cellKey(row,column) {
  return `${row},${column}`;
}
```

Separator tránh collision như `(1,23)` và `(12,3)`.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF033.js](../../../solutions/official/OF033.js).

```js
const ROUTE_MODULO = 1_000_000_007;

function schoolRouteCount(width, height, puddles) {
  const blocked = new Set(puddles.map(([x, y]) => `${y - 1},${x - 1}`));
  const dp = Array.from({ length: height }, () => new Uint32Array(width));
  dp[0][0] = 1;

  for (let row = 0; row < height; row++) {
    for (let column = 0; column < width; column++) {
      if (row === 0 && column === 0) continue;
      if (blocked.has(`${row},${column}`)) {
        dp[row][column] = 0;
        continue;
      }
      const fromTop = row > 0 ? dp[row - 1][column] : 0;
      const fromLeft = column > 0 ? dp[row][column - 1] : 0;
      dp[row][column] = (fromTop + fromLeft) % ROUTE_MODULO;
    }
  }

  return dp[height - 1][width - 1];
}
```

## 15. Dry-run

Grid 2×2 không puddle: start 1; cell phải 1; cell dưới 1; destination nhận `1+1=2`. Nếu puddle ở cell phải, destination chỉ nhận từ top/below path còn lại nên 1.

## 16. Edge cases

1. Một hàng hoặc một cột.
2. Puddle chặn route duy nhất.
3. Tọa độ x,y dễ đảo.
4. Destination nhận count đúng modulo.

## 17. Lỗi JavaScript thường gặp

- Dùng `[x][y]` thay `[row=y][column=x]`.
- Khởi tạo toàn first row/column là 1 bất chấp puddle.
- Quên modulo mỗi transition.
- Dùng `.fill(sameArray)` tạo alias rows.
- Overwrite start bằng transition zero.

## 18. Bài transfer cùng pattern

- OF032: max-sum DP, transition dùng max thay sum-count.
- OF060: 2D difference/prefix, iteration dependency khác.
- OF034: interval DP hai chiều state range.

Tín hiệu: đếm path monotone trên grid ⇒ dp cell bằng tổng predecessor, obstacle đặt zero.

## 19. Làm bằng tay và brute force executable

Grid 2×2 không puddle có hai đường `R,D` và `D,R`. Nếu puddle tại `[2,1]` (x=2,y=1), nhánh đi
phải bị chặn và chỉ còn một đường. Tọa độ input phải đổi thành row 0, column 1.

```js
function schoolRouteCountBrute(width, height, puddles) {
  const blocked = new Set(puddles.map(([x, y]) => `${y - 1}:${x - 1}`));

  function dfs(row, column) {
    if (row >= height || column >= width) return 0;
    if (blocked.has(`${row}:${column}`)) return 0;
    if (row === height - 1 && column === width - 1) return 1;
    return dfs(row + 1, column) + dfs(row, column + 1);
  }

  return dfs(0, 0) % 1_000_000_007;
}
```

Brute recursion tính lại số cách từ cùng cell; DP row-major gộp mọi prefix tại cell đó.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `blocked` | cell không đi được theo key row,column | đổi từng `[x,y]` sang zero-based |
| `dp[row][column]` | số path từ start tới cell | toàn 0, start bằng 1 |
| `fromTop`, `fromLeft` | hai tập path có bước cuối khác nhau | 0 nếu ngoài boundary |

## 21. Blueprint từ đề đến code

1. Chuyển tọa độ `[x,y]` thành `[row=y-1,column=x-1]` ngay khi dựng blocked.
2. State là số cách tới cell; start có một empty path.
3. Duyệt row-major để top và left đã sẵn sàng.
4. Puddle giữ count 0 và skip transition.
5. Cell thường nhận tổng top + left, modulo ngay mỗi bước.

## 22. Invariant, lỗi lộ diện và recall

Trước mỗi cell row-major, hai predecessor của nó đã đúng. Mọi route tới cell có bước cuối duy nhất
từ top hoặc left, nên hai tập rời nhau và được cộng. Puddle không có route hợp lệ nên state bằng 0.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| đảo x/y | grid 3×2, puddle `[2,1]` | 1 |
| fill first row/column bằng 1 | puddle chặn corridor | các cell sau bằng 0 |
| overwrite start | grid 1×1 | 1 |
| alias rows | update một cell đổi nhiều row | rows độc lập |

Recall: **count monotone grid = top + left; obstacle bằng 0; normalize x/y trước DP.**
