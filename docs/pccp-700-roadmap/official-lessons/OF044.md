# OF044 — Đá bước

- Nguồn đề: [Programmers lesson 43236](https://school.programmers.co.kr/learn/courses/30/lessons/43236?language=javascript)
- Pattern chính: binary search last feasible + greedy predicate
- Mức trong bank: STRETCH / advanced

## 01. Contract

Giữa start 0 và destination `distance` có rocks. Xóa tối đa n rock để maximize khoảng cách nhỏ nhất giữa các điểm liên tiếp còn lại.

## 02. Bound

Thử subset rock exponential. Answer integer và predicate “đạt minimum gap g được không” đơn điệu; binary search.

## 03. Brute force

Chọn mọi subset xóa, tính min gap, lấy maximum.

## 04. Bottleneck

Với target gap g, scan trái→phải: rock quá gần previous-kept phải xóa. Greedy giữ điểm sớm nhất hợp lệ minimize số removals.

## 05. Pattern

Predicate đếm removals khi `position-previous<g`, gồm destination sentinel. Feasible nếu removals≤n. Tìm last true.

## 06. State

Sorted positions + destination, `previous`, removed; binary low/high/mid.

## 07. Transition

Predicate: gap nhỏ thì remove current; đủ thì keep/update previous. Search feasible mid ⇒ low=mid+1; false ⇒ high=mid; answer low-1.

## 08. Invariant

Greedy previous là điểm kept sớm nhất có thể sau prefix và dùng minimum removals. Predicate true...true,false... theo g. Search interval giữ first false trong `[low,high]`.

## 09. Complexity

Sort `O(R log R)`; predicate `O(R)` × `O(log distance)`; space `O(R)`.

## 10. Pseudocode

```text
sort rocks; append destination
feasible(g): greedily count gaps<g removals
binary search first false g
return g-1
```

## 12. Code bước 2 — viết transition

## 13. Code bước 3 — ghép vòng lặp

```js
while (low<high) {
  const middle=low+Math.floor((high-low)/2);
  if (feasible(middle)) low=middle+1; else high=middle;
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF044.js](../../../solutions/official/OF044.js).

```js
function maximumMinimumRockDistance(distance,rocks,n) {
  const positions=[...rocks].sort((a,b)=>a-b); positions.push(distance);
  const feasible=gap=>{ let removed=0,previous=0; for (const p of positions) { if (p-previous<gap) removed++; else previous=p; } return removed<=n; };
  let low=0,high=distance+1;
  while (low<high) { const mid=low+Math.floor((high-low)/2); if (feasible(mid)) low=mid+1; else high=mid; }
  return low-1;
}
```

## 16. Edge cases

Không rock; xóa mọi rock; destination gap phải tính; answer 0/1; rock sát start.

## 17. Lỗi JavaScript thường gặp

Không append destination; khi remove vẫn update previous; convention binary lệch; dùng bitwise midpoint; predicate đảo monotonicity.
