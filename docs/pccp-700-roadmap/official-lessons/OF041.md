# OF041 — Hành trình du lịch

- Nguồn đề: [Programmers lesson 43164](https://school.programmers.co.kr/learn/courses/30/lessons/43164?language=javascript)
- Pattern chính: lexical Euler trail / Hierholzer
- Mức trong bank: TRANSFER / graph extension

## 01. Contract

Bắt đầu `ICN`, dùng mọi ticket đúng một lần; nếu nhiều itinerary, trả thứ tự từ điển nhỏ nhất.

## 02. Bound

Có tối đa `10,000` ticket, mỗi airport là mã ba chữ cái. Backtracking permutation có thể rất lớn. Đây là directed multigraph có Euler trail bảo đảm; Hierholzer dùng mỗi edge một lần sau sort, và explicit stack tránh call-stack overflow trên chain dài.

## 03. Brute force

DFS thử ticket chưa dùng theo lexical order và backtrack dead end; worst factorial.

## 04. Bottleneck

Đường đi tạm có thể đi vào dead end trước khi dùng hết edge. Hierholzer chỉ append airport vào route khi không còn outgoing edge, nên dead end được đặt đúng ở suffix.

## 05. Pattern

Adjacency destinations sort descending; pop lấy lexical nhỏ nhất. Dùng explicit traversal stack: còn outgoing edge thì push destination, hết edge thì pop airport sang reversed route; cuối cùng reverse.

## 06. State

Map airport→stack destinations, `routeReversed`; mỗi ticket là một array occurrence nên duplicate được giữ.

## 07. Transition

Nhìn airport ở đỉnh traversal stack. Nếu còn outgoing edge, pop destination nhỏ nhất và push nó vào stack; nếu hết edge, pop airport sang reversed route.

## 08. Invariant

Mỗi pop khỏi adjacency tiêu thụ đúng một ticket. Khi airport được pop khỏi traversal stack sang reversed route, mọi edge được chọn từ nó đã nằm trước nó trong reversed route. Chọn lexical smallest edge khi có choice tạo Euler itinerary lexical smallest.

## 09. Complexity

Tổng chi phí sort là `O(E log E)`, traversal `O(E)`, space `O(E)`. Explicit stack chứa tối đa `E + 1` airport và không phụ thuộc recursion depth của JavaScript.

## 10. Pseudocode

```text
group destinations; sort descending
stack = [ICN]
while stack not empty:
  airport = stack top
  if airport has outgoing:
    push pop-smallest destination onto stack
  else:
    append pop(stack) to reversed route
reverse route
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF041.js](../../../solutions/official/OF041.js).

```js
function travelItinerary(tickets) {
  const destinationsByAirport = new Map();
  for (const [from, to] of tickets) {
    if (!destinationsByAirport.has(from)) {
      destinationsByAirport.set(from, []);
    }
    destinationsByAirport.get(from).push(to);
  }
  for (const destinations of destinationsByAirport.values()) {
    destinations.sort((a, b) => b.localeCompare(a));
  }

  const routeReversed = [];
  const traversalStack = ["ICN"];
  while (traversalStack.length > 0) {
    const airport = traversalStack[traversalStack.length - 1];
    const destinations = destinationsByAirport.get(airport);
    if (destinations && destinations.length > 0) {
      traversalStack.push(destinations.pop());
    } else {
      routeReversed.push(traversalStack.pop());
    }
  }

  return routeReversed.reverse();
}
```

## 16. Edge cases

Duplicate tickets; lexical choice dẫn tới temporary dead end; airport không outgoing; cycle; chain dài tới `10,000` ticket phải dùng explicit stack.

## 17. Lỗi JavaScript thường gặp

Set adjacency làm mất duplicate; append preorder; sort ascending rồi pop lấy lớn nhất; không reverse; viết Hierholzer đệ quy rồi tràn call stack ở input dài.

### Loop and condition derivation

- **Nhịp lặp:** `while stack còn airport.`. Đây là lý do code dùng block bắt đầu bởi `while (traversalStack.length > 0) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “destinations có còn edge chưa dùng không.”. Trong dry run `ICN,A,ICN,A`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (!destinationsByAirport.has(from)) {`.
- **Tiến triển:** stack top thay đổi theo consume/backtrack, không recursion.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `mỗi ticket bị pop đúng một lần; route append ở dead end.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `const destinationsByAirport = new Map();`.
- **Cleanup:** reverse đúng một lần; route length phải bằng tickets.length+1.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Hành trình du lịch:** Guard visited, bounds hoặc stale distance phải chạy trước transition tương ứng. Với BFS, mark visited lúc enqueue để một đỉnh không xếp hàng nhiều lần; với Dijkstra, bỏ entry stale trước khi relax cạnh.

#### 19. Làm bằng tay và brute force executable

Hai ticket `ICN→A` là hai edge occurrence riêng. Với thêm `A→ICN`, route hợp lệ là
`ICN,A,ICN,A`; Set destination sẽ làm mất một ticket.

```js
function travelItineraryBrute(tickets) {
  const used = Array(tickets.length).fill(false);
  const route = ["ICN"];
  let answer = null;

  function dfs(airport) {
    if (route.length === tickets.length + 1) {
      const candidate = route.slice();
      if (answer === null || candidate.join(",") < answer.join(",")) answer = candidate;
      return;
    }
    for (let index = 0; index < tickets.length; index += 1) {
      if (used[index] || tickets[index][0] !== airport) continue;
      used[index] = true;
      route.push(tickets[index][1]);
      dfs(tickets[index][1]);
      route.pop();
      used[index] = false;
    }
  }

  dfs("ICN");
  return answer;
}
```

Brute force factorial. Hierholzer tiêu thụ mỗi edge một lần và ghép dead end theo postorder.
