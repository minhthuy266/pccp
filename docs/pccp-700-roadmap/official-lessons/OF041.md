# OF041 — Hành trình du lịch

- Nguồn đề: [Programmers lesson 43164](https://school.programmers.co.kr/learn/courses/30/lessons/43164?language=javascript)
- Pattern chính: lexical Euler trail / Hierholzer
- Mức trong bank: TRANSFER / graph extension

## 01. Contract

Bắt đầu `ICN`, dùng mọi ticket đúng một lần; nếu nhiều itinerary, trả thứ tự từ điển nhỏ nhất.

## 02. Bound

Backtracking permutation có thể rất lớn. Đây là directed multigraph có Euler trail bảo đảm; Hierholzer dùng mỗi edge một lần sau sort.

## 03. Brute force

DFS thử ticket chưa dùng theo lexical order và backtrack dead end; worst factorial.

## 04. Bottleneck

Đường đi tạm có thể đi vào dead end trước khi dùng hết edge. Hierholzer chỉ append airport vào route khi không còn outgoing edge, nên dead end được đặt đúng ở suffix.

## 05. Pattern

Adjacency destinations sort descending; pop lấy lexical nhỏ nhất. Recursively consume edges, postorder append, cuối reverse.

## 06. State

Map airport→stack destinations, `routeReversed`; mỗi ticket là một array occurrence nên duplicate được giữ.

## 07. Transition

Trong visit airport, pop/visit đến khi hết outgoing; sau đó push airport vào reversed route.

## 08. Invariant

Mỗi pop tiêu thụ đúng một ticket. Khi airport postorder-push, mọi edge reachable được chọn từ nó đã nằm trước nó trong reversed route. Chọn lexical smallest edge khi có choice tạo Euler itinerary lexical smallest.

## 09. Complexity

Sort tổng `O(E log E)`, traversal `O(E)`, space `O(E)` và recursion depth `O(E)`.

## 10. Pseudocode

```text
group destinations; sort descending
visit(airport):
  while outgoing: visit(pop smallest)
  append airport
visit(ICN)
reverse route
```


## 12. Code bước 2 — viết transition

```js
for (const destinations of graph.values()) destinations.sort((a,b)=>b.localeCompare(a));
```

## 13. Code bước 3 — ghép vòng lặp

```js
function visit(airport) {
  const destinations=graph.get(airport);
  while (destinations&&destinations.length) visit(destinations.pop());
  routeReversed.push(airport);
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF041.js](../../../solutions/official/OF041.js).

```js
function travelItinerary(tickets) {
  const graph=new Map();
  for (const [from,to] of tickets) { if (!graph.has(from)) graph.set(from,[]); graph.get(from).push(to); }
  for (const values of graph.values()) values.sort((a,b)=>b.localeCompare(a));
  const reversed=[];
  function visit(airport) { const values=graph.get(airport); while (values&&values.length) visit(values.pop()); reversed.push(airport); }
  visit("ICN"); return reversed.reverse();
}
```

## 15. Dry-run

ICN→A hai ticket, A→ICN: pop A, từ A pop ICN, từ ICN pop A; postorder reverse tạo `ICN,A,ICN,A`, dùng đủ duplicate.

## 16. Edge cases

Duplicate tickets; lexical choice dẫn tới temporary dead end; airport không outgoing; cycle.

## 17. Lỗi JavaScript thường gặp

Set adjacency làm mất duplicate; append preorder; sort ascending rồi pop lấy lớn nhất; không reverse; recursion depth lớn trong môi trường hạn chế.
