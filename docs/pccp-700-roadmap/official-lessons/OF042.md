# OF042 — Ghép mảnh puzzle

- Nguồn đề: [Programmers lesson 84021](https://school.programmers.co.kr/learn/courses/30/lessons/84021?language=javascript)
- Pattern chính: component extraction + canonical shape rotation
- Mức trong bank: STRETCH / special modeling

## 01. Contract

Extract lỗ `0` trên game board và mảnh `1` trên table theo bốn hướng. Mỗi mảnh dùng tối đa một lần, được xoay 90°, không phản chiếu; phải khớp chính xác lỗ. Tối đa hóa số ô lấp.

## 02. Bound

Grid nhỏ; BFS mỗi cell một lần, rồi so component/rotation.

## 03. Brute force

Thử mọi placement, rotation và assignment piece-hole trên grid; state explosion.

## 04. Bottleneck

Vị trí tuyệt đối không quan trọng, chỉ hình dạng. Dịch component về origin, sort coordinates thành canonical key; rotate bốn lần.

## 05. Pattern

Extract components; normalize; với mỗi hole tìm unused piece cùng size có một rotation key bằng hole; mark used và cộng size.

## 06. State

Arrays holes/pieces coordinates, `used`, canonical key; BFS visited.

## 07. Transition

Rotation `[r,c]→[c,-r]`, sau đó normalize. Match thành công consume piece và break.

## 08. Invariant

Extract trả maximal connected components đúng target. Normalize loại translation nhưng giữ adjacency. Bốn rotations liệt kê toàn orientation hợp lệ; used bảo đảm mỗi occurrence dùng một lần.

## 09. Complexity

Extract `O(N²)`; matching worst `O(H*P*4*S log S)`, đủ bound; space `O(N²)`.

## 10. Pseudocode

```text
holes=components(board,0); pieces=components(table,1)
for hole:
  for unused same-size piece:
    rotate up to 4; compare canonical key
    if match: use; answer+=size; break
```

## 11. Code bước 1 — dựng state

```js
function shapeKey(cells) {
  return normalizeShape(cells).map(([r,c])=>`${r}:${c}`).join("|");
}
```

## 12. Code bước 2 — viết transition

```js
function rotateShape(cells) {
  return normalizeShape(cells.map(([row,column])=>[column,-row]));
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
for (let turn=0;turn<4;turn++) {
  if (shapeKey(rotated)===holeKey) { matches=true; break; }
  rotated=rotateShape(rotated);
}
```

## 14. Code hoàn chỉnh

Code executable gồm extraction helpers: [solutions/official/OF042.js](../../../solutions/official/OF042.js).

```js
function matchOneHole(hole,pieces,used) {
  const key=shapeKey(hole);
  for (let i=0;i<pieces.length;i++) {
    if (used[i]||pieces[i].length!==hole.length) continue;
    let rotated=pieces[i];
    for (let turn=0;turn<4;turn++) {
      if (shapeKey(rotated)===key) { used[i]=true; return hole.length; }
      rotated=rotateShape(rotated);
    }
  }
  return 0;
}
```

## 15. Dry-run

L-piece `[(0,0),(1,0),(1,1)]` rotate/normalize thành `[(0,0),(0,1),(1,0)]`; translation ban đầu không ảnh hưởng key.

## 16. Edge cases

Một cell; duplicate shapes; piece chỉ khớp sau rotation; mirror không hợp lệ; component cùng size khác shape.

## 17. Lỗi JavaScript thường gặp

Không normalize sau rotate; cho phép reflection; dùng Set string unsorted; reuse piece; extract diagonal; alias visited rows.
