# OF042 — Ghép mảnh puzzle

- Nguồn đề: [Programmers lesson 84021](https://school.programmers.co.kr/learn/courses/30/lessons/84021?language=javascript)
- Pattern chính: component extraction + canonical shape rotation
- Mức trong bank: STRETCH / special modeling

## 01. Contract

Extract lỗ `0` trên game board và mảnh `1` trên table theo bốn hướng. Mỗi mảnh dùng tối đa một lần, được xoay 90°, không phản chiếu; phải khớp chính xác lỗ. Tối đa hóa số ô lấp.

## 02. Bound

Grid nhỏ; BFS mỗi cell một lần, rồi so component/rotation.

## 03. Brute force

Thử mọi placement, rotation và assignment piece-hole trên grid; state explosion.

## 04. Bottleneck

Vị trí tuyệt đối không quan trọng, chỉ hình dạng. Dịch component về origin, sort coordinates thành canonical key; rotate bốn lần.

## 05. Pattern

Extract components; normalize; với mỗi hole tìm unused piece cùng size có một rotation key bằng hole; mark used và cộng size.

## 06. State

Arrays holes/pieces coordinates, `used`, canonical key; BFS visited.

## 07. Transition

Rotation `[r,c]→[c,-r]`, sau đó normalize. Match thành công consume piece và break.

## 08. Invariant

Extract trả maximal connected components đúng target. Normalize loại translation nhưng giữ adjacency. Bốn rotations liệt kê toàn orientation hợp lệ; used bảo đảm mỗi occurrence dùng một lần.

## 09. Complexity

Extract `O(N²)`; matching worst `O(H*P*4*S log S)`, đủ bound; space `O(N²)`.

## 10. Pseudocode

```text
holes=components(board,0); pieces=components(table,1)
for hole:
  for unused same-size piece:
    rotate up to 4; compare canonical key
    if match: use; answer+=size; break
```

## 14. Code hoàn chỉnh

Code executable gồm extraction helpers: [solutions/official/OF042.js](../../../solutions/official/OF042.js).

```js
const SHAPE_DIRECTIONS = [[-1, 0], [1, 0], [0, -1], [0, 1]];

function normalizeShape(cells) {
  const minimumRow = Math.min(...cells.map(([row]) => row));
  const minimumColumn = Math.min(...cells.map(([, column]) => column));
  return cells
    .map(([row, column]) => [row - minimumRow, column - minimumColumn])
    .sort((a, b) => a[0] - b[0] || a[1] - b[1]);
}

function shapeKey(cells) {
  return normalizeShape(cells).map(([row, column]) => `${row}:${column}`).join("|");
}

function rotateShape(cells) {
  return normalizeShape(cells.map(([row, column]) => [column, -row]));
}

function extractComponents(board, target) {
  const rows = board.length;
  const columns = board[0].length;
  const visited = Array.from({ length: rows }, () => new Uint8Array(columns));
  const components = [];

  for (let startRow = 0; startRow < rows; startRow++) {
    for (let startColumn = 0; startColumn < columns; startColumn++) {
      if (visited[startRow][startColumn] || board[startRow][startColumn] !== target) continue;
      const queue = [[startRow, startColumn]];
      const cells = [];
      let head = 0;
      visited[startRow][startColumn] = 1;

      while (head < queue.length) {
        const [row, column] = queue[head++];
        cells.push([row, column]);
        for (const [deltaRow, deltaColumn] of SHAPE_DIRECTIONS) {
          const nextRow = row + deltaRow;
          const nextColumn = column + deltaColumn;
          if (
            nextRow < 0 || nextRow >= rows || nextColumn < 0 || nextColumn >= columns ||
            visited[nextRow][nextColumn] || board[nextRow][nextColumn] !== target
          ) continue;
          visited[nextRow][nextColumn] = 1;
          queue.push([nextRow, nextColumn]);
        }
      }
      components.push(normalizeShape(cells));
    }
  }
  return components;
}

function filledPuzzleCells(gameBoard, table) {
  const holes = extractComponents(gameBoard, 0);
  const pieces = extractComponents(table, 1);
  const used = Array(pieces.length).fill(false);
  let answer = 0;

  for (const hole of holes) {
    const holeKey = shapeKey(hole);
    for (let index = 0; index < pieces.length; index++) {
      if (used[index] || pieces[index].length !== hole.length) continue;
      let rotated = pieces[index];
      let matches = false;
      for (let turn = 0; turn < 4; turn++) {
        if (shapeKey(rotated) === holeKey) {
          matches = true;
          break;
        }
        rotated = rotateShape(rotated);
      }
      if (!matches) continue;
      used[index] = true;
      answer += hole.length;
      break;
    }
  }
  return answer;
}
```

## 15. Dry-run

L-piece `[(0,0),(1,0),(1,1)]` rotate/normalize thành `[(0,0),(0,1),(1,0)]`; translation ban đầu không ảnh hưởng key.

## 16. Edge cases

Một cell; duplicate shapes; piece chỉ khớp sau rotation; mirror không hợp lệ; component cùng size khác shape.

## 17. Lỗi JavaScript thường gặp

Không normalize sau rotate; cho phép reflection; dùng Set string unsorted; reuse piece; extract diagonal; alias visited rows.

## 19. Làm bằng tay và brute force executable

Mảnh `[(2,3),(3,3),(3,4)]` normalize thành `[(0,0),(1,0),(1,1)]`. Xoay 90° rồi normalize
thành `[(0,0),(0,1),(1,0)]`. Translation đã biến mất, nhưng reflection không tự xuất hiện.

```js
function sameShapeBrute(first, second) {
  if (first.length !== second.length) return false;

  function normalize(cells) {
    const minimumRow = Math.min(...cells.map(([row]) => row));
    const minimumColumn = Math.min(...cells.map(([, column]) => column));
    return cells
      .map(([row, column]) => [row - minimumRow, column - minimumColumn])
      .sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  }

  const target = JSON.stringify(normalize(second));
  let current = normalize(first);
  for (let turn = 0; turn < 4; turn += 1) {
    if (JSON.stringify(current) === target) return true;
    current = normalize(current.map(([row, column]) => [column, -row]));
  }
  return false;
}
```

Helper brute đối chiếu một cặp shape; solution thêm extraction component và consume từng piece.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `visited` | cell đã thuộc một component | matrix độc lập cho mỗi board |
| `cells` | tọa độ component đang extract | rỗng, thêm khi dequeue |
| `holes`, `pieces` | shape đã normalize | extract target 0 và target 1 |
| `used[index]` | piece occurrence đã consume | toàn false |
| `rotated` | orientation đang thử | shape gốc, xoay tối đa bốn lần |

## 21. Blueprint từ đề đến code

1. BFS/DFS bốn hướng để tách maximal components trên hai board.
2. Bỏ vị trí tuyệt đối bằng cách trừ minimum row/column và sort tọa độ.
3. Dùng canonical key để so shape, không so thứ tự discovery.
4. Với mỗi hole, chỉ xét piece cùng size và bốn rotation.
5. Match thành công thì mark đúng occurrence `used[index]`, cộng size và dừng tìm cho hole đó.

## 22. Invariant, lỗi lộ diện và recall

Extraction tạo mỗi cell target vào đúng một maximal component. Normalize bảo toàn hình nhưng loại
translation; rotate + normalize liệt kê đúng bốn orientation được phép. `used` giữ invariant mỗi
piece occurrence ghép nhiều nhất một hole.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| nối diagonal thành component | `[[1,0],[0,1]]` | hai component |
| không normalize sau rotate | L-piece lệch tọa độ âm | vẫn match |
| cho phép mirror | hai shape đối xứng gương | không match |
| dùng Set theo shape key thay occurrence | hai piece giống nhau | dùng được cả hai |

Recall: **extract component → normalize translation → thử 4 rotations → consume occurrence.**
