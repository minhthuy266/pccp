# OF026 — Cần điều khiển

- Nguồn đề: [Programmers lesson 42860](https://school.programmers.co.kr/learn/courses/30/lessons/42860?language=javascript)
- Pattern chính: independent vertical cost + horizontal route case analysis
- Mức trong bank: STRETCH / special case

## 01. Contract

Từ chuỗi toàn `A`, đổi thành `name`. Lên/xuống đổi chữ vòng tròn A–Z; trái/phải di chuyển cursor vòng tròn. Tìm tổng thao tác nhỏ nhất.

## 02. Bound

Chi phí đổi ký tự độc lập theo vị trí; phần khó là route ngang bỏ qua các đoạn `A`. Scan mọi điểm quay đầu `O(n²)` worst case với tìm next, vẫn đủ bound.

## 03. Brute force

BFS trên toàn state `(string,cursor)` có không gian khổng lồ; hoặc thử mọi thứ tự thăm vị trí cần đổi.

## 04. Bottleneck

Vertical không phụ thuộc route. Horizontal optimum có thể đi thẳng, đi phải rồi quay trái, hoặc trái rồi quay phải quanh một run A. Chỉ cần xét boundary mỗi run A.

## 05. Pattern

Vertical tại chữ index x là `min(x,26-x)`. Horizontal ban đầu `n-1`; với vị trí i và next non-A sau run:

```text
min(2*i + n-next, i + 2*(n-next))
```

## 06. State

`verticalMoves`, `horizontalMoves`, current `index`, `next` non-A.

## 07. Transition

Cộng vertical từng char. Từ mỗi i, scan next qua A rồi relax hai route quay đầu.

## 08. Invariant

Vertical sum luôn là minimum độc lập cho prefix ký tự. Horizontal là minimum trong mọi route candidate đã xét; mọi route tối ưu chỉ cần đổi hướng tại boundary của vùng cần thăm, tương ứng một run A được bỏ qua.

## 09. Complexity

Time `O(n²)` worst case do scan run cho mỗi i; space `O(1)`.

## 10. Pseudocode

```text
vertical=0; horizontal=n-1
for i:
  vertical += min(letterIndex,26-letterIndex)
  next=i+1; skip A
  horizontal=min(horizontal,2*i+n-next,i+2*(n-next))
return vertical+horizontal
```

## 11. Code bước 1 — dựng state

```js

```

## 12. Code bước 2 — viết transition

```js

```

## 13. Code bước 3 — ghép vòng lặp

```js

while (next<name.length && name[next]==="A") next++;
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF026.js](../../../solutions/official/OF026.js).

```js
function joystickMinimumMoves(name) {
  const length = name.length;
  let verticalMoves = 0;
  let horizontalMoves = Math.max(0, length - 1);

  for (let index = 0; index < length; index++) {
    const alphabetIndex = name.charCodeAt(index) - 65;
    verticalMoves += Math.min(alphabetIndex, 26 - alphabetIndex);

    let next = index + 1;
    while (next < length && name[next] === "A") {
      next += 1;
    }

    horizontalMoves = Math.min(
      horizontalMoves,
      index * 2 + length - next,
      index + (length - next) * 2,
    );
  }

  return verticalMoves + horizontalMoves;
}
```

## 15. Dry-run

Tên toàn A có vertical 0; mọi i có thể làm horizontal về 0. Với run A dài giữa các ký tự cần đổi, hai công thức so đi phải-quay lại và đi trái-quay lại.

## 16. Edge cases

Toàn A; một ký tự; run A ở giữa; ký tự cần đổi ở hai đầu; Z dùng một bước xuống.

## 17. Lỗi JavaScript thường gặp

Chỉ dùng n-1 horizontal; quên wrap alphabet; bỏ một trong hai công thức quay đầu; horizontal âm khi n=0; nhầm `next` là length A thay vì index sau run.

## 18. Bài transfer cùng pattern

- OF030: greedy có proof endpoint rõ hơn.
- OF028: two-end route decision.
- OF040: coordinate modeling đặc thù.

Tín hiệu: cost tách thành độc lập theo node + route thăm node, hãy giải hai phần riêng rồi xét đầy đủ route case.

## 19. Làm bằng tay và brute force executable

Với `ABAAAAAAAAABB`, vertical cost là 3 cho ba chữ B. Đi thẳng phải gần hết chuỗi rất tốn; route
quay trái qua vòng rồi đổi hướng quanh run A dài cho horizontal 4, tổng 7.

```js
function joystickMinimumMovesBrute(name) {
  const length = name.length;
  let vertical = 0;
  let targetMask = 0;
  for (let index = 0; index < length; index += 1) {
    const value = name.charCodeAt(index) - 65;
    vertical += Math.min(value, 26 - value);
    if (value !== 0) targetMask |= 1 << index;
  }

  const startMask = name[0] === "A" ? 0 : 1;
  const queue = [[0, startMask, 0]];
  const visited = new Set([`0:${startMask}`]);
  for (let head = 0; head < queue.length; head += 1) {
    const [cursor, mask, moves] = queue[head];
    if ((mask & targetMask) === targetMask) return vertical + moves;
    for (const next of [(cursor + 1) % length, (cursor - 1 + length) % length]) {
      const nextMask = name[next] === "A" ? mask : mask | (1 << next);
      const key = `${next}:${nextMask}`;
      if (visited.has(key)) continue;
      visited.add(key);
      queue.push([next, nextMask, moves + 1]);
    }
  }
  return vertical;
}
```

Brute BFS horizontal dùng bitmask, chỉ phù hợp tên ngắn. Bản tối ưu chứng minh chỉ cần xét boundary run A.

## 20. Bảng state và khởi tạo

| State | Ý nghĩa | Khởi tạo |
| --- | --- | --- |
| `verticalMoves` | tổng đổi ký tự độc lập | `0` |
| `horizontalMoves` | route ngang tốt nhất đã biết | `length-1` |
| `index` | điểm có thể quay đầu | quét 0..n-1 |
| `next` | vị trí non-A đầu sau run A | `index+1`, rồi skip A |

## 21. Blueprint từ đề đến code

1. Tách vertical và horizontal vì đổi chữ không phụ thuộc route.
2. Vertical mỗi chữ là min đi lên và wrap đi xuống.
3. Horizontal baseline là đi thẳng phải `n-1`.
4. Với mỗi index, tìm run A kế tiếp có thể bỏ qua.
5. Relax hai hướng quay đầu: phải trước rồi trái, hoặc trái trước rồi phải.
6. Cộng hai cost độc lập.

## 22. Invariant, lỗi lộ diện và recall

Vertical sum luôn tối ưu từng ký tự độc lập. Sau index i, horizontal là minimum của baseline và mọi
route quay đầu quanh run A đã xét. Một route tối ưu chỉ cần đổi hướng ở boundary vùng cần thăm; mọi
khả năng bỏ một run A được scan nên hai công thức phủ optimum.

| Sai lầm | Test làm lộ | Kết quả đúng |
| --- | --- | ---: |
| chỉ đi thẳng `n-1` | `ABAAAAAAAAABB` | 7 tổng |
| quên alphabet wrap | `Z` | 1 |
| chỉ xét một hướng quay đầu | non-A gần cả hai đầu | min hai công thức |
| all A vẫn di chuyển | `AAAA` | 0 |

Recall: **joystick = vertical độc lập + horizontal route; scan run A và xét cả hai kiểu quay đầu.**
