# OF031 — Biểu diễn bằng N

- Nguồn đề: [Programmers lesson 42895](https://school.programmers.co.kr/learn/courses/30/lessons/42895?language=javascript)
- Pattern chính: Set-DP theo resource count
- Mức trong bank: TRANSFER / variant

## 01. Contract

Dùng chữ số N tối đa 8 lần, phép `+,-,*,/` và phép nối như `NN`, tìm số lần dùng ít nhất tạo target; không được trả về thì `-1`. Chia lấy phần nguyên theo rule bài.

## 02. Bound

Số count chỉ 1..8 nhưng expression tree nhiều. DP Set gộp mọi expression cùng value/count.

## 03. Brute force

Sinh mọi cây biểu thức, operator và partition; vô số expression trùng value.

## 04. Bottleneck

Future chỉ cần value đạt được và số N đã dùng, không cần cấu trúc expression. Set deduplicate state.

## 05. Pattern

`dp[count]` là Set mọi value dùng đúng count N. Thêm concatenation; split count thành left/right và combine Cartesian product bốn phép.

## 06. State

`valuesByCount[1..8]`; loop `count`, `leftCount`, values left/right.

## 07. Transition

Add `N` repeated count; với mọi partition add plus/minus/multiply và trunc division nếu denominator khác zero. Sau xây count, check target.

## 08. Invariant

Sau count c, Set chứa mọi và chỉ value tạo bởi đúng c N: base concatenation, hoặc root operator chia expression thành i và c-i N. Induction cover mọi expression tree.

## 09. Complexity

Phụ thuộc kích thước Set; với count≤8 đủ nhỏ. Space là tổng unique states.

## 10. Pseudocode

```text
for count 1..8:
  add concatenated N
  for split 1..count-1:
    for left in dp[split], right in dp[count-split]: add operations
  if target in set return count
return -1
```

## 11. Code bước 1 — dựng state

```js

```

## 12. Code bước 2 — viết transition

```js

```

## 13. Code bước 3 — ghép vòng lặp

```js
set.add(left+right); set.add(left-right); set.add(left*right);
if (right!==0) set.add(Math.trunc(left/right));
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF031.js](../../../solutions/official/OF031.js).

```js
function minimumNExpressionCount(n, target) {
  const valuesByCount = Array.from({ length: 9 }, () => new Set());

  for (let count = 1; count <= 8; count++) {
    valuesByCount[count].add(Number(String(n).repeat(count)));

    for (let leftCount = 1; leftCount < count; leftCount++) {
      const rightCount = count - leftCount;
      for (const left of valuesByCount[leftCount]) {
        for (const right of valuesByCount[rightCount]) {
          valuesByCount[count].add(left + right);
          valuesByCount[count].add(left - right);
          valuesByCount[count].add(left * right);
          if (right !== 0) {
            valuesByCount[count].add(Math.trunc(left / right));
          }
        }
      }
    }

    if (valuesByCount[count].has(target)) {
      return count;
    }
  }

  return -1;
}
```

### Loop and condition derivation

- **Nhịp lặp:** `với mỗi count thêm concatenation, rồi thử mọi split left+right=count.`. Đây là lý do code dùng block bắt đầu bởi `for (let count = 1; count <= 8; count++) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “rightValue !== 0 trước division; Set hiện tại có target không.”. Trong dry run `55/5+1=12`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (right !== 0) {`.
- **Tiến triển:** count tăng; split tăng; hai for...of quét Cartesian product.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `add mọi result vào valuesByCount[count].` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `for (let count = 1; count <= 8; count++) {`.
- **Cleanup:** Set tự gộp expression cùng value nhưng không gộp khác exact count.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

#### 19. Làm bằng tay và brute force executable

Với N=5, count 2 chứa `55`, `5+5=10`, `5-5=0`, `5*5=25`, `5/5=1`. Count 4 có thể
tạo `55/5+1=12`, nên target 12 dùng tối thiểu 4 chữ số.

```js
function minimumNExpressionCountBrute(n, target) {
  function build(count) {
    const values = [Number(String(n).repeat(count))];
    for (let leftCount = 1; leftCount < count; leftCount += 1) {
      for (const left of build(leftCount)) {
        for (const right of build(count - leftCount)) {
          values.push(left + right, left - right, left * right);
          if (right !== 0) values.push(Math.trunc(left / right));
        }
      }
    }
    return values;
  }

  for (let count = 1; count <= 8; count += 1) {
    if (build(count).includes(target)) return count;
  }
  return -1;
}
```

Brute build lại cùng subtree và giữ duplicate value. Set-DP memo theo exact count loại cả hai lãng phí.
