# OF018 — Hình chữ nhật nhỏ nhất

- Nguồn đề: [Programmers lesson 86491](https://school.programmers.co.kr/learn/courses/30/lessons/86491?language=javascript)
- Pattern chính: normalize orientation + extrema
- Mức trong bank: TRANSFER / warmup

## 01. Contract

Mỗi danh thiếp có hai cạnh và được phép xoay. Tìm diện tích ví nhỏ nhất chứa được mọi thẻ.

## 02. Bound

Một scan tuyến tính đủ; không cần thử `2^n` cách xoay.

## 03. Brute force

Với mỗi thẻ chọn xoay/không xoay, tính max width × max height cho mọi configuration. Có `2^n` configuration.

## 04. Bottleneck

Hai orientation của từng thẻ tương đương nếu chuẩn hóa cạnh dài luôn nằm cùng một trục, cạnh ngắn ở trục kia. Sau đó chỉ cần hai maximum.

## 05. Pattern

Với `[a,b]`, lấy `long=max(a,b)`, `short=min(a,b)`. Ví cần `maxLong × maxShort`.

## 06. State

`maximumLongSide`, `maximumShortSide`; không cần giữ orientation từng thẻ.

## 07. Transition

Mỗi thẻ cập nhật hai maximum sau normalize.

## 08. Invariant

Sau prefix thẻ, hai state là kích thước nhỏ nhất chứa mọi thẻ prefix khi cạnh dài đã đặt cùng trục. Mọi orientation khác không thể giảm đồng thời hai cực trị so với normalization này.

## 09. Complexity

Time `O(n)`, space `O(1)`.

## 10. Pseudocode

```text
maxLong=0; maxShort=0
for [a,b]:
  maxLong=max(maxLong,max(a,b))
  maxShort=max(maxShort,min(a,b))
return maxLong*maxShort
```

## 11. Code bước 1 — dựng state

```js
let maximumLongSide=0;
let maximumShortSide=0;
```

## 12. Code bước 2 — viết transition

```js
function normalize(width,height) {
  return [Math.max(width,height),Math.min(width,height)];
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
for (const [width,height] of sizes) {
  const [long,short]=normalize(width,height);
  maximumLongSide=Math.max(maximumLongSide,long);
  maximumShortSide=Math.max(maximumShortSide,short);
}
```

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF018.js](../../../solutions/official/OF018.js).

```js
function minimumWalletArea(sizes) {
  let maxLong=0,maxShort=0;
  for (const [width,height] of sizes) {
    maxLong=Math.max(maxLong,Math.max(width,height));
    maxShort=Math.max(maxShort,Math.min(width,height));
  }
  return maxLong*maxShort;
}
```

## 15. Dry-run

`[60,50],[30,70]` normalize thành `[60,50],[70,30]`; wallet `70×50`, không phải lấy max width/max height của orientation ban đầu.

## 16. Edge cases

Một thẻ; thẻ vuông; cạnh dài nhất và cạnh ngắn-max nằm ở hai thẻ khác nhau; mọi thẻ cần xoay khác nhau.

## 17. Lỗi JavaScript thường gặp

Lấy max từng cột trước normalize; sort toàn input không cần; mutate pair; nhân maximum của toàn bộ 2n cạnh hai lần.

## 18. Bài transfer cùng pattern

- OF021: reduce geometry về factor equations.
- OF015: normalize index rồi sort slice.
- OF057: normalize decision qua endpoint.

Tín hiệu: mỗi item có orientation hoán đổi hai chiều ⇒ normalize local trước khi aggregate extrema.

## 19. Làm tay và brute force

`[60,50]`, `[30,70]` normalize thành `[60,50]`, `[70,30]`; ví cần `70×50`. Brute thử
hai orientation cho mọi card tạo `2^n` cấu hình. Vì từng card xoay độc lập, đặt cạnh dài
cùng một chiều loại toàn bộ nhánh, rồi lấy hai maximum.

## 20. State, Blueprint, invariant

| State | Nghĩa | Init |
| --- | --- | --- |
| `maximumLongSide` | cạnh dài lớn nhất prefix | `0` |
| `maximumShortSide` | cạnh ngắn lớn nhất prefix | `0` |

```text
OUTPUT area; LOOP từng pair; CURRENT long=max(width,height), short=min;
UPDATE hai maximum; RETURN product; không mutate sizes.
```

Sau mỗi card, hai state là kích thước nhỏ nhất chứa toàn bộ prefix đã normalize. Mỗi maximum
có một card witness nên giảm bất kỳ chiều nào sẽ làm card đó không vừa.

## 21. Lỗi/test và recall

| Lỗi | Test | Đúng |
| --- | --- | --- |
| không xoay | `[[10,100],[90,20]]` | `2000` |
| max theo cột gốc | cùng test | thừa diện tích |
| min toàn cục | `[[8,6],[7,5]]` | `48` |
| swap pair tại chỗ | lưu clone | input không đổi |

Recall: từng card `long=max`, `short=min`; lấy max của từng role; nhân.

## A17. Blueprint đủ trường và Recall ba tầng

```text
OUTPUT: diện tích ví nhỏ nhất chứa mọi card sau khi được xoay.
PREPARE: normalize mỗi pair thành long=max và short=min.
GLOBAL STATE: maximumLongSide và maximumShortSide.
INIT: hai maximum = 0 vì chưa đọc card nào.
MAIN LOOP: quét từng [width,height].
CURRENT ITEM: card hiện tại với longSide và shortSide.
PER-ITERATION STATE: hai cạnh normalized chỉ sống trong lượt.
CHECK: cạnh hiện tại có lớn hơn maximum cùng vai trò không.
BRANCH: Math.max xử lý hai check, không cần if riêng.
UPDATE: cập nhật maximumLongSide và maximumShortSide độc lập.
POINTER MOVEMENT: for...of tự sang card kế tiếp.
STOP / RETURN: hết cards thì return tích hai maximum.
CLEANUP: không mutate orientation gốc; không ghép long của card này với short chưa normalize.
```

- Recall 1: Xoay từng card để cạnh dài cùng một vai trò, lấy max của hai vai trò rồi nhân.
- Recall 2: STATE maxLong/maxShort → LOOP cards → CHECK max/min → UPDATE maxima → RETURN product.
- Recall 3: Điền `longSide = Math.___(width,height)` và `shortSide = Math.___(width,height)`.
