# OF054 — Làm hai queue có tổng bằng nhau

- Nguồn đề: [Programmers lesson 118667](https://school.programmers.co.kr/learn/courses/30/lessons/118667?language=javascript)
- Pattern chính: two queue pointers + conserved sum
- Mức trong bank: TRANSFER / invariant

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Một operation lấy phần tử front của queue này và đưa vào back queue kia. Tìm số operation ít nhất để tổng hai queue bằng nhau; không thể thì `-1`. Các phần tử dương và hai queue ban đầu cùng độ dài.

## 02. Bound

Dùng `shift()` làm mỗi operation `O(n)`. Có thể biểu diễn chuỗi phần tử mà queue1 nhận/mất bằng một window trên `queue1 + queue2`, hai pointer chỉ tiến.

## 03. Brute force

Mô phỏng hai array bằng `shift/push`, thử chuyển từ queue có tổng lớn hơn. Logic choice đúng với số dương nhưng implementation dịch array và cần bound chống cycle.

## 04. Bottleneck

Tổng toàn hệ thống bảo toàn. Nếu total lẻ, impossible. Queue1 tại mọi thời điểm là một đoạn liên tiếp trong chuỗi ghép theo thứ tự chuyển; sum dương cho biết: thấp thì mở right, cao thì tăng left.

## 05. Pattern

Window target `total/2`:

```text
current < target → đọc combined[right] → cộng vào sum → tăng right
current > target → đọc combined[left] → trừ khỏi sum → tăng left
```

Mỗi pointer tối đa đi qua combined một lần.

## 06. State

- `combined=[...queue1,...queue2]`;
- window queue1 `[left,right)`;
- `current` sum window;
- `target`, `operations`.

## 07. Transition

Nhận phần tử: add trước vị trí right rồi right++. Bỏ phần tử: subtract vị trí left rồi left++. Mỗi transition tương ứng đúng một queue operation.

## 08. Invariant

`current` bằng tổng đoạn `[left,right)` đại diện queue1 sau đúng `operations` moves. Vì value dương, khi current thấp chỉ mở rộng mới có thể tăng; khi cao chỉ thu trái mới có thể giảm. Do đó greedy pointer không bỏ qua target window hợp lệ sớm hơn.

## 09. Complexity

Time `O(n)`, space `O(n)` cho combined. Mỗi pointer bị chặn bởi `2n`; không cần magic loop vô hạn.

## 10. Pseudocode

```text
total=sum both; if odd return -1
target=total/2; combined=q1+q2
left=0; right=len(q1); current=sum(q1); ops=0
while left<combined.length:
  if current==target return ops
  if current<target:
    if right==combined.length: break
    entering = combined[right]
    current += entering
    right += 1
  else:
    leaving = combined[left]
    current -= leaving
    left += 1
  ops += 1
return -1
```

## 11. Code bước 1 — dựng state

```js
function queueWindow(queue1, queue2) {
  return { combined:[...queue1,...queue2], left:0, right:queue1.length };
}
```

## 12. Code bước 2 — viết transition

```js
function receive(state) {
  const enteringValue = state.combined[state.right];
  state.current += enteringValue;
  state.right += 1;
}
```

## 13. Code bước 3 — ghép vòng lặp

```js
function release(state) {
  const leavingValue = state.combined[state.left];
  state.current -= leavingValue;
  state.left += 1;
}
```

Hai transition đều tiến pointer, nên không cycle.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF054.js](../../../solutions/official/OF054.js).

```js
function equalQueueSumOperations(queue1, queue2) {
  const combined = [...queue1, ...queue2];
  let totalSum = 0;
  for (const value of combined) {
    totalSum += value;
  }
  if (totalSum % 2 !== 0) return -1;

  const targetSum = totalSum / 2;
  let queue1Sum = 0;
  for (const value of queue1) {
    queue1Sum += value;
  }

  let left = 0;
  let right = queue1.length;
  let operationCount = 0;

  while (left < combined.length) {
    if (queue1Sum === targetSum) return operationCount;

    if (queue1Sum < targetSum) {
      if (right >= combined.length) break;
      const enteringValue = combined[right];
      queue1Sum += enteringValue;
      right += 1;
    } else {
      const leavingValue = combined[left];
      queue1Sum -= leavingValue;
      left += 1;
    }

    operationCount += 1;
  }

  return -1;
}
```

## 15. Dry-run

Q1 sum 14, Q2 sum 16, target 15: current thấp nên nhận front Q2; nếu value làm current cao, bước sau bỏ front Q1. Mỗi thay đổi chính xác một operation và window dịch theo FIFO.

## 16. Edge cases

1. Sum đã bằng: 0.
2. Total lẻ: -1 ngay.
3. Một value lớn hơn target có thể làm impossible.
4. Cần nhiều lần nhận rồi nhiều lần bỏ.

## 17. Lỗi JavaScript thường gặp

- `shift()` lặp.
- Chỉ giới hạn operations bằng số đoán tùy ý.
- Không check total lẻ.
- Pointer right vượt combined.
- Dùng Number nếu constraints tổng vượt safe integer; bài này nằm trong miền Number an toàn theo contract hiện hành.

## 18. Bài transfer cùng pattern

- OF053: positive window đạt target sum trên một sequence.
- OF009: re-enqueue queue item với identity.
- SR004: hai front độc lập nhưng không có invariant sum.

Tín hiệu: move front→back bảo toàn thứ tự vòng và value dương ⇒ biểu diễn queue bằng window trên array nối.

## 19. Từ hai queue thật đến một cửa sổ dễ code

### Làm bằng tay và brute force

Mỗi lần chỉ có hai lựa chọn hợp lý vì value dương: queue1 nặng hơn target thì chuyển front của
queue1 sang queue2; queue1 nhẹ hơn thì nhận front queue2. Tổng toàn hệ thống không đổi.

```js
function equalQueueSumOperationsBruteForce(queue1, queue2) {
  const firstQueue = queue1.slice();
  const secondQueue = queue2.slice();
  let firstSum = firstQueue.reduce((sum, value) => sum + value, 0);
  let secondSum = secondQueue.reduce((sum, value) => sum + value, 0);
  const operationLimit = (queue1.length + queue2.length) * 3;

  for (let operationCount = 0; operationCount <= operationLimit; operationCount++) {
    if (firstSum === secondSum) return operationCount;
    if (firstSum > secondSum) {
      const leavingValue = firstQueue.shift();
      if (leavingValue === undefined) return -1;
      firstSum -= leavingValue;
      secondSum += leavingValue;
      secondQueue.push(leavingValue);
    } else {
      const enteringValue = secondQueue.shift();
      if (enteringValue === undefined) return -1;
      secondSum -= enteringValue;
      firstSum += enteringValue;
      firstQueue.push(enteringValue);
    }
  }
  return -1;
}
```

Baseline dễ hiểu nhưng `shift()` dịch array và operation limit là hàng rào chống cycle khó
chứng minh. Thứ tự FIFO cho phép xem queue1 như window `[left,right)` trên `queue1+queue2`.

### State, init và ý nghĩa pointer

| State | Kiểu | Lưu chính xác gì | Init/lý do | Scope |
| --- | --- | --- | --- | --- |
| `combined` | number[] | thứ tự các value có thể đi qua queue1 | nối hai queue | toàn hàm |
| `left` | number | front logic của queue1 | `0` | xuyên loop |
| `right` | number | vị trí đầu tiên chưa thuộc queue1 | `queue1.length` | xuyên loop |
| `queue1Sum` | number | tổng window `[left,right)` | sum queue1 | xuyên loop |
| `targetSum` | number | nửa tổng bảo toàn | `total/2` | toàn hàm |
| `operationCount` | number | số move đã mô phỏng | `0` | output state |
| `enteringValue`,`leavingValue` | number | value vào/ra window | từ pointer | iteration |

Total lẻ return `-1` trước loop. Positive values là điều kiện cho transition đơn điệu: sum thấp
chỉ có thể tăng bằng mở right; sum cao chỉ có thể giảm bằng tăng left.

```text
OUTPUT: minimum operation count hoặc -1; PREPARE: combined,total,target
GLOBAL STATE: left,right,queue1Sum,operationCount
INIT: 0,queue1.length,sum(queue1),0; MAIN LOOP: while left<combined.length
CURRENT ITEM: entering at right hoặc leaving at left
PER-ITERATION STATE: enteringValue/leavingValue
CHECK: sum==target? sum<target? right còn trong bound?
BRANCH: thấp → add rồi right++; cao → subtract rồi left++
UPDATE: queue1Sum và đúng một pointer; operationCount++ sau move
POINTER MOVEMENT: pointer tách riêng khỏi array access
STOP / RETURN: equal → count; không thể mở rộng → break; cuối -1
CLEANUP: không
```

Invariant đầu vòng: `queue1Sum` đúng bằng tổng `combined[left..right)` sau đúng
`operationCount` moves. Mỗi transition là đúng một front→back operation, nên lần đầu chạm target
là số operation nhỏ nhất trên đường pointer đơn điệu.

| Sum trước | So target | Transition | Pointer | Operations |
| ---: | --- | --- | --- | ---: |
| 14 | `<15` | add front queue2 | right++ | 1 |
| 18 | `>15` | remove front queue1 | left++ | 2 |
| 15 | bằng | return | không đổi | 2 |

Mỗi pointer chỉ tiến tối đa độ dài combined: `O(n)` time, `O(n)` space cho array nối. Không có
nested rescan và không cần magic operation limit.

- Logic: chuyển từ queue nhẹ sang queue nặng; sum càng lệch.
- Off-by-one: right khởi tạo `queue1.length-1`; window thiếu phần tử cuối.
- Check/update: `right++` trước khi đọc làm skip front queue2.
- Init: quên total lẻ; `[1],[2]` không thể bằng nhau.
- Hidden: sum đã bằng phải return 0 trước bất kỳ move nào.
- Performance: dùng `shift()` ở mỗi operation trên input lớn.

```text
Recall 1: total lẻ fail; queue1 là window; thấp add right; cao remove left; bằng return.
Recall 2: STATE combined,left,right,sum,target,ops; LOOP; CHECK; UPDATE pointer; RETURN.
Recall 3: if (sum < target) { sum += combined[____]; ____++; } else { sum -= combined[____]; ____++; }
OUT: min moves/-1; LIMIT: pointers O(n); HAND: theo dõi sum queue1
BRUTE: shift/push hai queue; SLOW: shift và cycle bound; PATTERN: positive window
STATE + INIT: [left,right)=[0,n),sum=q1; LOOP + INVARIANT: window là queue1
UPDATE + STOP: add/right hoặc subtract/left, equal return
```
