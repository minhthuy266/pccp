# OF036 — Số mục tiêu

- Nguồn đề: [Programmers lesson 43165](https://school.programmers.co.kr/learn/courses/30/lessons/43165?language=javascript)
- Pattern chính: DFS trên cây lựa chọn nhị phân
- Mức trong bank: CORE / template

Tài liệu diễn giải lại contract để học; trang Programmers ở trên là nguồn đề chuẩn.

## 01. Contract

Dùng mọi số đúng một lần và giữ thứ tự; với mỗi số chọn dấu `+` hoặc `-`. Đếm số chuỗi lựa chọn tạo tổng `target`.

Đếm cách, không cần trả biểu thức.

## 02. Bound

Số phần tử nhỏ đủ để duyệt `2^n` cách. Đây là exhaustive search có chủ đích, không phải DFS vì nhìn thấy chữ “cây”.

## 03. Brute force

Sinh toàn bộ mảng dấu dài `n`, tính sum mỗi mảng từ đầu `O(n*2^n)`. Đúng nhưng tính lại prefix sum.

## 04. Bottleneck

Hai expression có chung prefix lựa chọn có chung partial sum. DFS truyền sum xuống nhánh, mỗi edge cập nhật `O(1)` thay vì tính lại toàn biểu thức.

## 05. Pattern

Cây quyết định:

```text
state(index,sum)
branch +numbers[index]
branch -numbers[index]
base index==n: sum==target ? 1 : 0
```

## 06. State

State đủ là `(index, sum)`. `index` cho biết đã dùng bao nhiêu số; `sum` là kết quả của đúng prefix đó. Không cần visited vì mỗi level dùng index kế tiếp.

## 07. Transition

Từ `(i,sum)` tạo `(i+1,sum+numbers[i])` và `(i+1,sum-numbers[i])`. Base chỉ kiểm target sau khi đã dùng hết số.

## 08. Invariant

Mỗi lời gọi `dfs(index,sum)` đại diện đúng một prefix gồm `index` quyết định, và `sum` là tổng của prefix đó. Hai nhánh liệt kê đầy đủ, không trùng mọi lựa chọn dấu cho số kế tiếp.

## 09. Complexity

- Time `O(2^n)` nodes/leaves theo bound nhỏ.
- Call stack `O(n)`.
- Không lưu toàn bộ expression.

## 10. Pseudocode

```text
ways=0
dfs(index,sum):
  if index==n:
    if sum==target: ways++
    return
  dfs(index+1,sum+numbers[index])
  dfs(index+1,sum-numbers[index])
dfs(0,0)
return ways
```

## 11. Code bước 1 — dựng state

```js
function isLeaf(index, numbers) {
  return index === numbers.length;
}
```

Không dừng sớm khi partial sum bằng target vì còn số chưa dùng.

## 12. Code bước 2 — viết transition

```js
function nextSums(sum, value) {
  return [sum + value, sum - value];
}
```

Hai nhánh đều tăng index đúng một.

## 13. Code bước 3 — ghép vòng lặp

```js
function countFrom(numbers, target, index, sum) {
  if (index === numbers.length) return sum === target ? 1 : 0;
  return countFrom(numbers,target,index+1,sum+numbers[index]) +
    countFrom(numbers,target,index+1,sum-numbers[index]);
}
```

Có thể cộng return hoặc dùng counter closure; code cuối dùng counter để nhìn rõ base.

## 14. Code hoàn chỉnh

Code executable: [solutions/official/OF036.js](../../../solutions/official/OF036.js).

```js
function targetNumberWays(numbers, target) {
  let ways = 0;

  function dfs(index, sum) {
    if (index === numbers.length) {
      if (sum === target) {
        ways += 1;
      }
      return;
    }

    dfs(index + 1, sum + numbers[index]);
    dfs(index + 1, sum - numbers[index]);
  }

  dfs(0, 0);
  return ways;
}
```

Numbers `[1,1]`, target `0` tạo bốn leaf: `+1+1=2`, `+1-1=0`, `-1+1=0`, `-1-1=-2`; answer 2.

## 16. Edge cases

1. Target âm.
2. Một phần tử.
3. Nhiều value giống nhau: lựa chọn theo index vẫn là các cách riêng.
4. Partial sum bằng target trước leaf: chưa được đếm.

## 17. Lỗi JavaScript thường gặp

- Quên `return` ở base rồi truy cập out-of-bounds.
- Chỉ tạo nhánh cộng.
- Mutate global sum rồi không restore; truyền primitive sum tránh lỗi.
- Dùng Set expression và vô tình gộp các cách khác nhau cùng sum.

## 18. Bài transfer cùng pattern

- OF022: choice là dungeon chưa dùng, cần visited và restore.
- OF020: permutation chữ số, cần deduplicate kết quả.
- OF024: DFS enumerate alphabet fixed branching.

Tín hiệu: mỗi position có tập choice nhỏ, bound cho phép tích branching ⇒ DFS choice tree với state prefix tối thiểu.

### Loop and condition derivation

- **Nhịp lặp:** `DFS tạo đúng hai recursive branch tại mỗi index.`. Đây là lý do code dùng block bắt đầu bởi `function dfs(index, sum) {`, thay vì chọn loop theo thói quen.
- **Câu hỏi trước branch:** “index === numbers.length; tại base sum === target không.”. Trong dry run `[1,1]`, đối chiếu dòng làm condition true và dòng làm condition false; code tương ứng bắt đầu tại `if (index === numbers.length) {`.
- **Tiến triển:** mỗi branch gọi index + 1, không lùi hay skip index.. Nếu state/pointer không đổi, loop có thể xét lại cùng candidate hoặc giữ representation lệch current.
- **Thứ tự:** phải hoàn thành `ways += 1 chỉ ở matching leaf.` ở scope sở hữu current rồi mới chuyển nhịp. Dòng movement chính là `dfs(index + 1, sum + numbers[index]);`.
- **Cleanup:** sum truyền theo value nên không có mutable state phải restore.. Nếu là “không cần”, state đã hoàn tất ngay trong main loop; nếu có, block chỉ chạy sau khi traversal đã cung cấp đủ thông tin.

**Kiểm tra theo family cho Số mục tiêu:** Guard visited, bounds hoặc stale distance phải chạy trước transition tương ứng. Với BFS, mark visited lúc enqueue để một đỉnh không xếp hàng nhiều lần; với Dijkstra, bỏ entry stale trước khi relax cạnh.

#### 19. Làm bằng tay và brute force executable

Với `[1,1]`, target 0, hai index tạo bốn chuỗi dấu: `++`, `+-`, `-+`, `--`. Hai chuỗi giữa
đều đạt 0 và là hai cách khác nhau dù cùng partial/final sum.

```js
function targetNumberWaysBrute(numbers, target) {
  const choices = 1 << numbers.length;
  let ways = 0;

  for (let mask = 0; mask < choices; mask += 1) {
    let sum = 0;
    for (let index = 0; index < numbers.length; index += 1) {
      const usePlus = (mask & (1 << index)) !== 0;
      if (usePlus) {
        sum += numbers[index];
      } else {
        sum -= numbers[index];
      }
    }
    if (sum === target) ways += 1;
  }
  return ways;
}
```

Brute mask tính lại sum từ đầu. DFS truyền partial sum nên mỗi edge chỉ làm một phép cộng/trừ.
